# 多子多福：开创仙朝

一款以同名小说为世界观的**浏览器端放置修仙游戏**。

你是桂冈 —— 末世修仙世界里一个小家族的家长。修行、娶妻、生子、经营封地，
带着一群有灵根的子孙，把家族一步步推成仙朝。

基于开源项目 [setube/vue-idle-xiuxian](https://github.com/setube/vue-idle-xiuxian)（MIT）二次开发：
**修行侧已经整体换成了这本小说的世界观**（本命/灵根/功法/同参/灵地/契合度），
探索、秘境、经济、封地也都是按小说重写的，保留的上游通用系统只剩背包、成就等骨架。

> **开发中。** 已能完整玩通「修行 + 多子多福 + 桂冈的一天 + 探索/秘境 + 封地建设」这条主线，
> 任务战斗、百艺、门派政治等模块尚未实现（见下方[进度](#进度)）。

---

## 现在能玩到什么

**修行与突破** —— 练气 → 筑基 → 结丹。本命决定灵根，**功法 / 同参 / 灵地**三维契合度决定能否突破；
同参契合是标签连续值（0.1~1.0），不是档位。

**桂冈的一天**（主界面）—— 06:00 + 巡视时长开工 → 小循环（练功 / 炼体）→ 妻妾互动 → 18:00 下班 → 睡觉。
一个游戏天 96 现实秒，自动循环推进；白天干多少活、晚上留多少体力由你决定。

**多子多福** —— 侍妾位阶（P1~P13）、怀孕孕育、诞生抽卡、灵根与本命、洗命 / 血脉、
生命周期与经期；子嗣会自己打坐修炼（练气二层可出战）、能安排到 **6 个家族经济岗**、
被派去**历练**，家族树按生母 / 生父纵向展开，还能**导出族谱 JSON**（拖进 `public/clan-tree.html` 出图）。

**灵宠同修** —— 出战灵兽跟着桂冈打坐拿 50% 修为，面板 = 白板 × 成色 × 境界系数，秘境编成 3 子嗣 + 1 灵兽。

**三大挂机** —— **探索**（练气四图、叙事事件二选一、按境界判胜率）、
**秘境**（每难度 50 层、难度轴顺序解锁、Boss 首破奖励）、**镇守**（巡视图与流水，数值仍是占位）。

**封地经营** · `/estate` —— 乡侯府 / 灵田 / 鸦巢舍 / 亭卫四座建筑，建设 / 征收 / 产出三条进度条，
在线与离线都在 00:00 日结；巡视 ×2 在这里才真正生效。

**经济** —— 货币三字段（大子 / 金页子 / 灵石）同层自动进位、跨层买卖带价差；
郑家宝阁四页签（1~5 阶宝匣按境界解锁买入）、物品回收、宝箱开箱、装备 5 槽 + 一键装备。

**离线结算** —— 关掉页面也照样跑，最多结算 **180 游戏天（≈4.8 现实小时）**；
三大挂机按离线时状态三选一续跑，唯一会停下来等你的情况是子嗣陨落。

**当前可玩边界约在练气八层，九层的路已经打开。** 练气三层换《吕氏练气次第论》或元氏即可；
六层**必须先拿《兽器双修经》再换猪妖同参**（否则契合只有 0.228，过不了 0.24）；
九层需要同参契合 0.8 +《兽器双修经》——《兽器双修经》可以从探索「无字石碑」刷到，
但 0.8 的同参目前还没有获取途径，所以九层要挂一段时间探索。
筑基以上地图与筑基/金丹功法同样尚无来源 —— **这些都是设计上的断点，不是 bug**。

## 技术栈

Vue 3.5 · Vite 6 · Pinia 3 · Naive UI 2.41。
纯前端、无后端，存档加密后存在浏览器 IndexedDB 里。

## 本地运行

```bash
npm install
npm run dev            # http://localhost:2025
npm run verify:quiet   # 1684 条纯函数断言，只打失败项（数值改完必跑）
npm run check:docs     # 设计文档旧口径 + 坏链接
```

开发期想验证能不能打包 —— **不要**直接 `npm run build`，它会覆盖已提交的 `docs/`
（那是部署产物）：

```bash
npx vite build --minify esbuild --outDir .buildcheck
rm -rf .buildcheck
```
