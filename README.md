# 多子多福：开创仙朝

一款以同名小说为世界观的**浏览器端放置修仙游戏**。纯前端、无后端，打开网页就玩，关掉页面也照样修行。

你是**桂冈** —— 末世修仙世界里一个小家族的家长。修行、娶妻、生子、经营封地，
带着一群有灵根的子孙，把家族一步步推成仙朝。

基于开源项目 [setube/vue-idle-xiuxian](https://github.com/setube/vue-idle-xiuxian)（MIT）二次开发：
**修行侧已整体换成这本小说的世界观**（本命 / 灵根 / 功法 / 同参 / 灵地 / 契合度），
探索、秘境、经济、封地、门派也都是按小说重写的，保留的上游通用系统只剩背包、成就等骨架。

> **开发中。** 已能完整玩通「修行 + 多子多福 + 桂冈的一天 + 探索 / 秘境 + 封地建设与经营 +
> 飞鹰门日常 + 离线结算」。金丹段内容已经铺好，元婴以上仍是设计断点（见下方[可玩边界](#当前可玩边界)）。

## 游戏简介

**一局游戏在玩什么**

1. **修行与突破** —— 能不能破境，看「功法 × 同参 × 灵地」三维契合度**连乘**，不是攒够经验就行。
   本命决定灵根；功法是 90 本四阶四品的功法库；同参是带三层标签的实物（撞不上就是 0）；
   灵地要一块块从门派任务里挣。30 级境界：练气、筑基、金丹各十层。
2. **桂冈的一天** —— 主界面是一个会自己走的日循环：06:00 带巡视时长开工 →
   练功 / 炼体 / 百艺 → 晚间与妻妾互动 → 18:00 下班 → 睡觉。**一个游戏天 96 现实秒**。
   筑基后世界加速 **24×**、金丹 **168×**，日循环退成「昨日战报」。
3. **多子多福** —— 纳妾、怀孕、生子。子嗣继承灵根与本命，也会老、会死；
   修炼位只有 50 + 快子峰木屋等级 × 25，谁上谁下按资质排。家族树能长到上千人，也能导出成族谱图。
4. **经营与闯荡** —— 封地 22 栋建筑、人口徭役、三链经营；探索十二张图、秘境五十层；
   飞鹰门周任务与贡献点。资源进背包，背包进装备，装备进战力。
5. **离线也在跑** —— 关掉页面按现实时长结算（上限 4.8 小时），回来领「闭关归来」报告。

**它和一般放置游戏不一样的地方**：门槛不是「攒够经验」，而是一套**会卡人的契合度**；
子孙不是数值，是**会老死的角色**；数值表、设计文档和 3,400 多条断言都在仓库里，
改一个数要连锁验算。

## 现在能玩到什么

**修行与突破** —— **30 级境界**：练气、筑基、金丹各十层（元婴 31~40 未落地）。
本命决定灵根，**功法 / 同参 / 灵地**三维契合度连乘决定能否突破（门槛 0.15 / 0.26 / 0.35 / 0.40 / 0.76）。
同参契合是三层标签的连续值（0~1.0，撞不上就是 0）；**心法取已修最高的一本**，等级还会进门槛；
功法库 **90 本**，分心法 / 法术 / 身法 / 炼体 / 器诀，只有心法有残页。突破弹三档提示，不暂停时钟。
**结丹有丹论**：金丹一层突破后三选一立论，27 条文言候选按存档行为生成，0 数值、纯叙事。

**桂冈的一天**（主界面）—— 练气期 06:00 + 巡视时长开工 → 小循环（练功 / 炼体 / 百艺）→ 妻妾互动 → 18:00 下班 → 睡觉。
**一个游戏天 96 现实秒**，自动循环推进。筑基后世界加速 **24×**（金丹 **168×**），小循环退场、改看昨日战报。

**多子多福** —— 侍妾位阶 P1~P9（练气 P1–P3 凡女 20 金页子 / 筑基 P9 练气女修 6 二阶；金丹 P10 以上挂起）、
**孕产与生育模型**（孕期 280 天、产后 30 天、奖励期 90/10、自然期受孕率按位阶、育龄窗口按寿元）、
诞生抽卡、灵根与本命、洗命 / 血脉；子嗣出生即自动打坐（练气二层可出战），
能安排到 **6 个家族经济岗**、被派去**历练**，也能进**传功阁**学一门匹配功法。
**子嗣词条 v2**：修士 35 条 / 凡人 21 条 / 专精 47 条，按修行 / 战力 / 功法 / 岗位 / 专精五个通道生效。
寿元随境界提升（凡人 80 / 练气 120 / 筑基 200 / 金丹 500 仙龄岁），寿终与陨落走横幅讣告。
**千字文辈分取名**（桂天 X / 桂地 X …），家族树按生母 / 生父纵向展开，能**导出族谱 JSON**
（拖进 `public/clan-tree.html` 出图）。

**灵宠同修** —— 出战灵兽跟着桂冈打坐拿 50% 修为，面板 = 白板 × 成色 × 境界系数，秘境编成 3 子嗣 + 1 灵兽。

**三大挂机** —— **探索**：十二图三段（练气 1/3/6/9 + 筑基 11/14/17/20 + 金丹 21/24/27/30，
全库 12 图 / 207 条），叙事事件二选一、按境界判胜率，掉落阶随境界段抬升；
**秘境**：每难度 50 层、难度轴顺序解锁、Boss 首破奖励、扫荡难度加成；
**镇守**：巡视图与流水已跑，数值仍是占位。

**封地经营** · `/estate` —— **22 栋建筑**，解锁由乡侯府 Lv1~5 卡；村民人口 + 徭役（总人口 × 25%）+ 税收；
粮 / 灵植 / 矿石进**独立中间产物仓**；**三链经营**（酒坊 粮→灵酒、丹炉 灵植→灵丹、工坊 矿石→法器），
市集是必建闸门，成品即产即卖；仓里的灵植可以**取回背包**（本段阶 + 中成色 + 五系按药力缺口）喂药浴 / 炼丹。
建设 / 征收 / 产出三条进度条，在线与离线都在 00:00 日结；巡视加速按小时折算 `(24+S)/24`；
封地全景图 6×4 地块三态。

**飞鹰门** · `/faction` —— 贡献点与周任务、**飞鹰阁 9 库位**（功法 3 + 物资 6）、老九订货、
四步剧情任务线（解锁其余 **9 块灵地**，一阶 3 块开局送）；**职位与俸禄**：累计贡献 **17,000 / 240,000**
升中柱 / 上柱，月俸 **833 / 1,500 / 2,500 二阶**，**90% 贡献点 + 10% 累积可提现额度**。

**百艺** · `/arts` —— **四艺**：炼器 / 炼丹 / 制符 / 炼阵，13 条配方；一阶配方免残页，
二阶起集齐 `5 × 配方阶` 张残页自动学会。秘境消耗品（丹药每 5 层 / 符箓每层 / 阵法整趟）自动从背包扣；
**乡间自动百艺**：丹炉 / 工坊 / 符坊 / 阵堂每级每天产 1 件本段阶实物，可回收。

**经济** —— 货币 v4（单字段总账，一阶自动进位）、郑家宝阁五阶宝匣（148 / 444 / 2,000 / 7,200 / 23,040 二阶）、
物品回收、宝箱开箱、坊市**灵材三换二**、装备 5 槽 + 一键装备。

**离线结算** —— 关掉页面也照样跑，上限统一是**现实 4.8 小时**：练气 180 游戏天 /
筑基 4,320 天 / 金丹 30,240 天（时间倍率越高，同样的现实时长换算出的游戏天越多）。
按块结算（练气 1 / 筑基 7 / 金丹 180 游戏天一块）；封地块内仍逐日算，只是复印 / 钱袋 / 落盘
合成块首块末各一次。
三大挂机按离线时状态三选一续跑，唯一会停下来等你的情况是子嗣陨落。

### 当前可玩边界

**可玩边界 = 练气十层。** 练气三层换《吕氏练气次第论》或元氏即可（0.206）；
六层**必须先拿《兽器双修经》**（≈0.33，可从探索「无字石碑」刷到），吕氏练满也只有 0.251，过不了 0.26；
九层再把同参换到猪妖系（62.3%）→ 0.380。

**筑基正路 = 功法 + 同参**：飞鹰阁功法栏（练气八层开放，池 = T1+T2 心法 24 本、整本 200~300 点、
全随机不保底）买《万兽御器经》（`0.26 + 0.40 = 0.66`）× 猪妖系同参 62.3% = **0.411 > 0.40**。
金丹要 **《兽器同源经》 × 本命原物 1.0 = 0.760 卡线**，这本功法目前仍无获取途径。
元婴以上地图与四阶功法尚无来源 —— **这些都是设计上的断点，不是 bug**。

## 技术栈

Vue 3.5 · Vite 6 · Pinia 3 · Naive UI 2.41。
纯前端、无后端，存档加密后存在浏览器 IndexedDB 里。

## 本地运行

```bash
npm install
npm run dev            # http://localhost:2025
npm run verify:quiet   # 3,452 条纯函数断言，只打失败项（数值改完必跑）
npm run check:docs     # 设计文档旧口径 + 坏链接
```

开发期想验证能不能打包 —— **不要**直接 `npm run build`，它会覆盖已提交的 `docs/`
（那是部署产物）：

```bash
npx vite build --minify esbuild --outDir .buildcheck
rm -rf .buildcheck
```
