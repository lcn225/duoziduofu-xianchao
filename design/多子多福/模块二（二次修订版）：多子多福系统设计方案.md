# 模块二（二次修订版）：多子多福系统设计方案

## 一、核心机制确认

根据最新补充，子嗣系统核心规则如下：

1. **只有拥有灵根的子嗣才提供修行加成和契合度加成。**
2. **无灵根子嗣不能加成修行，但可以继续繁育后代，扩大人口基数，增加后代灵根出现概率。**
3. **无灵根子嗣可从事家族日常工作，维护家族运转。**
4. **有灵根子嗣是核心资产，无灵根子嗣是人口基数和家族劳力。**

**核心循环（修订）**：

白天积累精力 → 晚上分配精力互动 → 当场确认怀孕 → 孕育 → 诞生抽卡（10% 灵根概率） → **有灵根子嗣提供修行加成，无灵根子嗣进入家族人口池** → 无灵根子嗣继续繁育，扩大人口基数 → 人口基数提升灵根出现概率 → 子嗣成长 → 派遣/联姻/从政 → 加成修行 → 获取资源 → 纳更多侍妾。

## 二、子嗣分类与价值

### 2.1 有灵根子嗣

| 项目    | 说明                        |
| ----- | ------------------------- |
| 修行加成  | ✅ 提供 `cultivationSpeed`   |
| 契合度加成 | ✅ 提供 `compatibilityBonus` |
| 可修行   | ✅ 自动修行，提升修为               |
| 可派遣   | ✅ 可执行战斗、巡查、征战任务           |
| 可联姻   | ✅ 联姻价值高                   |
| 可抢夺词条 | ✅ 拥有词条，可被抢夺               |
| 可传功   | ✅ 可学习功法、炼丹、炼器             |
| 陨落返还  | ✅ 触发修行返还                  |

**核心价值**：修行加速、契合度提升、战斗派遣、门派任职。

### 2.2 无灵根子嗣

| 项目    | 说明               |
| ----- | ---------------- |
| 修行加成  | ❌ 不提供任何修行加成      |
| 契合度加成 | ❌ 不提供契合度加成       |
| 可修行   | ❌ 无法修行           |
| 可派遣   | ✅ 可执行凡俗任务        |
| 可联姻   | ✅ 联姻价值低，但可维系势力关系 |
| 可抢夺词条 | ❌ 无词条（极少数除外）     |
| 可传功   | ❌ 无法学习仙家功法       |
| 陨落返还  | ❌ 不触发修行返还        |

**核心价值**：人口基数、家族劳力、繁育载体、联姻工具。

### 2.3 无灵根子嗣的繁育机制

无灵根子嗣虽然不能修行，但可以继续繁育后代。这是他们最重要的价值。

**繁育规则**：

- 无灵根子嗣成年后（18岁），可安排婚配。
- 婚配对象可以是：其他无灵根子嗣、凡人、低阶修士。
- 婚配后自动繁育，每对夫妇每年有概率诞下后代。
- 诞下的后代进入**孙辈人口池**，参与灵根概率判定。

**人口基数与灵根概率**：

```
灵根概率 = 基础概率 10% + 人口基数加成
```

| 人口基数（子孙总数） | 人口基数加成 |
| ---------- | ------ |
| 0-50       | +0%    |
| 51-100     | +1%    |
| 101-200    | +2%    |
| 201-500    | +3%    |
| 501-1000   | +5%    |
| 1001-5000  | +8%    |
| 5001+      | +10%   |

**人口基数** = 所有存活子孙总数（含有灵根和无灵根）。

**示例**：已有 300 名子孙，则灵根概率 = 10% + 3% = 13%。

**关键**：无灵根子嗣越多，人口基数越大，后代中出现灵根的概率越高。

- 玩家可在**家族管理界面**中，将无灵根子嗣分配到不同岗位。

- 子嗣的**属性**（管理、武艺、经商、口才等）影响岗位效率。
- 可通过**培训、教育**提升子嗣属性。

## 四、子嗣抽卡系统（修订）

### 4.1 灵根概率

| 结果  | 基础概率 | 人口基数加成后      |
| --- | ---- | ------------ |
| 无灵根 | 90%  | 90% - 人口基数加成 |
| 有灵根 | 10%  | 10% + 人口基数加成 |

**首充礼包**：第一个子嗣必定拥有灵根（100%）。

### 4.2 有灵根子嗣品质细分

| 品质  | 概率（占有灵根） | 综合概率  | 灵根      | 本命    | 词条          |
| --- | -------- | ----- | ------- | ----- | ----------- |
| 下品  | 60%      | 6%+   | 五灵根     | 凡兽    | 1个普通词条      |
| 中品  | 25%      | 2.5%+ | 四灵根/三灵根 | 灵兽    | 1个稀有词条      |
| 上品  | 12%      | 1.2%+ | 双灵根     | 王级变异兽 | 2个稀有词条      |
| 极品  | 3%       | 0.3%+ | 单灵根     | 神兽/仙器 | 3个词条+1个传说词条 |

### 4.3 保底机制

- 每 20 次抽卡必出有灵根子嗣。
- 每 100 次抽卡必出上品及以上。
- 每 500 次抽卡必出极品。
- 保底计数器在抽到对应品质时重置。

## 五、子嗣成长与婚配

### 5.1 成长阶段

| 年龄     | 状态  | 有灵根         | 无灵根         |
| ------ | --- | ----------- | ----------- |
| 0-3岁   | 幼年  | 基础加成        | 无           |
| 4-6岁   | 启蒙  | 测灵根，开始修行    | 开始教育        |
| 7-12岁  | 少年  | 可派遣简单任务     | 可分配简单工作     |
| 13-18岁 | 青年  | 可派遣危险任务，可联姻 | 可婚配，可分配正式工作 |
| 19-30岁 | 成年  | 可担任门派职务     | 可担任家族管理     |
| 31岁以上  | 中年  | 可带兵、镇守、出使   | 可担任家族长老     |

### 5.2 婚配系统

**有灵根子嗣婚配**：

- 优先与修士家族联姻（郑家、明家、冯家、张家）。
- 联姻获取势力好感、资源、功法。
- 诞下的后代有更高概率拥有灵根（+5%）。

**无灵根子嗣婚配**：

- 可与其他无灵根子嗣、凡人、低阶修士婚配。
- 婚配后自动繁育，扩大人口基数。
- 诞下的后代进入孙辈人口池，参与灵根判定。
- 婚配不消耗玩家精力，自动进行。

**婚配规则**：

- 每对夫妇每年有 30% 概率诞下一名后代。
- 后代自动进入人口池，参与灵根判定。
- 人口池越大，灵根出现概率越高。
- 玩家可查看**家族谱系**，追踪子孙繁衍情况。

## 八、与其他模块的交互

| 模块   | 交互方式                                               |
| ---- | -------------------------------------------------- |
| 修行突破 | 仅有灵根子嗣提供 `cultivationSpeed` 和 `compatibilityBonus` |
| 内宅姻缘 | 侍妾状态机决定互动和怀孕；好感度影响内宅稳定                             |
| 门派政治 | 有灵根子嗣可担任门派职务；无灵根子嗣可担任家族管理                          |
| 封地经营 | 无灵根子嗣可担任庄头、账房、驿丞等岗位                                |

## 九、可玩性设计要点

1. **有灵根子嗣是核心资产**：提供修行加成，是突破门槛的关键。
2. **无灵根子嗣是人口基数**：虽然不提供加成，但能继续繁育，扩大人口池，提升后代灵根概率。
3. **人口基数正反馈**：子孙越多，灵根概率越高，形成“多子多福”的长期正循环。
4. **家族工作是无灵根子嗣的用途**：安排他们到各岗位，产出资源，维护家族运转。
5. **婚配系统是人口扩张的引擎**：无灵根子嗣自动婚配繁育，持续扩大人口池。
6. **精力分配是每晚的核心决策**：有限精力如何分配给多个侍妾，是广撒网还是重点突破。
7. **侍妾状态机提供策略深度**：需要关注例假、已孕、生气等状态，合理安排互动顺序。
8. **当场确认怀孕提供即时反馈**：每次互动后立即知道结果，爽感强。
9. **10% 灵根概率 + 人口加成保证稀缺性和成长性**：有灵根子嗣珍贵，但人口基数提升后概率增加。
10. **保底机制避免非酋挫败**：20 抽必有灵根，100 抽必出上品。
11. **好感度是隐藏的长期投资**：提升好感度可提高怀孕率、子嗣质量、派遣成功率。
12. **精力无限彩蛋提供终极目标**：50 子嗣或 20 P4 侍妾后解锁，夜夜笙歌。
13. **词条抢夺有代价**：抢夺子嗣词条可快速提升，但降低好感，可能触发叛逆。
14. **家族谱系提供长期成就感**：看着子孙满堂、开枝散叶，是放置游戏的核心情感满足。
