# 同参系统 — 完整方案书

## 一、系统定位

同参是**辅助本命修炼**的物品。

**核心规则**：

- 同参从物品池里筛选，不单独建表
- 亲和度动态计算，取决于修士本命
- 同参品阶只影响稀有词条获得率，不影响契合度
- 同参不能升级，只能更换

## 二、物品池

### 2.1 四大类

| 类别     | 用途        | 示例         |
| ------ | --------- | ---------- |
| **灵兽** | 灵宠出战 / 同参 | 猪、獾、鸦、虎、蛟  |
| **灵草** | 炼丹 / 同参   | 参、草、花、果    |
| **灵器** | 装备 / 同参   | 盾、剑、牌、刀    |
| **灵岩** | 炼器材料 / 同参 | 暗金、风磨铜、青金石 |

### 2.2 物品数据结构

```javascript
item = {
  id: 'boar_black_2',
  name: '刃背黑猪妖',
  category: '灵兽',        // 灵兽 / 灵草 / 灵器 / 灵岩
  series: 'boar',          // 系列
  tier: '2下',             // 品阶
  equipmentStats: null,    // 灵器/灵岩有
  petStats: { hp, atk },   // 灵兽有
  // 不存 fateAffinity，动态计算
}
```

### 2.3 同参筛选

```javascript
function getFateCandidates(fate) {
  return allItems.filter(item => 
    item.series === fate.series ||
    item.category === fate.category
  );
}
```

**任何物品都可以当同参。** 物品池里所有东西都能参与筛选。

## 三、同参契合度六档

### 3.1 档位表

| 档位      | 系数       | 判定                  |
| ------- | -------- | ------------------- |
| **正主**  | **1.0**  | 完全对应（唯一）            |
| **准正主** | **0.8**  | 同系列 + 同名            |
| **同系列** | **0.6**  | 同 series            |
| **近类型** | **0.4**  | 同 category + 同 kind |
| **同类型** | **0.25** | 同 category          |
| **无关**  | **0.1**  | 其他                  |

### 3.2 判定逻辑

```javascript
function calcFateAffinity(item, fate) {
  if (item.id === fate.masterItemId) return 1.0;       // 正主
  if (item.series === fate.series && item.name === fate.name) return 0.8;  // 准正主
  if (item.series === fate.series) return 0.6;         // 同系列
  if (item.category === fate.category && item.kind === fate.kind) return 0.4;  // 近类型
  if (item.category === fate.category) return 0.25;    // 同类型
  return 0.1;                                           // 无关
}
```

### 3.4 实现方式：先硬编，规则以后再说（**2026-10-16 定**）

**背景**：「同参」这玩意在原作里本来就玄，没有一套能自洽的判定规则。理想解是
**给所有物品打标签，契合度看标签接近度** —— 但要给整个物品池（100+ 件）打标签，
工作量太大，现在做不值。

**临时测试方案（本批采用）**：

> **硬写桂冈的那几件同参的契合度。** 照 §3.3 那张表直接写死系数，不实现 §3.2 的判定规则。
> 以后物品池扩充、标签体系定了，再统一调。

具体值（**这就是要硬编的清单**）：

| 同参 | 对桂冈的契合度 | 备注 |
|---|---|---|
| `boar_king_4` 刃背乌鬣猪王 | 1.0 | 正主 |
| `boar_adult_3` 刃背乌鬣猪妖·成年 | 0.8 | 准正主 |
| `boar_black_2` / `boar_flower_2` / `wu_li_zhu_yao` | 0.6 | 同系列 |
| `taotie_shield` 饕餮纹风磨铜盾 | **0.4** | 开局默认主同参 |
| `taotie_white_2` / `taotie_blue_3` / `taotie_jade_4` | 0.6 / 0.6 / 1.0 | 同系列 / 正主 |
| `qingyu_sword` / `jinggang_ci` / `lingteng_shield` | 0.25 | 同类型 |

⚠ **两处规则对不上的地方，在硬编方案下**不构成阻塞**，但记在这里免得以后忘了**：

1. 盾的 series 是 `taotie`、本命玉牌也是 `taotie`，按 §3.2 该是**同系列 0.6**，上表按 §3.3 写的是 **0.4**。
   硬编期间**以上表为准**（开局默认主同参 = 盾 → 0.4 → 综合 0.08，与 §六 自洽）。
2. 「准正主 = 同系列 + 同名」，但本命叫「刃背乌鬣猪」、物品叫「刃背乌鬣猪妖·成年」，名字并不相等。
   硬编期间**这条规则不实现**，直接给 0.8。

**目标方案（待办）**：物品打标签 → 契合度 = 标签接近度。见 §十一 待办。

## 五、同参品阶的作用

### 5.1 品阶不影响契合度

**同参契合度只看接近度，不看品阶。**

### 5.2 品阶决定稀有词条获得率

| 同参品阶 | 积累速度           | 说明  |
| ---- | -------------- | --- |
| 一阶   | 1 次 / 100 游戏小时 | 最慢  |
| 二阶   | 1 次 / 80 游戏小时  |     |
| 三阶   | 1 次 / 60 游戏小时  |     |
| 四阶   | 1 次 / 40 游戏小时  |     |
| 五阶   | 1 次 / 30 游戏小时  | 最快  |

**词条品质由本命品阶决定，不由同参品阶决定。**

### 5.3 防薅羊毛机制

| 机制       | 说明                 |
| -------- | ------------------ |
| **积累制**  | 词条机会逐次积累，换同参只影响之后的 |
| **切换冷却** | 换同参后 24 游戏小时才生效    |
| **不可逆**  | 已积累的词条机会品质已定       |
