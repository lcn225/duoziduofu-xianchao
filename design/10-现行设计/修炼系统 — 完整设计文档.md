## 一、行功带宽（散功重修）

### 1.1 核心机制

散功重修的本质是扩展行功带宽：

```
行功带宽 = 基础带宽 1.0 + Σ(每次散功重修的带宽扩展)
```

### 1.2 五种散功情况

| 情况           | 说明             | 带宽扩展 |
| ------------ | -------------- | ---- |
| a. 旧功法重修     | 散功后重修同一本       | +0%  |
| b. 差不多的功法     | 五行相同、类型相同、同级   | +10% |
| c. 全新功法      | 五行不同或类型不同      | +20% |
| d. 差不多的高级功法   | 五行相同、类型相同、高级   | +30% |
| e. 全新高级功法     | 五行不同或类型不同、高级   | +50% |

### 1.3 边际衰减

```
第 n 次重修的实际带宽扩展 = 基础扩展 × (1 / (1 + 0.1 × n))
```

### 1.4 带宽上限

```
行功带宽上限 = 1.0 + 已收集功法总数 × 0.5
```

### 1.5 散功代价

| 项目     | 变化    |
| ------ | ----- |
| 灵力     | 清零    |
| 内功修为   | 清零    |
| 境界     | 回练气一层 |
| 功法熟练度  | 减半    |
| 同参     | 不变（本就不能升级，只可更换） |
| 子嗣     | 不受影响  |
| 行功带宽   | 永久扩展  |

> 旧版的「同参祭炼取消」一条已删除：祭炼机制整体取消（见《跨文档冲突审阅》§9）。

## 二、子嗣修炼加成

```
子嗣修炼加成 = Σ(每个有灵根子嗣的加成)

单个子嗣加成 = 灵根系数 × 本命契合系数 × 词条系数
```

| 灵根   | 灵根系数 |
| ---- | ---- |
| 五灵根  | 0.02 |
| 四灵根  | 0.05 |
| 三灵根  | 0.10 |
| 双灵根  | 0.20 |
| 单灵根  | 0.40 |

| 子嗣本命与玩家本命关系 | 本命契合系数 |
| ----------- | ------ |
| 完全相同        | 1.5    |
| 同类型         | 1.2    |
| 同五行         | 1.0    |
| 无关          | 0.5    |

| 词条    | 词条系数 |
| ----- | ---- |
| 普通词条  | +0.05 |
| 稀有词条  | +0.10 |
| 传说词条  | +0.20 |

**上限**：+200%。

### 示例

假设玩家有 10 名有灵根子嗣：

| 子嗣    | 灵根  | 本命关系 | 词条   | 单个加成             |
| ----- | --- | ---- | ---- | ---------------- |
| 桂大    | 单火  | 同类型  | 剑心通明 | 0.40×1.2×1.10 = 0.528 |
| 桂二    | 双水木 | 同五行  | 丹心妙手 | 0.20×1.0×1.10 = 0.220 |
| 桂四    | 三灵根 | 同类型  | 经商奇才 | 0.10×1.2×1.10 = 0.132 |
| 桂六    | 四灵根 | 无关   | 无    | 0.05×0.5×1.0 = 0.025   |
| ...   |     |      |      |                  |
| **10 人合计** |   |      |      | **约 +1.5**        |
