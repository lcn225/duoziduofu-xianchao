子嗣与家族经济体系 — 完整设计

一、设计原则

原则 说明

子嗣是家族执行者 不分封、不独立，产出归家族

子嗣月钱是运营损耗 不影响家族资产，只是固定支出

小金库不回流 子嗣个人经济独立，结余归己

真正的扩张靠开拓 新地盘归家族，子嗣只管理

管理能力是扩张瓶颈 有钱没人管，扩张就卡住

2.1 月钱表

子嗣类型 月钱 年成本 设计意图

无灵根、未成年 50 大子 6 金页子 零花，可忽略

设计逻辑：月钱 = 该境界子嗣每年能买 1-2 瓶正路子丹药的水平。

2.2 验证：仙朝阶段

假设仙朝阶段子嗣构成：

占仙朝收入 110,000 二阶的 3.34%——与侍妾月饷（5.9%）合计约 9.2%，正好在 10% 财政负担线以内。

> **口径补充（2026-10-15）**：仙朝收入分两档——《经济体系》口径的 **80,000 二阶/年**（不含跨域贸易）与含跨域贸易的 **110,000**。上面的 9.2% 是按 110,000 算的；**换成 80,000 则是 12.7%，会越过 10% 财政线**。配平时请明确用哪一档。

三、子嗣小金库

3.1 设计

项目 说明

来源 月钱花不完的部分

用途 自身修行、培养后代、联络势力

是否回流 不回流，纯运营损耗

是否影响好感 小金库越多，子嗣越独立，好感增长越慢

3.2 运营损耗的体现

· 子嗣月钱 = 家族固定支出，花出去就没了

· 子嗣小金库 = 子嗣个人资产，家族无法动用

· 好感 80+ 的子嗣有概率自愿上缴部分小金库（随机事件）

设计意图：子嗣不是纯工具人，有自己的经济空间。这增加了家族运营的真实感和损耗感。

四、管理能力约束（ABC 全实现）

4.1 A. 每块封地需要一个人管理

岗位 数量 说明

乡侯 = 封地数量 管理一乡

驿丞 = 驿站数量 管理驿站

庄头 = 村庄数量 管理村庄

亭长 = 亭卫数量 管理亭卫

每个岗位必须有人，否则：

· 乡侯空缺 → 封地税收 -50%

· 驿丞空缺 → 情报产出归零

· 庄头空缺 → 村庄产出 -30%

· 亭长空缺 → 边境安全 -20%

4.2 B. 管理岗位有数量上限

```
管理岗位总数 = 10 + 有灵根成年子嗣数 × 2 + 无灵根成年子嗣数 × 0.5 + 门人数 × 0.3
```

来源 系数 说明

基础 10 桂冈本人 + 核心亲信

有灵根成年子嗣 ×2 每人可管 2 个岗位

无灵根成年子嗣 ×0.5 每人可管 0.5 个岗位

门人 ×0.3 忠诚度低，效率差

示例：

· 扎根阶段：10 + 5×2 + 50×0.5 + 3×0.3 = 45 个岗位

· 仙朝阶段：10 + 126×2 + 500×0.5 + 20×0.3 = 518 个岗位

4.3 C. 管理能力影响产出效率

```
岗位产出效率 = 基础效率 × 管理者能力系数
```

管理者 能力系数 说明

桂冈本人 1.0 最高

有灵根子嗣（筑基+） 0.9 修为高，能力强

有灵根子嗣（练气） 0.7 修为低，但可培养

无灵根子嗣 0.5 凡人，能力有限

门人 0.4 忠诚度低，效率差

示例：

· 长岭乡由有灵根子嗣（练气）管理：税收 ×0.7

· 长岭乡由桂冈本人管理：税收 ×1.0

· 长岭乡由门人管理：税收 ×0.4

五、真正的扩张：开拓新地盘

5.1 扩张来源

方向 目标 难度 收益 前置条件

北 长岭关外 极高 妖兽材料、灵地 战斗力系统

东 七连寨 高 人口、灵矿 战斗力系统

西 连山派边缘 极高 商路、功法 战斗力系统

南 郑家飞地 中 坊市分成 外交系统

5.2 开拓流程

1. 派遣子嗣 + 队伍前往目标区域

2. 建立据点（消耗灵石 + 时间）

3. 占领 / 谈判 / 征服

4. 设立封地（归家族所有）

5. 派遣管理者（子嗣或门人）

6. 封地开始产出

5.3 扩张的边际成本

封地数量 开拓成本 管理需求 总税收

1（长岭乡） 初始 1 乡侯 5,703 金页子/年

2 5,000 二阶 2 乡侯 +8,000 金页子/年

3 10,000 二阶 3 乡侯 +12,000 金页子/年

5 30,000 二阶 5 乡侯 +20,000 金页子/年

10 100,000 二阶 10 乡侯 +40,000 金页子/年

瓶颈不是钱，是管理能力——每块封地需要有人管，子嗣不够就只能派门人，门人忠诚度低、效率差。

六、修正后的家族经济循环

```
家族经济：

收入 → 俸禄 + 封地税收 + 商队 + 投资 + 子嗣派遣

支出 → 侍妾月饷 + 子嗣月钱 + 建设 + 修行 + 联姻

子嗣经济：

收入 → 家族月钱

支出 → 自身修行 + 培养后代 + 联络势力

结余 → 小金库（不回流，纯运营损耗）

扩张：

子嗣派遣 → 开拓新地盘 → 家族直辖 → 新封地

（真正的增量，不是左手倒右手）

管理约束：

岗位总数 = 10 + 有灵根子嗣×2 + 无灵根子嗣×0.5 + 门人×0.3

产出效率 = 基础 × 管理者能力系数

循环：

家族收入增长 → 更多子嗣 → 更多管理岗位 → 更多封地 → 更多收入

（正循环，但受管理能力约束）
```
