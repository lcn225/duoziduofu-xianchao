四、综合契合度（连乘）

4.1 公式

```
综合契合度 = 功法契合 × 同参契合 × 灵地契合
```

维度 范围

功法契合 0.2 ~ 1.0

同参契合 0.15 ~ 1.0

灵地契合 0.2 ~ 1.0

连乘，任何一项短板都拖累整体。

4.2 功法契合

```
功法契合 = 品阶分 + 覆盖率 × 40% + 熟练度
```

项目 分值

品阶分 练气篇 20% / 筑基级 30% / 金丹级 40%

覆盖率 \|功法灵气 ∩ 修士灵气\| / \|修士灵气\|

熟练度 每 100 游戏小时 +1%，上限 20%

功法契合上限：

品阶 不匹配 部分匹配 完全匹配

练气篇 40% 60% 80%

筑基级 50% 70% 90%

金丹级 60% 80% 100%

4.3 同参契合

```
同参契合 = 接近度系数
```

接近度 系数 判定

正主 1.0 物品 id === 本命 masterItemId

同系列 0.7 物品 series === 本命 series

同类型 0.4 物品 category === 本命 category

无关 0.15 其他

9.1 统一模型

```
物品池（灵兽 / 灵草 / 灵器 / 灵岩）

├── 装备属性 → 装备栏用

├── 灵宠属性 → 灵宠栏用

└── 同参属性 → 同参栏用
```

同一件物品，可以装备、可以出战、可以参悟。

9.2 物品数据结构

```javascript
item = {

id, name,

category: '灵兽', // 灵兽 / 灵草 / 灵器 / 灵岩

series: 'boar', // 系列

tier: '2下', // 品阶

equipmentStats, // 灵器/灵岩有

petStats, // 灵兽有

}
```

物品不存亲和度。亲和度由公式动态算。

十一、升级加成

11.1 公式

```
本次实际增加 = 基础增加数值 × (1 + 本命浮动)

基础增加数值 = 等级基础值 × 功法乘数
```

11.2 本命浮动

本命品阶 浮动范围 平均

一阶 0%~10% 5%

二阶 5%~15% 10%

三阶 10%~20% 15%

四阶 15%~25% 20%

五阶 20%~30% 25%

每次突破时 roll 一次。

11.3 验证

基础增加 10 攻击力/次，18 次突破：

本命 浮动 单次 18 次累计

一阶 +5% 10.5 189

四阶 +20% 12 216

五阶 +25% 12.5 225

四阶 vs 一阶差 14%，五阶 vs 一阶差 19%。

功法层级影响更大：一阶本命 + 金丹级功法 vs 五阶本命 + 练气篇功法，一阶反超。
