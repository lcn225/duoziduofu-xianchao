# 宝箱系统 — 完整设计方案书（含获取途径）

## 一、 核心设计原则

1. **暗黑2式TC掉落树**：一切随机，摒弃固定奖励清单，用Pick（拾取次数）、大类判定、标签判定、成色判定，构建打宝快感。
2. **无“正主/极品”概念**：宝箱只产出**底材**（灵器/灵兽/灵草/灵材）。能不能当同参，取决于它的 `series`（标签）和玩家本命的匹配度。
3. **同参强度受本命封顶**：高阶宝箱提供的底材面板极高，但作为同参的契合度受限于玩家“本命品阶”（如四阶本命拿五阶替代品，契合度仍按四阶算）。
4. **只出死物，不出活人**：女修/侍妾不进宝箱。高阶宝箱可开出【联姻信物】，去触发事件系统。

## 二、 修仙版 TC（财宝等级）机制定义

| 暗黑2 概念           | 修仙版映射           | 说明                                     |
|:---------------- |:--------------- |:-------------------------------------- |
| **TC等级**         | **宝匣阶级 (1~7阶)** | 决定能掷出的底材最高品阶，以及 Pick 次数。               |
| **Pick次数**       | **掉落次数**        | 1~2阶掷 3~5 次，3~4阶掷 5~8 次，5~7阶掷 8~12 次。  |
| **大类池**          | **物品大类**        | 灵石、灵草、灵材、灵器、灵兽、功法、特殊道具。                |
| **标签池 (Series)** | **系列标签**        | boar（猪）、taotie（饕餮纹）、huan、ya、hu、jiao 等。 |
| **成色 (Quality)** | **品质词条**        | 凡品、下品、中品、上品、极品（影响装备面板与词条数）。            |

## 三、 开箱逻辑：完整判定流程

开启一个宝匣，系统依次执行以下判定：

### Step 1：决定掉落次数（Pick）

根据宝匣阶级，掷骰子决定本次进行几次 Pick：

* 1~2阶：3~5 次 Pick。
* 3~4阶：5~8 次 Pick。
* 5~7阶：8~12 次 Pick。
* *（Boss 首杀宝匣额外 +3 次 Pick）*

### Step 2：单次 Pick 判定大类

每一次 Pick 掷骰子：

| 大类              | 概率权重 | 说明                  |
|:--------------- |:---- |:------------------- |
| **灵石**          | 50%  | 基础货币，越高级箱子给的灵石数量越大。 |
| **空包 (NoDrop)** | 10%  | 什么都没出（防爆仓机制）。       |
| **灵草 / 灵材**     | 20%  | 用于百艺的材料。            |
| **灵器 / 灵兽**     | 15%  | 核心打宝底材。             |
| **功法残页 / 特殊道具** | 5%   | 极品奖励（洗命符、破境丹等）。     |

### Step 3：大类细分判定（若抽中非灵石类）

1. **标签判定（Series）**：
   * 50% 概率：从玩家本命系列池中抽（如桂冈为 boar / taotie）。
   * 50% 概率：从全系列池中抽（如 huan / qingyu 等）。
2. **底材品阶判定（Qlvl）**：根据宝匣 TC 等级，决定最高能出几阶底材。
3. **成色判定（受寻宝值MF影响）**：极品 → 上品 → 中品 → 下品 → 凡品（逐级降格判定）。

## 五、 宝箱获取途径（全系统联动）

为了控制通货膨胀并保证高级箱子的稀缺性，获取途径严格挂钩《最高宪法》设定的各大系统：

### 1. 境界突破（【破境造化】）

* **小境界突破**：奖励 **1 个 一阶木匣**。
* **门槛突破**（如练气三层、筑基）：奖励 **2 个 二阶铁匣**。（给玩家换配置的资本）
* **大境界突破**（如练气十层升筑基）：奖励 **1 个 四阶银匣 + 3 个 三阶铜匣**。
* **元婴大突破**：奖励 **1 个 六阶玉匣**。

### 2. 子嗣诞生（多子多福）

* **下品（五灵根）**：1 个 一阶木匣。
* **中品（三/四灵根）**：1 个 二阶铁匣。
* **上品（双灵根）**：1 个 三阶铜匣。
* **极品（单灵根）**：1 个 四阶银匣。

### 3. 秘境爬塔

* **每 5 层（Buff层）**：奖励 **1 个 三阶铜匣**。
* **每 10 层（小 Boss）**：奖励 **1 个 四阶银匣**。
* **首杀 Boss**：奖励高一级的宝箱（如首杀 10 层，原本给 4 阶，首杀给 **5 阶金匣**）。
* **扫荡模式**：只产出 一阶木匣、二阶铁匣，绝对不产出高阶宝箱。

### 4. 探索奇遇

* 日常流水账中极小概率触发“古修遗府”事件，获得 **1 个 一阶或二阶宝匣**。
* *（探索定位为基础盘，高级箱子爆率极低）*

### 5. 镇守日常

* 封地建设、百艺炼制（后续开放）极小概率产出 **一阶木匣**。
* *（作为大本营的添头）*

### 6. 坊市购买与合成

* **灵石购买**：只能用灵石购买 **一阶、二阶** 宝匣（给灵石溢出的玩家一个消费口）。
* **宝匣合成**：5 个同阶宝匣合成 1 个高阶宝匣（最高只允许合成到 **四阶银匣**，五阶及以上必须靠硬核玩法获取）。

## 六、 特殊机制补充

* **联姻信物与事件联动**：六阶玉匣、七阶仙匣中，可开出【大宗嫡女联姻庚帖】、【仙朝立后信物】等特殊道具。玩家拿到信物后，会触发专属事件系统去迎娶女修，绝对不把人塞进箱子里。
* **寻宝值（MF）联动**：子嗣的“福缘深厚”词条、特定的丹药符箓、以及英烈祠的微弱Buff，都可以提供“寻宝值”，只影响开箱时的“成色判定（出白板还是出极品词条）”，不影响底材品阶。
