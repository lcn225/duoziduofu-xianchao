## 1. A 类：不定就没法开工

### A1. 药浴池先做「灵材库存」还是直接上池子（B4 前置）

**现状**

- P45 已定：建池后**浴桶关闭**，投入材料走**独立仓、不占背包、可随时取出反悔**；
  转换恒定 **1 件/小时 = 24 件/天**；存量上限 100 / 300 / 1,000 / 3,000 / 10,000；
  药力上限 ×1 / 1.5 / 2 / 3 / 4；某系到 cap 停吸，五系全满整体停止、材料留池。
- 但 P36 **第 8 步**还写着「依赖 dayLoop 轮次重构 + 灵材库存 / 锁定 / 二换一」——
  其中**品种锁**（背包锁 + 配方锁）与**二换一**都还是纸面。

**要定**

1. B4 一次做完「灵材库存 + 品种锁 + 药浴池」，还是先只做药浴池的独立仓？
2. 独立仓吃不吃的「品种锁」？（被锁的灵材不该被一键投入）
3. 一键投入的防呆顺序（先低阶、同阶先低成色、跳过装备中 / 品种锁 / 配方锁 / 出战灵宠）
   要不要在 B4 就做？

**建议**：B4 一次做完「独立仓 + 品种锁 + 一键投入」，**二换一推到 B11（百艺）**。
理由：二换一是「缺一系停摆」的兜底，只有五系都消耗起来才需要它。

**影响**：B4 的会话量（1 → 1.5）、灵材页 UI 改动、`verify-items` 新增断言。

**出处**

- 《下一步》P45 #2 / #5 / #6 / #8 / #9（`design/00-总览与状态/下一步.md`）
- 《下一步》P36 第 8 步（同文件）
- 《炼体药浴》§A.2 品种锁、§A 二换一（`design/20-系统设计/炼体药浴.md`）
- 《2026-10-26 日报》§十 B3 拍板表（药浴池不在 B3 范围）

### A2. 门派俸禄按原作量级还是按游戏量级（B8 前置）★最贵

**现状**

- **今天新补录的原作数据**：飞鹰门「八柱四将四相」一职一禄，全部为年俸 ——
  下柱 **10,000 二阶/年（≈833 二阶/月）**、将职 4,000、佐职 2,000、游击 1,000、
  世袭乡侯 1,000、长岭驿守兼任 350；桂冈身兼四职合计 **15,350 二阶/年（≈1,279 二阶/月）**。
- **游戏已定**：下柱 **6,000** / 中柱 **12,000** / 上柱 **18,000 大子/月**（1:2:3，锚点 = 开局俸禄）。
  汇率 100 大子 = 1 金页子、3.5 金页子 = 1 一阶、100 一阶 = 1 二阶 ⇒ 1 二阶 = **35,000 大子**。
- 所以游戏下柱 = **0.17 二阶/月**，比原作小约 **4,900 倍**；上柱 18,000 大子 = **0.51 二阶/月**，
  而一瓶回春丹要 **80~100 二阶** —— 攒十几年买一瓶。

**要定**

1. 保持「大子小额补贴」（门派俸禄永远不是收入主源），还是给门派阶段单开一套二阶俸禄？
2. 若保持：上柱一个月买不到一瓶回春丹，是不是预期？
3. 秘库 / 贡献点是否也按大子计价？（现在秘库是「贡献点」，还没接货币）

**建议**：**保持大子口径**，但把三档抬到 **10,000 / 20,000 / 30,000 大子/月**（上柱 = 3 金页子），
并重申《模块六》§1.3 的老约束「职位津贴不超过同期封地税收的 30%」仍然有效。
原作 15,350 二阶/年只作「宗门大兴期」的量级参考，不进常规经济。

**影响**：B8 三个会话的全部数值；《产出登记表》要新增一条 R 类；《模块五》§13.4 的职位阶梯表。

**出处**

- 《原作物价表》§3.1 宗门薪俸阶梯、§3.2 发饷与结算制度（`design/30-数据与决议/原作物价表.md`，2026-10-26 补录）
- 《模块六》§1.3「职位津贴：从主源降为辅源」（`design/10-模块设计/模块六-经济体系.md`）
- 《模块五》§13.4 职位与俸禄（`design/10-模块设计/模块五-任务战斗.md`）
- 《产出登记表》2026-10-26 行（`design/00-总览与状态/产出登记表.md`）

### A3. 后宅欠俸怎么算（B6，0.5 会话）

**现状**

- P51 #8 只写了「后宅欠俸→互动停摆，要红点 + 横幅」，**欠俸规则本身一个字都没定**。
- 今天刚把月饷按原文重排为（折大子）**12 / 24 / 50 / 100 / 300 / 1,000 / 1,400 / 3,500 / 10,500 / …**，
  P1 一个月只有 **12 大子**。
- P10+ 修仙侍妾的月饷**不进家族账**（按 2026-10-19 决议），欠俸对她们没有对象。

**要定**

1. 月结时余额不够发满：**按位阶从高到低发到没钱为止**，还是全员按比例发？
2. 停摆范围：所有侍妾，还是只停欠俸的那几位？互动次数减半还是清零？
3. 恢复条件：补发即恢复，还是要等下个游戏月？
4. P10+ 是豁免，还是按「个人收入」单独记账？

**建议**：月结**从高位阶往下发，发到没钱为止**；没拿到的**降一档互动权重（不清零）**；
下月补齐即恢复；P10+ 不进欠俸计算。理由：清零会让玩家一夜之间丢掉全部互动，
而降权重保留了「补钱能救回来」的动机。

**影响**：模块二互动与日结逻辑、四档通知（红点 + 横幅）、需要新增断言。

**出处**

- 《下一步》P51 #8（`design/00-总览与状态/下一步.md`）
- 《模块二》§2.1「后宅月饷重排（2026-10-26）」（`design/10-模块设计/模块二-多子多福.md`）
- 《数值真值表》§5.3 月饷与月钱（`design/00-总览与状态/数值真值表.md`）
- 《模块六》§五 侍妾月饷（P10+ 不进家族账的口径）
