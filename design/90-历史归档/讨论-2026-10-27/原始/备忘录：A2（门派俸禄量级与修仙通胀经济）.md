## 一、核心矛盾与设计哲学

### 1. 矛盾来源

- **原作数据**：桂冈兼职四职（下柱 10,000 二阶 + 大盾将 4,000 二阶 + 乡侯 1,000 二阶 + 驿站 350 二阶）年俸合计 **15,350 二阶/年**（约 1,279 二阶/月）。

- **原作物价极其畸形**：一阶下品丹药 50~150 二阶/颗，一阶下品飞剑 2,400 二阶，一张一阶上品保命符箓 800 二阶。桂冈两次大库支账就花掉 9,100 二阶，账上只剩 250 二阶。

- **结论**：原作并不是“高薪”，而是**“高薪高物价”**。桂冈拿到门派年俸后，购买力其实很有限。

### 2. 设计哲学

- **不要砍玩家的钱，而是给这笔钱找一个内部消耗池**。

- 玩家手里持有的“二阶灵石”确实很多，但**修仙界的高阶资源（丹药、法器、妖兽、稀有材料）也极其昂贵**。

- 最终形成：**赚得多 → 花得也多 → 逼玩家去肝任务/去跑商/去百艺**。

## 二、飞鹰门俸禄与消费闭环

### 1. 俸禄发放口径

- **足额发放二阶灵石**：按原作量级发放（下柱 10,000 二阶/年 ≈ 833 二阶/月），按月打进玩家账户。

- 兼职长岭驿守 350 二阶/年、世袭乡侯 1,000 二阶/年等，按剧情逐步解锁并叠加。

### 2. 修仙层物价表（锚点）

将原作物价并入游戏物价体系（真源：《原作物价表》扩展附录）：

| 品类 | 参考价（二阶灵石） |

|---|---|

| 一阶下品回血丹 | 50 / 颗 |

| 一阶下品回气丹 | 50 / 颗 |

| 一阶下品回春丹 | 80 / 颗 |

| 一阶下品生肌丹 | 150 / 颗 |

| 一阶下品解毒丹 | 200 / 颗 |

| 一阶上品保命符箓（如金钟罩） | 800 / 张 |

| 一阶下品飞剑 | 2,400 / 柄 |

| 四阶稀有材料（如暗金） | 120 / 两 |

**预期效果**：桂冈拿一个月俸（833 二阶），**买一把一阶下品飞剑就要吃掉近 3 个月的俸禄**。这与原作体验一致。

### 3. 大库支账（见票支账）

- 高阶妖兽、稀有法器、门派秘库物资，不直接放在坊市里摆卖。

- 必须走“老九大库”见票支账，或预留额度（如原作桂冈预留 5,000 二阶买乌鬣猪妖尾款）。

- 强制玩家在门派体系内做资金配置。

## 三、防通胀机制（超级溢价兑换）

### 1. 二阶灵石 → 贡献点（高价兑换）

- **汇率：10 二阶灵石 = 1 贡献点**（占位，待验算）。

- 理由：玩家一个月俸（833 二阶）最多换 83 贡献点，而一张筑基功法残页要 600 贡献点——**光靠俸禄不干活，攒大半年都换不到一张**。

- 逼玩家去做任务/肝百艺。

### 2. 二阶灵石 → 凡俗大子（限额 + 汇率差）

- 保留原有的“跨层兑换限额”（每天 100~300 金页子等）。

- 汇率带差价：低买高卖，逼迫玩家只在应急时兑换。

### 3. 高阶消耗品的消费端

- **百艺**：炼丹/炼器自己造，省下大钱，但要花时间（练功时间被挤压）。

- **坊市**：可买成品，但价格畸贵（按上表）。

- **子嗣开销**：高阶子嗣（筑基/结丹）的月钱全部用二阶灵石结算。

- 参考原设定：有灵根·筑基 5 二阶/月，有灵根·结丹 20 二阶/月，有灵根·元婴 100 二阶/月。

- 大量高阶子嗣的月钱支出，本身就是一笔巨额二阶开销。

## 四、后宫月例重新映射（P1~P6 凡女段）

### 1. 原作数据（引用）

- P1（死契丫鬟）：首月 8 大子，之后 12 大子/月。

- P3（叶梨儿）：50 大子/月 + 四季衣裳。

- P4（如夫人，如萧金桂）：1 金页子/月 + 独门独院 + 4 侍女。

- P6 及以上：原文查无明价。

### 2. 原作纳妾彩礼参考

- **迎娶冯珠儿（次相冯世俸庶女）**：88 二阶灵石 + 88 一阶灵石 + 88 金页子。

- **替四太保陈无恤垫付提亲彩礼**：388 二阶 + 388 一阶 + 388 金页子。

- **郑家人口中心大采购**：一次性买入 60 名女眷（2 嫡女 + 8 庶女 + 48 凡女），打包支付 **50 二阶灵石**。

- **飞鹰镇人牙采购**：32 名死契丫鬟 + 3 辆马车 + 马匹 + 打赏，消耗大量凡俗黄金（金页子）。

### 3. 当前游戏内月饷表（2026-10-26 重排）

折大子后：**12 / 24 / 50 / 100 / 300 / 1,000 / 1,400 / 3,500 / 10,500 / 35,000 / 175,000 / 1,750,000 / 17,500,000**（P1~P13）。

### 4. 待办事项

1. **P1~P6 凡女段月饷确认**：现表已按原作 P1/P3/P4 三档锁定（12/50/100 大子），但 P2 = 24 大子、P5 = 300 大子、P6 = 1,000 大子是拟值。**需要玩家最终确认这三档。**

2. **P4 及以上的月饷是否要引入“金页子/一阶/二阶”混合结算**：原文 P4 是“1 金页子”，P7 以上是“一阶”，P10 以上是“二阶”。
- 游戏货币 v2 目前是三字段（secular 大子 / spiritual 一阶 / strategic 四阶）。

- **待确认**：要不要拆成“大子支付 P1~P2、金页子（大子溢价）支付 P3~P6、一阶支付 P7~P9、二阶支付 P10+”。
3. **纳妾彩礼机制**：目前游戏里是“侍妾池 20 金页子/位”随机抽。原作是“88 二阶 + 88 一阶 + 88 金页子”这样的大额固定彩礼。
- **待确认**：要不要引入“定向纳妾彩礼”（如娶某位女修必须支付 X 二阶）机制，还是维持现在的“随机抽池”玩法。
