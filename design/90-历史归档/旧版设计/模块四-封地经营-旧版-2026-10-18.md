## 一、模块定位

封地经营是放置游戏的核心产出引擎。玩家离线时，封地自动生产资源；上线后，分配徭役、升级建筑、处理事件。

对应小说中桂冈的长岭乡：快子村、三王庄、张家庄、李家庄、长岭关、排骨山、炭场、长岭驿。

**核心循环**：封地自动产出 → 资源入库 → 升级建筑/分配徭役 → 提升产出 → 解锁新封地 → 获取更多资源。


- Lv.1：预警范围 10km
- Lv.2：预警范围 20km
- Lv.3：预警范围 30km，可提前 1 天预警

| 项目   | 所需徭役 | 工期   | 效果         |
| ---- | ---- | ---- | ---------- |

| 修建工坊 | 150  | 30 天 | 法器/符箓 +1/天 |

| 登仙大典 | 200  | 5 天  | 民心 +10     |

**徭役分配策略**：

- 徭役有限，玩家需决定优先级。
- 秋收期间徭役需求大，其他项目暂停。
- 张家庄徭役需额外消耗民心才能征召。
- 过度征召会降低民心，影响产出。

### 4.3 民心系统

```
民心 = 基础值 50 + 乡侯府等级 × 5 + 减税 + 示恩 - 过度征召 - 天灾
```

| 民心     | 等级  | 效果                |
| ------ | --- | ----------------- |
| 90-100 | 拥戴  | 产出 +20%，徭役效率 +20% |
| 70-89  | 安定  | 产出 +10%，徭役效率 +10% |
| 50-69  | 一般  | 无加成               |
| 30-49  | 不满  | 产出 -10%，徭役效率 -10% |
| 10-29  | 怨愤  | 产出 -20%，可能暴动      |
| 0-9    | 崩溃  | 产出 -50%，村庄逃亡      |

**民心变化**：

| 行为     | 变化  |
| ------ | --- |
| 减税     | +5  |
| 示恩（送粮） | +3  |
| 登仙大典   | +10 |
| 过度征召   | -5  |
| 天灾     | -10 |
| 妖兽入侵   | -5  |
| 子嗣陨落   | -3  |

## 五、资源产出

### 5.1 产出列表

| 资源    | 来源      | 用途       |
| ----- | ------- | -------- |
| 粮草    | 灵田、秋收   | 民心、徭役、军粮 |
| 灵谷    | 灵田      | 修行、迅风鸦饲料 |
| 灵草    | 药圃、排骨山  | 炼丹、炼器    |
| 银骨木炭  | 炭场      | 炼丹、炼器    |
| 一阶灵石  | 矿场      | 通用货币     |
| 二阶灵石  | 门派俸禄、商队 | 通用货币     |
| 金页子   | 税收、商队   | 凡俗货币     |
| 妖兽血肉  | 猎人山口    | 炼体、气血汤   |
| 情报    | 长岭驿、暗探  | 预警、任务    |
| 法器/符箓 | 工坊      | 战斗、派遣    |
| 门派贡献  | 门派任务    | 晋升、兑换    |

### 5.2 产出公式

```
产出 = 基础产出 × 建筑等级 × 民心系数 × 人口系数 × 子嗣加成
```

- 民心系数：民心/50（民心 100 时 ×2）
- 人口系数：当前人口/5000（人口 5000 时 ×1）
- 子嗣加成：有灵根子嗣提供 +5%/人，无灵根子嗣提供 +1%/人

### 5.3 离线产出

- 离线时，封地按上述公式自动产出。
- 离线效率 = 0.8 × 内宅稳定度系数。
- 上线时，汇总离线产出，弹出“封地报告”。

## 十、可玩性设计要点

1. **离线产出是核心爽点**：上线时看到封地报告，资源入库、事件发生。
2. **徭役分配是策略决策**：有限徭役如何分配，是优先建设还是优先秋收。
3. **建筑升级是长期目标**：每个建筑可升多级，消耗资源，提供递增收益。
4. **民心系统提供平衡**：过度征召降低民心，减税示恩提升民心。
5. **封地事件提供叙事**：妖兽入侵、萧家余孽、商队遇劫，需派遣子嗣处理。
6. **人口是灵根概率的基础**：无灵根子嗣婚配繁育，扩大人口基数。
7. **村庄差异化**：张家庄免税，李家庄分散，三王庄有亭卫，各有特点。
8. **长岭驿是情报中心**：驿站等级影响情报获取和商队收益。
9. **快子峰是修行核心**：木屋等级直接影响修行速度，是突破门槛的关键。
10. **封地扩张是长期追求**：乡侯府升级解锁封地扩张，获取更多村庄。
