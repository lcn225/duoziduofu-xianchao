一、核心结构

不新建物品池。直接改现有池子。

```

├── 灵宠池（Gacha.vue）→ 加 category/series/tier
```

2.4 同参

删除 FATE_ITEMS 独立表。

四个池子都有 `category` / `series` / `tier` 三个字段后，同参就是**从池子里筛**（细则见《同参系统》）：

```javascript
function getFateCandidates(fate) {
  return allItems.filter(item =>
    item.series === fate.series || item.category === fate.category
  );
}
```

⚠ 池子是**四个**不是三个：灵宠池（灵兽）、灵草池（灵草）、特殊装备（灵器）、**灵岩池（灵岩）**。
旧版漏了灵岩池 —— 但《灵气系统》§9.1 的 `category` 枚举里一直有它。灵岩当炼器材料，也能当同参。

三、亲和度动态计算

⚠ **本节已被《同参系统》取代** —— 档位从 4 档扩到 **6 档**（正主 1.0 / 准正主 0.8 / 同系列 0.6 / 近类型 0.4 / 同类型 0.25 / 无关 0.1）。以《同参系统》§3 为准，下面的旧 4 档仅留作对照：

```javascript
function calcFateAffinity(item, fate) {

if (item.id === fate.masterItemId) return 1.0; // 正主

if (item.series === fate.series) return 0.7; // 同系列

if (item.category === fate.category) return 0.4; // 同类型

return 0.15; // 无关

}
```
