# 模块五：任务战斗系统设计方案（简版）

## 一、模块定位

任务战斗系统是挂机系统，玩家不操作具体战斗，只负责**配置队伍、选择任务、派遣子嗣/门人**，然后等待结算。

对应小说中桂冈的巡查、清剿、护送、征战等任务，以及三才幡阵操演。

**核心循环**：接取任务 → 配置队伍 → 派遣 → 挂机等待 → 结算战报 → 获取奖励/损失。

## 三、队伍配置

### 3.1 队伍槽位

每次任务可派遣一支队伍，队伍最多 6 人：

| 槽位  | 职责      | 推荐          |
| --- | ------- | ----------- |
| 大盾将 | 防御，保护全队 | 桂冈、桂大（盾将词条） |
| 天幡将 | 阵法主攻    | 老三、桂二（剑修词条） |
| 地幡将 | 阵法辅助    | 老四、桂四       |
| 人幡将 | 阵法辅助    | 老八、桂六       |
| 游击将 | 输出/支援   | 老十、桂五       |
| 替补  | 随时递补    | 任意          |

### 3.2 配置规则

- 玩家从**自己、有灵根子嗣、可派遣门人**中选择。
- 每个角色有**战力评分**，由修为、炼体、功法、同参、词条决定。
- 队伍总战力 = 所有成员战力之和 × 阵型加成。
- 阵型加成：三才幡阵完整配置 +30%，大盾将+剑修 +15%，纯输出 +5%。

## 四、战斗结算

### 4.1 结算流程

1. 派遣后，任务进入**挂机计时**。
2. 到期后，系统自动结算。
3. 根据**队伍战力 vs 任务推荐战力**计算成功率。
4. 掷骰判定成功/失败。
5. 成功：获得全额奖励，队员获得经验。
6. 失败：获得部分奖励，队员可能受伤/陨落。
7. 生成**战报**，玩家上线后查看。

### 4.2 成功率公式

```
成功率 = 基础 50% 
       + (队伍战力 - 推荐战力) / 推荐战力 × 30%
       + 子嗣好感加成
       + 词条加成
       - 风险惩罚
```

**上限 95%，下限 5%。**

### 4.3 失败惩罚

| 失败程度 | 判定          | 后果          |
| ---- | ----------- | ----------- |
| 轻败   | 成功率差 10%以内  | 队员受伤，奖励减半   |
| 中败   | 成功率差 10-30% | 队员重伤，奖励 30% |
| 重败   | 成功率差 30%以上  | 队员陨落，无奖励    |

**队员陨落**：有灵根子嗣陨落触发修行返还；无灵根子嗣陨落不返还。

## 六、幡阵操演

### 6.1 操演机制

每年腊月，洪晃组织三才幡阵操演，决定来年军阵职务俸禄。

**操演流程**：

1. 洪晃指定幡阵配置。
2. 各队伍轮流操演。
3. 系统根据**配合度、战力、表现**评分。
4. 评分决定来年军阵俸禄等级。

### 6.2 操演评分

```
评分 = 队伍战力 / 推荐战力 × 60% 
     + 配合度 × 20% 
     + 随机发挥 × 20%
```

| 评分     | 等级  | 俸禄        |
| ------ | --- | --------- |
| 90-100 | 优   | 军阵俸禄 ×1.5 |
| 70-89  | 良   | 军阵俸禄 ×1.0 |
| 50-69  | 中   | 军阵俸禄 ×0.7 |
| 0-49   | 差   | 军阵俸禄 ×0.5 |

## 十、可玩性设计要点

1. **纯挂机，不操作战斗**：玩家只负责配置队伍和选择任务，战斗自动结算。
2. **队伍配置有策略**：三才幡阵完整配置 +30%，大盾将+剑修 +15%，需合理搭配。
3. **成功率可视化**：玩家可看到预计成功率，决定是否派遣。
4. **战报提供叙事**：每次任务生成战报，描述战斗过程，增强代入感。
5. **失败有惩罚**：队员可能受伤、陨落，有灵根子嗣陨落触发修行返还。
6. **幡阵操演是年度事件**：每年腊月操演，决定来年军阵俸禄。
7. **任务类型多样化**：巡查、清剿、护送、出使、执法、传功、征战。
8. **子嗣可培养**：通过任务获得经验，提升战力，成为长期资产。
9. **风险与收益并存**：高难度任务奖励丰厚，但失败可能损失子嗣。
10. **自动配置功能**：玩家可一键自动配置最优队伍，节省操作。
