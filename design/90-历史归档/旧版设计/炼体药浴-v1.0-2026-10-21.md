# 炼体药浴系统设计方案书 v1.0

> 2026-10-21 定稿。替代《日常循环》§二「炼体」的旧口径。

> 核心变更：炼体从「直接产进度」改为「药浴产药力 → 药力转进度」的双层结构。

> 灵材从「只进不出」变成有最终回收口。

---

## 一、核心定位

炼体不再只是一个消耗体力的动作，而是**灵材的最终回收口**。

```
灵材 → 药浴 → 五系药力 → 吸收 → 炼体修为
```

- 灵材从探索/子嗣历练/秘境/宝箱产出，堆积在背包。

- 药浴每天消耗灵材，产出五系药力。

- 吸收将药力转为炼体修为。

- **五系只决定「能不能炼」，不卡突破**（暂不设晋级门槛）。

---

## 二、时间与结算

| 项 | 值 |

|---|---|

| 1 炼体轮 | 1 游戏小时 = **4 现实秒** |

| 一天炼体 | 5 轮 = **20 现实秒** |

| 结算频率 | **每秒 tick**，两条流独立并行 |

| 产气频率 | **每轮最多 1 次**（4 秒内最多消耗 N 件） |

本条应参考打坐修炼结算方式，两边尽量对齐

---

## 三、五系药力

### 3.1 五系

| 系 | 来源灵材 `fateElement` |

|---|---|

| 金气 | `metal` |

| 木气 | `wood` |

| 水气 | `water` |

| 火气 | `fire` |

| 土气 | `earth` |

**器（`vessel`）/ 兽（`beast`）灵材不产气**，只能分解/合成。

### 3.2 参数

| 参数 | 含义 | 状态 |

|---|---|---|

| `floor(L)` | 下限 = 每次吸收五系各扣的量 | 真值表算，与轮数脱钩，参考打坐 |

| `cap(L)` | 上限，超了不能产气 | 真值表算，`cap > floor` |

| `gain(L)` | 吸收一次得多少炼体修为 | 真值表算，`= 现有日产出 / 20`（满药力时） |

| `yield(tier)` | 单件材料产多少药力；**再乘成色系数（下/中/上/极）** | 真值表算 |

| `N` | 每次产气消耗几件 | **暂定 1**，可调（大药缸升级） |

### 3.3 约束

```
cap > floor

yield × N ≈ 4.8 × floor // 速率比 1.2，产气略快于吸收（2026-10-21 订正：原写 24）

gain × 20 ≈ 现有炼体日产出 // 满药力时维持曲线
```

**为什么是 4.8 不是 24（2026-10-21 定）**

- 吸收：每秒 1 次，一天 5 轮 × 4 现实秒 = **20 次/天**。
- 产气：每秒判定，但**每轮最多 N 件（N=1）** → **5 件/天**。
- 每件要供 20 ÷ 5 = 4 次吸收，再乘 1.2 余量 → **`yield ≈ 4.8 × floor`**。
- 原稿的 24 是按「一天 24 次产气」推的，与「每轮 1 件」矛盾，作废。

**甲 / 乙 两档（当前选甲）**

| 档 | 产气频率 | 消耗 | yield | 适用 |
|---|---|---|---:|---|
| **甲（当前）** | 每轮 1 件 | 5 件/天 | **4.8 × floor** | 材料消耗慢、背包压力小 |
| 乙（未来） | 每秒 1 件 | 20 件/天 | **1.2 × floor** | floor 提高后，需要大量烧低级灵材时切换 |

设计目的：**让堆积的低级灵材有去处，填补炼体的大缺口**。
切到乙的时机 = 真值表验算发现「floor 涨得比材料产出快、甲供不上」时，用 `N` 或频率调，不用改结构。

## 四、炼体环节流程

```
炼体环节（1h/轮，一天 5 轮），每秒 tick：

┌─ 吸收流（每秒）──────────────────────────┐

│ 五系药力都 ≥ floor？ │

│ ├── 是 → 五系各扣 floor，得 gain 炼体修为，播打桩 │

│ └── 否 → 本 tick 不吸收 │

└──────────────────────────────────────────┘

┌─ 产气流（每轮最多 1 次）──────────────────┐

│ 本轮还没产过气，且存在某系 < cap，且有该系未锁定材料？ │

│ ├── 是 → 消耗 N 件该系材料，该系 += yield × N，播药浴 │

│ └── 否 → 不产气 │

└──────────────────────────────────────────┘

两条流独立并行，互不阻塞。

停止条件：

① 五系都 ≥ cap → 只吸收不产气（吸收扣到 < cap 后自动恢复产气）

② 五系不都 ≥ floor，且所有 < cap 的系都没材料 → 停止炼体

③ 两者都不满足 → 正常循环
```

**动画**：药浴、打桩每轮依次循环播放，不影响结算。

## 五、药力池状态

| 状态 | 含义 | 表现 |

|---|---|---|

| **可吸收** | 五系都 ≥ floor | 打桩动画，炼体修为增长 |

| **可产气** | 某系 < cap 且有材料 | 药浴动画，药力增长 |

| **满溢** | 五系都 ≥ cap | 只打桩，不药浴 |

| **枯竭** | 五系不都 ≥ floor，且无材料 | 停止炼体 |

| **正常循环** | 部分可吸收、部分可产气 | 两动画交替 |

**跨天保留**：五系药力是持久资源，睡觉/换日**不清零**。
**展示**：放在主界面「炼体环节」旁边，按五行显示当前药力 / cap 的进度条。
**枯竭时**：本轮炼体**直接跳过**，不原地空转、不继续扣体力。

## 六、灵材锁定

### 6.1 两种锁法，统一为「品种锁」

| 锁法 | 触发 |

|---|---|

| **配方锁** | 炼器/炼丹配方需要的灵材品种，自动锁定 |

| **背包锁** | 玩家在背包页面手动锁定某品种 |

### 6.2 判断逻辑

- 锁是**品种级**（`series + tier`），不是单件级。

- 药浴时，可用材料 = 该系未锁定的材料。

- 某系全部锁定 → 该系「无可用材料」，跳过。

### 6.3 UI

- 背包灵材页每行一个锁图标，点击切换。

- 锁定的品种在药浴/分解/合成时灰显或标注「已锁」。

## 七、灵材整理工具（配套）

### 7.1 五合一升级

```
5 件同 category + 同 series + 同 tier → 1 件同 series + tier+1
```

### 7.2 同级定向二换一

```
2 件同 tier 任意灵材 → 1 件同 tier 指定灵材
```

- 不限 series，任意换任意。

- 用于凑五系或凑配方材料。

- **成色规则（2026-10-21 定）**：五合一 / 二换一**都无视成色**，产物成色**随机**（按物品池成色权重）。
  例：5 件「下品」也可能合出「极」；2 件任意成色换 1 件指定品种，成色重掷。

### 7.3 与药浴的分工

| 工具 | 定位 |

|---|---|

| 五合一 | 把低阶散料攒成高阶 |

| 二换一 | 把不要的换成要的 |

| **药浴** | **最终消耗口，灵材真正消失** |

## 八、与现有系统的关系

| 系统 | 影响 |

|---|---|

| **日常循环** | 炼体环节内部重构，队列不变（1h/轮） |

| **体力** | 炼体仍耗体力 15/h，不变 |

| **炼体修为** | 产出路径变为「药力 → 修为」，总量维持现有曲线 |

| **灵材** | 新增消耗口，品种级锁定 |

| **炼器** | 也消耗灵材（P15.8 灵岩系统），与炼体抢材料 |

| **晋级** | 暂不设五系门槛，炼体晋级只看炼体进度 |

| **产出登记表** | 灵材从「只进不出」变成有消耗口，需登记 |

## 九、真值表待算参数

| # | 参数 | 约束 |

|---|---|---|

| 1 | `floor(L)` | 每次吸收五系各扣的量，随境界增长 |

| 2 | `cap(L)` | `cap > floor`，随境界增长 |

| 3 | `gain(L)` | `= 现有炼体日产出 / 20`（满药力时） |

| 4 | `yield(tier)` | `yield × N ≈ 24 × floor` |

| 5 | `N` | 暂定 1，可调 |

**反推链条**：

```
① 定现有炼体日产出（5 轮 × 每轮进度）

② gain = 日产出 / 20

③ 定 floor（参考打坐的转化率递减）

④ 定 cap = k × floor（k 待定，建议 3~5）

⑤ 定 yield(tier) = 4.8 × floor / N（N=1 时；甲方案，见 §3.3）

⑥ 按 tier 递增分配 yield
```

## 十一、与旧口径的差异

| 项 | 旧 | 新 |

|---|---|---|

| 炼体产出 | 直接产进度 | 药浴产药力 → 吸收转进度 |

| 灵材消耗 | 无 | 药浴消耗（最终回收口） |

| 五系 | 无 | 五系药力池，各有上下限 |

| 晋级 | 只看进度 | 暂不设五系门槛 |

| 灵材锁定 | 无 | 品种级锁（配方锁 + 背包锁） |

| 灵材整理 | 无 | 五合一 + 二换一 |
