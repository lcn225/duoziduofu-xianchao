# 灵气系统 — 完整设计文档（最终版）

> **本版取代此前那份「四维契合度」版本。** 主要变化：**本命契合整维删除**（四维 → 三维），同参权重 0.30 → 0.50，灵地 0.20 → 0.35；新增「本命品阶」并让它封顶同参契合；门槛下调（练气九层 70→68%、筑基 80→71%）。
>
> 上一版把「本命契合」做成了一维，但它其实随境界自动上涨（练气 75% → 筑基自动满值），玩家经营不了、白送 26 个点。删掉它之后，**开局过不去练气三层**，第一道门槛才真正开始筛选。

## 一、本命

### 1.1 核心规则

| 规则 | 说明 |
|---|---|
| 本命决定灵根 | 灵根只是本命的属性体现 |
| 本命天生固定 | 后天不可更改 |
| 本命可以有多个 | 数量越多，修炼越慢 |
| 本命可以多属性 | 如石中水 = 水+土 |
| **本命有品阶** | 决定同参契合上限 |

### 1.2 本命与灵根对应

| 本命类型 | 灵根 |
|---|---|
| 草/木/花 | 木灵根 |
| 灵兽/妖兽 | 兽灵根 |
| 器物/法器 | 器灵根 |
| 火/炎/焰 | 火灵根 |
| 水/冰/液 | 水灵根 |
| 土/石/山 | 土灵根 |
| 金/铁/矿 | 金灵根 |
| 混合（如石中水） | 多灵根 |

**注**：武器是器灵根，不是金灵根。

## 四、三维契合度

### 4.1 公式

```
综合契合度 = 功法 × 0.15 + 同参 × 0.50 + 灵地 × 0.35
```

| 维度 | 权重 | 理由 |
|---|---|---|
| 同参 | **50%** | 辅助本命修炼，最重要 |
| 灵地 | **35%** | 修行环境 |
| 功法 | **15%** | 修行法门 |

**换同参效果 = 换功法的 2~3 倍。**

### 4.2 功法契合

```
功法契合 = 品阶分 + 灵根匹配分 + 熟练度
```

| 项目 | 分值 |
|---|---|
| 品阶分 | 练气篇 20% / 筑基级 30% / 金丹级 40% |
| 灵根匹配分 | 完全匹配 40% / 部分匹配 20% / 不匹配 0% |
| 熟练度 | 每 100 游戏小时 +1%，上限 20% |

**功法契合上限**：

| 品阶 | 不匹配 | 部分匹配 | 完全匹配 |
|---|---|---|---|
| 练气篇 | 40% | 60% | 80% |
| 筑基级 | 50% | 70% | 90% |
| 金丹级 | 60% | 80% | 100% |

**灵根匹配分 = 40% × 覆盖率**，覆盖率 = 功法灵气覆盖了修士多少比例的灵气（分母是**修士**）。

| 修士灵气 | 功法灵气 | 覆盖率 | 匹配分 | 档位 |
|---|---|---|---|---|
| 兽+器 | 兽+器 | 100% | 40% | 完全匹配 |
| 兽+器 | 兽 | 50% | 20% | 部分匹配 |
| 兽+器 | 火 | 0% | 0% | 不匹配 |
| 兽+器+木 | 兽 | 33% | 13.3% | 无对应档位 |

三档表是按**双本命**预计算的示例；实现时用 `40% × 覆盖率` 公式，三本命及以上的覆盖率也能自动成立。

### 4.3 同参契合

```
同参契合 = 接近度系数 × min(同参品阶系数, 本命品阶系数)
```

| 接近度 | 系数 |
|---|---|
| 正主 | 1.0 |
| 同系列替代 | 0.7 |
| 同类型替代 | 0.4 |
| 无关 | 0.15 |

**品阶系数**：

| 品阶 | 系数 |
|---|---|
| 不入品 | 0.20 |
| 一阶下品 | 0.30 |
| 一阶中品 | 0.35 |
| 一阶上品 | 0.40 |
| 二阶 | 0.55 |
| 三阶 | 0.75 |
| 四阶 | 1.00 |

**核心规则**：本命品阶决定同参契合上限。同参品阶超过本命品阶时，按本命品阶算。

**示例**：

| 场景 | 接近度 | 同参品阶 | 本命品阶 | min | 同参契合 |
|---|---|---|---|---|---|
| 不入品本命 + 不入品正主 | 1.0 | 0.20 | 0.20 | 0.20 | **20%** |
| 不入品本命 + 四阶同系列 | 0.7 | 1.00 | 0.20 | 0.20 | **14%** |
| 四阶本命 + 四阶正主 | 1.0 | 1.00 | 1.00 | 1.00 | **100%** |
| 四阶本命 + 不入品同系列 | 0.7 | 0.20 | 1.00 | 0.20 | **14%** |

> 上表前两行与第四行的原标注是「一阶本命 / 一阶同系列」，但取值用的是 **0.20**，那是「不入品」的系数（一阶下品是 0.30）。已按取值改标为「不入品」。若原意是「一阶下品」，请把 0.20 一并改成 0.30。

### 4.4 灵地契合

```
灵地契合 = 匹配百分比（0%~100%）
```

与 §3.4 同。

## 五、修炼速度公式

```
灵力/秒 = 灵地基础产出 
        × (0.7 + 综合契合度 × 0.6)
        × spiritRate
        × 本命数量系数
        × 行功带宽
        × (1 + 子嗣修炼加成)
```

| 系数 | 说明 |
|---|---|
| 灵地基础产出 | 由灵地等级决定 |
| 综合契合度 | 三维加权（0%~100%） |
| spiritRate | 每次内功突破 ×1.2 |
| 本命数量系数 | 单本命 1.0 / 双本命单灵根 0.9 / 双本命双灵根 0.8 / 三本命 0.7 / 三本命以上 0.6 |
| 行功带宽 | 散功重修扩展 |
| 子嗣修炼加成 | 上限 +200% |

**即使 0% 契合，也有 0.7 倍保底。**

> **契合度是门票，不是收益引擎**：0% → 100% 只把速度从 0.70× 拉到 1.30×。真正驱动挂机收益的是 spiritRate、子嗣和行功带宽。
> 上表的本命数量系数补齐了 §1.3 的五档（原文只列了三档）。

|---|---|

### 7.4 设计目标 vs 本批实际路径

上表假设**兽/器功法已经拿到手**，而它们在本批里还没有获取途径（属模块四/五）。所以第一道门槛的实际解法不同：

| | 功法契合 | 综合 | 三层 55% |
|---|---|---|---|
| 桂氏气血经（开局默认，练气篇·不匹配） | 20% | 50.25% | ❌ 差 4.75pt |
| 吕氏练气次第论（练气篇·不匹配） | 20% | 50.25% | ❌ 差 4.75pt |
| **元氏修命经（金丹级·不匹配）** | **40%** | **53.25%** | ❌ 差 1.75pt |
| 元氏修命经 + 熟练度 12% | 52% | **55.05%** | ✅ |

**即：换到元氏修命经把功法品阶分从 20% 顶到 40%（综合 +3 个点），再把熟练度养到 12%（1200 游戏小时 ≈ 20 现实分钟）就过。**

熟练度阈值可以反解：要过 55%，功法契合需 ≥ `(0.55 - 0.245×0.50 - 1.00×0.35) / 0.15 = 51.67%`，元氏修命经打底 40%，还差 11.67% = 1167 游戏小时。

> ⚠ **这不是「点击就过」**，是「换功法 + 养一段时间」。因为三本开局功法**都不匹配**（覆盖率 0），唯一能拉开差距的只有品阶分。等兽/器功法接进来后，§7.2 那条 56.25% 的一步到位路径才成立。

## 十、关键设计原则

| 原则 | 说明 |
|---|---|
| 本命是根本 | 决定灵根，决定同参上限 |
| 本命品阶决定上限 | 一阶本命同参契合上限 20%，四阶本命 100% |
| 同参辅助本命 | 权重 50%，比功法更重要 |
| 灵地是环境 | 权重 35%，影响速度和门槛 |
| 功法是法门 | 权重 15%，权重最低 |
| 换同参 > 换功法 | 同参效果是功法的 2~3 倍 |
| 不契合也能修炼 | 0% 契合有 0.7 倍保底 |
| 灵地等级只影响速度和门槛 | 不影响契合度 |
| 灵地单属性为主 | 少数混合 |
| 功法与灵根强相关 | 完全匹配 +40% |
| 门槛引导配置优化 | 每次突破都是一次检查 |
