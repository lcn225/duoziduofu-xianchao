> 本份覆盖 2026-11-02 讨论的封地建设模块重构。**框架已定，数值与执行细节交开发组。**
> 标 **交开发组** 的是框架已定、具体数值/顺序待定的；标 **待确认** 的是讨论中遗漏、需要补的。

---

## 一、总体定位

封地是**「功能解锁 + 长期经营」模块**，不是「投资回本」模块。账面回本不重要，玩家投钱是因为解锁了新玩法。

**经营模拟深度 = L1（单层中间产物）**，实际体验后可往 L2 扩展。

## 七、藏书阁

| 项      | 结论                        |
| ------ | ------------------------- |
| 藏书范围   | **桂冈已学的功法**               |
| 效果给谁   | **子嗣自己**（子嗣变强）            |
| 每子嗣学几门 | **只 1 门，不可替换**            |
| 随机池    | **只从匹配的功法里抽**（按灵根）        |
| 没匹配    | **不学，不兜底**                |
| 抽到弱的   | 接受（锦上添花，不是核心）             |
| 触发时机   | **落成时一次 + 之后每个子嗣到筑基时也触发** |

**已知风险**：桂冈开局只有 3 本（火/土/金），木/水/兽/器灵根的子嗣暂时抽不到。等桂冈学了更多功法后自然缓解。
