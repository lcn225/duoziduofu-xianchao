## A 类：不定就没法开工

### A1. B8-b 的第一刀：封地建设按「境界段」还是按「建筑等级」重标？

**现状**

- 封地是**一条连续的建筑线**，初始成本（二阶）：

  | 目标等级 | 基础成本（二阶） | 当前定位 |
  |---|---:|---|
  | Lv1 | **0**（首建） | 练气期 |
  | Lv2 | **40** | 练气期 |
  | Lv3 | **500** | 扩张 |
  | Lv4 | **1,500** | 扩张后期 |
  | Lv5 | **10,000** | 仙朝 |

  四栋建筑各自乘 `weight`（乡侯府 / 灵田 / 鸦巢舍 / 亭卫），当前总价 = Lv2 40、Lv3 500、Lv4 1,500、Lv5 10,000 量级。
- 新收入基准（B8-a 之后）：**下柱现银 83 二阶 30 一阶/月**（10%），挂账 749.7 二阶/月
  **只能花在秘库**；贡献点 690/月。练气期探索约 5~6 二阶/月（练气一图 17.6 一阶/游戏天）。
- 宝匣已按「三阶 = 2.5 三阶」重标到 148/444/2,000/7,200/23,040 二阶（§十五）。

**要定的分叉**

1. 「物价按境界段定价」在封地上怎么落：
   **甲的等级 ↔ 境界段**，还是**同一等级对所有段同价**？
2. 如果按段：Lv1~Lv5 分别归到哪一段？建议 **L1 练气初期 / L2 练气后期 / L3 筑基 / L4 金丹 / L5 仙朝（未落地）**。
3. 定价比例用「**整段总成本 = 该段 2~3 个月可支配收入**」还是「每次升级 ≤ 1 个月收入」？

**建议**

- 按 **建筑等级 ↔ 境界段**（否则同一栋楼在练气和金丹两个价，玩家看不懂）。
- 每级成本 = **该段 2~3 个月「可自由支配收入」**，可自由支配 = **俸禄现银 + 探索/秘境**
  （**不含挂账**，挂账只能买秘库）。
- 练气段：Lv2 40 二阶 ≈ 0.4 个月现银，**太便宜**；建议抬到 **150~250 二阶**（2~3 个月）。
  Lv3 归筑基后，则现值 500 二阶相对筑基段收入偏低，同批再算。

**影响**

- 代码：`plugins/estate.js`（`ESTATE_TUNING` 成本表）· 断言 `verify-estate`。
- 会话量：**1 会话**（定价 + 改表 + 断言）。
- 产出登记：**S 类新记录**（回收口金额变化，不是产出增减）。

**出处**

- [《模块六》§1.3](../../10-模块设计/模块六-经济体系.md)（定价方法四条）
- [《模块四》§十](../../10-模块设计/模块四-封地经营.md)（建设成本口径）
- [《下一步》B8 剩余](../../00-总览与状态/下一步.md) · 日报 §十五 / §十六

## B 类：开工前一周定

### B1. 一 / 二阶宝匣要不要按新俸禄重标？

**现状**

- 一阶 **148 二阶**、二阶 **444 二阶** 是**倒推值**（三阶 ÷4.5、÷3），没有练气段实测锚点。
- 用户 2026-11-01 原话：「练气段整段收入远低于筑基段，14,800 一阶一个一阶匣……
  不太可能，**等俸禄发下来就够了**。买不起就打秘境，好说。**之后再算吧**。」
- 现在俸禄已发（下柱 83 二阶现银/月），可以先观察一局。

**要定的分叉**

- 一 / 二阶匣维持 148 / 444，还是按「练气段整段现银收入 ÷ 50」重算？

**建议**

- **先维持**，等玩家实际跑一个练气段再定；若实测「整段买不起 10 个」，再按段收入 ÷50 下修。

**影响**

- 纯数值，`shop.js` 两行 + 断言两条；**无代码结构改动**。

**出处**

- 日报 §十五「遗留」#1 · [《模块五》§13.4.1](../../10-模块设计/模块五-任务战斗.md)

### B2. 大库页面（丹药 / 法器 / 符箓 / 灵兽）的形态

**现状**

- 挂账 90% 目前只能买秘库两栏（心法 + 同参底材），**买不到丹药 / 法器 / 符箓 / 灵兽**。
- 原作机制 = 「见票支账」，凭信单到大库按**宗门内部优惠价**淘换（《原作物价表》§3.2）。

**要定的分叉**

1. 大库是**飞鹰门页里的一个分区**，还是独立页？
2. 结算用**挂账额度**，还是「挂账 + 贡献点」双币？
3. 「内部优惠价」= 挂账购买力打几折？（秘库已定 1 二阶 = 1 贡献点）
4. 货架是全品类常驻，还是像秘库一样月刷？

**建议**

- 先做成**飞鹰门页的分区**（不新增导航）；**只收挂账**；**1 二阶 = 1 点，不再打折**（与秘库一致）；
  常驻货架、不月刷（大库是「稳定补给」，不是抽卡）。

**影响**

- 会话量：**1~1.5 会话**（新分区 + 价格表 + 结算）。
- 断言：新增 `verify-faction` 大库段。

**出处**

- 《原作物价表》§3.2 / §3.3 · 日报 §十五「遗留」#3
