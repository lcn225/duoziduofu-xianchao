## 一、底层数据挂载口径

不修改现有的 `newOffspring` 数据结构，直接利用现有字段：

1. **挂载核心**：由于子孙采用 Y 染判定（只看男系），家族树本质上是一棵**父系树**。
   - 子嗣通过 `fatherId` 挂载到生父节点下。
   - 孙辈及以上，直接找父亲的 id 即可。
2. **生母展示**：
   - 不为儿媳（配偶）生成独立的全局 ID。
   - 孙辈的 `motherId` 留空，仅存 `motherName`（如"张氏"），作为文本标签展示在节点旁。
3. **侍妾节点**：
   - 第一代子嗣通过 `motherId` 挂载到对应的侍妾节点下。
   - 侍妾若已老死（80岁），节点保留（打上灰色/已故标记），其子嗣分支不因侍妾死亡而断裂。

## 二、游戏内 UI：方案 2（纵向缩进树）

为保证在 600+ 子嗣、默认全展开的情况下手机端不卡顿，游戏内只做极简族谱。

### 1. 形态

采用纵向缩进的树形列表：

```text
▾ 桂冈
  ▾ 萧金桂 [已故]
    ▾ 桂大（练气五层） [母：萧金桂]
      ▾ 桂小一（凡人） [母：张氏]
      ▾ 桂小二（练气二层） [母：张氏]
    · 桂三（已外嫁） [母：萧金桂]
  ▾ 丁赛喜
    ▾ 桂四（练气三层） [母：丁赛喜]
```

### 2. 节点与样式

- **玩家（桂冈）**：固定在树的最顶端，主干起点。
- **侍妾**：第二层级。存活为正常色，已故显示 ✝ 且变灰。
- **子嗣**：
  - 旁注 `[母：xxx]`。
  - 儿子若娶妻，节点带 `▾` 可展开/折叠下一层。
  - 女儿外嫁：标记 💍，作为叶子节点，无下一层。
  - 陨落子嗣：标记 ✝ 变灰。
- **性能**：使用 Vue 递归组件 + 虚拟滚动（Virtual Scroll），只渲染视口内的节点。

## 三、独立导出器：方案 1（小震撼族谱）

因为游戏内画"侍妾发散连线图"在手机上绝对会横向爆炸，所以把重资产的功能移到游戏外。

### 1. 玩法流程

玩家在游戏内点击【导出族谱】按钮，下载一个 `clan_tree.json` 文件。玩家将该文件拖入一个**独立的纯静态网页（族谱生成器）**，网页会调用 ECharts / D3.js 生成极其宏大的树状图。

### 2. 外部网页的视觉表现

- **发散式连线**：以桂冈为圆心（或顶冠），侍妾向两侧发散，子嗣顺延连线。
- **节点高亮**：单灵根子嗣发光，极品本命带专属边框，凡人灰显。
- **一键截图**：提供【导出超清长图】按钮，方便玩家分享到贴吧/群聊。

### 3. 游戏内导出代码逻辑

```javascript
function exportClanTree(rootData) {
  const jsonStr = JSON.stringify(rootData, null, 2);
  const blob = new Blob([jsonStr], { type: 'application/json' });
  const url = URL.createObjectURL(blob);

  const a = document.createElement('a');
  a.href = url;
  a.download = `桂冈家族谱.json`;
  a.click();
  URL.revokeObjectURL(url);
}
```

## 五、开发落地步骤

1. **第一步（纯函数）**：开发写 `buildFamilyTree` 将子嗣和侍妾组装成树形结构。对于找不到母亲的第一代老档子嗣，统一挂在一个"旁系/失传"虚拟节点下兜底。
2. **第二步（游戏内 UI）**：使用 Vue 递归组件渲染缩进树，加上虚拟滚动。
3. **第三步（导出功能）**：加个按钮下载 JSON 文件。
4. **第四步（外部工具）**：单独写一个 HTML 文件挂 ECharts，实现炫酷图表。
