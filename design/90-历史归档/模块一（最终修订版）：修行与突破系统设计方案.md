# 模块一（最终修订版）：修行与突破系统设计方案

## 一、核心机制确认

修行系统的核心是两条线并行：

**速度线**：四维契合度决定修炼速度，契合度越高，灵力积累越快。

**门槛线**：只有五个节点有契合度硬性要求，其余小境界只需灵力池满即可挂机突破。

| 节点      | 类型  | 契合度要求 | 说明          |
| ------- | --- | ----- | ----------- |
| 练气二层→三层 | 第一槛 | 20%   | 需土系灵地+本命物契合 |
| 练气三层→四层 | 普通  | 无     | 挂机即可        |
| 练气四层→五层 | 普通  | 无     | 挂机即可        |
| 练气五层→六层 | 第二槛 | 50%   | 需水系灵地+散功风险  |
| 练气六层→七层 | 普通  | 无     | 挂机即可        |
| 练气七层→八层 | 普通  | 无     | 挂机即可        |
| 练气八层→九层 | 第三槛 | 75%   | 需火系灵地+子嗣加成  |
| 练气九层→十层 | 普通  | 无     | 挂机即可        |
| 练气十层→筑基 | 筑基  | 80%+  | 筑基门槛        |
| 筑基→结丹   | 结丹  | 100%  | 结丹门槛        |

## 二、四维契合度模型

### 2.1 综合契合度

```
综合契合度 = (功法契合 + 同参契合 + 灵地契合 + 本命契合) / 4
```

每个子契合度范围 0–100%，综合契合度也是 0–100%。

### 2.2 修炼速度公式

```
修炼速度 = 基础速率 × (0.5 + 综合契合度 × 1.5) × 子嗣加成 × 其他加成
```

- 综合契合度 0% 时，速度只有基础的一半。
- 综合契合度 50% 时，速度等于基础。
- 综合契合度 100% 时，速度是基础的两倍。

**关键**：速度只影响挂机效率，不影响能否突破普通小境界。普通小境界只看灵力池是否满。

### 2.3 突破规则

**普通小境界**（三、四、六、七、九、十层）：

- 灵力池满 → 自动或手动突破 → 成功。
- 无契合度要求，无失败风险。
- 纯粹挂机积累。

**门槛节点**（第一槛、第二槛、第三槛、筑基、结丹）：

- 灵力池满 + 综合契合度达标 → 可冲击。
- 契合度不足时，按钮置灰，提示“契合度不足，需 XX%”。
- 突破有失败风险，失败后灵力清零，契合度暂时 -10%。

## 三、四个维度的详细设计

### 3.1 功法契合

**功法属性**：每本功法有五行属性（金木水火土）和行功特色。

| 功法       | 五行  | 行功特色      | 与本命匹配        |
| -------- | --- | --------- | ------------ |
| 桂氏气血经练气篇 | 火   | 气血搬运，刚猛直进 | 刃背乌鬣猪（火属）→ 高 |
| 吕氏练气次第论  | 土   | 居中守土，次第生长 | 饕餮纹玉牌（土属）→ 中 |
| 元氏修命经    | 金   | 修命铸骨，金锐之气 | 刃背乌鬣猪（火属）→ 低 |

**功法契合度计算**：

```
功法契合 = 基础匹配分 + 功法等级 × 2% + 功法熟练度 × 1%
```

- 基础匹配分：功法五行与本命五行的匹配度，相生 +40%，相同 +30%，相克 -10%。
- 功法等级：每升一层 +2%。
- 功法熟练度：使用该功法修行的时间累积，每 100 小时 +1%，上限 20%。

**功法升级**：

- 消耗灵石 + 时间 + 对应五行灵物。
- 每层提升功法契合度 +2%，同时解锁新的行功路线。
- 练气期功法最高十层。

### 3.2 同参契合

**同参定义**：与本命对应的实体物事，包括法器、灵宠、玉牌、飞剑等。

**同参列表**（桂冈可拥有）：

| 同参           | 类型  | 五行  | 品质   | 与本命匹配      |
| ------------ | --- | --- | ---- | ---------- |
| 饕餮纹风磨铜镶青金石玉盾 | 法器  | 土   | 一阶中品 | 饕餮纹玉牌 → 高  |
| 青玉剑          | 飞剑  | 木   | 一阶下品 | 饕餮纹玉牌 → 中  |
| 精钢刺          | 飞剑  | 金   | 一阶下品 | 刃背乌鬣猪 → 低  |
| 乌鬣猪妖         | 灵宠  | 火   | 一阶   | 刃背乌鬣猪 → 极高 |
| 灵藤木盾         | 法器  | 木   | 不入品  | 饕餮纹玉牌 → 中  |

**同参契合度计算**：

```
同参契合 = 基础匹配分 + 同参等级 × 3% + 祭炼程度 × 2%
```

- 基础匹配分：同参五行与本命五行的匹配度，相生 +50%，相同 +40%，相克 -20%。
- 同参等级：每升一级 +3%。
- 祭炼程度：用灵力祭炼同参的累积时间，每 50 小时 +2%，上限 20%。

**同参升级**：

- 消耗灵石 + 材料 + 时间。
- 每级提升同参契合度 +3%，同时提升同参本身效果。
- 同参可突破品阶，需要稀有材料。

**同参切换**：

- 玩家可同时携带多件同参，但只有**主同参**参与契合度计算。
- 主同参可随时切换，但切换后祭炼程度保留 50%。

### 3.3 灵地契合

**灵地属性**：每块灵地有五行属性和等级。

| 灵地      | 等级   | 五行  | 功法契合    | 本命契合     |
| ------- | ---- | --- | ------- | -------- |
| 飞鹰镇外村庄  | 一阶下品 | 土   | 吕氏 +20% | 玉牌 +20%  |
| 快子峰顶木屋  | 一阶中品 | 金   | 桂氏 +10% | 乌鬣猪 +5%  |
| 萧家山门半山腰 | 一阶上品 | 水   | 吕氏 +10% | 玉牌 +10%  |
| 飞鹰山顶洞府  | 二阶下品 | 火   | 桂氏 +30% | 乌鬣猪 +30% |
| 洪晃石室    | 二阶中品 | 土   | 吕氏 +40% | 玉牌 +40%  |
| 郑家山门核心  | 三阶   | 木   | 元氏 +50% | 玉牌 +20%  |

**灵地契合度计算**：

```
灵地契合 = 灵地等级系数 × 五行匹配系数 × 100%
```

- 灵地等级系数：一阶下品 0.5，一阶中品 0.7，一阶上品 0.9，二阶下品 1.0，二阶中品 1.2，三阶 1.5。
- 五行匹配系数：功法五行与灵地五行相生 +30%，相同 +20%，相克 -10%。
- 最终灵地契合度上限 100%。

**灵地升级**：

- 封地灵地可通过建筑、阵法、灵脉引渡升级。
- 门派灵地需贡献或职位权限。
- 敌对灵地需占领或偷入。

### 3.4 本命契合

**本命契合**反映本命觉醒程度与当前境界的匹配。

```
本命契合 = 境界系数 × 本命技解锁数 × 本命物收集数
```

- 境界系数：练气期 0.5，筑基期 0.8，金丹期 1.0。
- 本命技解锁数：每解锁一个本命技 +10%。
- 本命物收集数：每收集一件与本命相关的同参 +5%。

**本命觉醒**：

- 每次大境界突破时，本命自动觉醒，提升本命契合度。
- 收集齐本命对应的所有同参，可触发**本命共鸣**，额外 +15%。

## 五、修行流程

### 5.1 日常挂机

1. 玩家选择当前灵地、主修功法、主同参。
2. `spirit.js` 按公式计算灵力/秒，离线时按 0.8 效率累计。
3. 灵力池满后：
   - 若当前是普通小境界 → 自动突破或提示手动突破。
   - 若当前是门槛节点 → 检查契合度，达标则提示可冲击，不达标则提示需提升契合度。
4. 同参祭炼、功法熟练度在挂机时自动累积。

### 5.2 上线调整

1. 查看四维契合度雷达图。
2. 针对性提升：
   - 功法契合低 → 升级功法、换功法、提升熟练度。
   - 同参契合低 → 升级同参、换同参、增加祭炼。
   - 灵地契合低 → 换灵地、升级灵地、调整五行。
   - 本命契合低 → 解锁本命技、收集本命物。
3. 若当前是门槛节点且契合度达标，点击突破。
4. 若当前是普通小境界，灵力满即可突破，无需调整。

### 5.3 门槛突破结算

1. 检查综合契合度是否达到阈值。
2. 播放突破动画（打坐、观想、破土/生长/结实三阶段）。
3. 成功：提升层数，本命契合 +5%，解锁新本命技或词条。
4. 失败：灵力清零，契合度暂时 -10%，记录 attempts。
5. 连续失败 3 次后，提示“或许该换条路走走”，引导散功重修或换同参。

### 5.4 散功重修

1. 玩家可主动散功，清空灵力池，重置换修新功法。
2. 散功后重修回原境界速度极快，契合度保留 50%。
3. 重修后灵力池上限永久提升，功法契合度重新计算。
4. 散功期间战力下降，需避免巡查、战斗。

## 八、可玩性设计要点

1. **挂机为主，门槛为辅**：普通小境界纯挂机，玩家不需要频繁操作。只有五个门槛节点需要认真准备。
2. **四维搭配有策略**：门槛前需要调整功法、同参、灵地、本命的搭配，达到契合度要求。
3. **同参升级是长线目标**：每件同参可升多级，需要大量材料和灵石，与封地、商队联动。
4. **功法切换有代价**：散功重修损失战力，但换来更高上限，需权衡时机。
5. **灵地争夺有政治**：好灵地往往在他人手中，需通过合议、外交、占领获得。
6. **契合度可视化**：雷达图让玩家一眼看出短板，针对性提升。
7. **突破有保底**：连续失败后引导换路，避免挫败感。
8. **筑基 80%、结丹 100%**：长线目标明确，玩家有长期追求。
