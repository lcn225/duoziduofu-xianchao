**范围**：代码批，**只做纯优化、不碰玩法**（功能项另立小快修批）。验证 **2028/2028**（+41 条）。

**落地内容**

- 新增 `src/plugins/saveThrottle.js`（纯逻辑、可注入时钟）：`markDirty` 只标脏，
  5 秒窗口内排一个定时器；并发写**合并成一次**；写失败**保持脏、下个窗口重试**。
- `persistence.saveData` = 标脏 + 按窗口决定；新增 `flushSave()`；
  `persistSnapshot()` 是**唯一写盘实现**（`toRaw($state)` → stringify → 加密 → IDB）。
- **措施 ③ 的根因不是「内宅特供」**：练功那一片 tick 里 `gainSpirit` 存一次、
  `meditateInSlice → cultivate` 又存一次 ⇒ 练功时段**全仓**都是 2 次/秒，只是当轮采样停在内宅。
- **加密**：新密文 `vux2:` + base64(iv12 ‖ 密文+tag)；密钥 PBKDF2-SHA256
  （口令 `vue-idle-xiuxian`、固定盐、120k 次、**会话内只派生一次**，CryptoKey 缓存）。
  老档（CryptoJS、无前缀）**只读不写**，读到后下一次落盘自动写成新格式 ⇒
  **不升 `SAVE_VERSION`**（换加密是外层包装，升版反而清档）。
  `crypto.subtle` 只在安全上下文有（https / localhost），file:// 打开时退回 CryptoJS。
- `encryptData` / `decryptData` 变 async，全仓只有 `persistence.js` 一个消费者。
- 真档回归：老档 7.66MB CryptoJS → 解密 → 迁移 → 写出 2.92MB 新格式 → **灌回去再读一遍**
  （明文 2.07MB、无 console.error）。

## 二、看起来像 bug 的预期行为（本批新增）

1. **崩溃 / 强杀最多丢最后 5 秒的进度** —— 落盘节流的代价，登记 R29。正常关页有
   `pagehide` 强制落盘兜底，所以正常玩法看不到丢档。
2. **导出的存档文件小了一大截、开头是 `vux2:`** —— 换了加密格式（base64 + GCM 无额外填充）。
   **老档文件照样能导入**，导入后下一次落盘自动转新格式。
3. **`saveData()` 不再「调了就进库」** —— 新模块如果在没有 tick 的时刻结算，
   别指望它立刻落盘；要立即进库就 `saveData({ force: true })` 或 `await flushSave()`。
4. **内宅 / 秘境仍有 12 条 ~150ms 的长任务** —— 是 buff 倒计时 rAF 与 2,800 节点渲染，
   **不是落盘**（存盘已是 0.2 次/秒）。P58 只承诺「落盘不再是主线程大头」。
5. **在暂停页（背包 / 坊市）挂着不产生任何存盘** —— 时钟暂停、无脏数据可写，这是对的；
   关页那一下会强制写一次，正是为了让离线基线与真实下线时刻对齐。
