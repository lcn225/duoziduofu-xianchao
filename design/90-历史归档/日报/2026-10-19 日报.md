### 8.2 本命 → 灵根修正（用户纠错）

**旧逻辑（错）**：先定灵根数量 → 抽等量本命，并强制灵气不重复。
结果「3 件木系本命」永远不可能出现。

**新逻辑（对）**：

```
先抽本命数量（3/12/10/15/60）→ 抽本命（灵气可重复，仅同系列不重复）
→ 灵根 = fateElement 去重集合 → 灵根数量 = 集合大小
```

- 3 件木系本命 = **单木灵根**；5 件全木 = 仍是单木灵根；5 件不同属性 = 五灵根。
- 实测灵根分布（20 万次）：**1 灵根 4.7% / 2 17.1% / 3 30.2% / 4 36.6% / 5 11.4%**。
- 根系数整体 ×0.6：**0.012 / 0.03 / 0.06 / 0.12 / 0.24**；期望根系数 0.062（旧 0.0655）。
- 本命阶数上限按**最终灵根数**（5→1、4/3→2、2→4、1→5），**上限不是保底**；
  先定本命，再用 `clampFateTiers` 压阶。
- 老档 `fates[]` 按 `roots` 稳定补齐（**迁移例外**：保留旧档已判定的灵根数）；
  旧「粗铁棍」这类已删物品会被替换，刷新不重掷。
- 术语：旧「凡兽 / 灵兽 / 王级变异兽 / 神兽·仙器」作废，统一 **1 阶灵兽 / 2 阶灵兽 / …**。

### 9.3 旧灵石补偿（重大口径修正）

**问题**：2026-10-18 的存档 `spiritStones: 14,005`，按旧规则 1 旧 = 10 大子变成
140,050 大子；顶栏「灵石」一栏显示 0，看起来像全部贬值。

**新口径（用户拍板）**：

```
1 旧灵石 = 1 一阶灵石
90% 留一阶；剩下 10% 里，5 阶换大子（1,750），其余按 3.5 金页子/阶换金页子
```

| 项目 | 旧口径 | 新口径 |
|---|---:|---:|
| 一阶灵石 | 0 | **12,604** |
| 金页子 | 0 | **4,886** |
| 大子 | 140,050 | **1,750** |
| 二阶灵石 | 0 | 0 |
