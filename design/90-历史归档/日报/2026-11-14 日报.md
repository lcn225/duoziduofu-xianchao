## 三、P62 阶段 F：真档测速 + 复评（当天第 3 段会话）

**范围**：纯测量 + 工具，零产线代码改动（`perf-probe` 只加一个开关）。断言仍是 3,612。

**方法**：以 **2026-11-07 真档**（金丹十层 / 1,436 子嗣 / 4.72MB 密文）为底，只改 `idleMode`
派生两份测速档（探索档补建会话、秘境档保留 `highestBossCleared = 5`），`lastOnlineRealMs` 不动
⇒ 离线预算排满 30,240 天。每份都 `--dump-save` 回读核验走的是对应结算路径。

**测速结果（同机同档，Vite dev）**

| 模式 | 读档到可交互 | 核验 |
|---|---|---|
| 镇守 | **32.8 秒** | — |
| 探索 | **33.7 秒** | `offlineReport.windows = 0`、`stats.events +362,880`（= 30,240 × 12）⇒ 走期望值 |
| 秘境 | **32.8 秒** | `stats.sweeps +30,240`、报告「离线扫荡 30240 趟（每趟 1 天，打到第 5 层）」 |
| 不结算对照 | **1.9 秒** | 同一份档 `lastOnlineRealMs` 改成「刚刚」⇒ **离线重放本身 ≈31 秒** |

**复评（读档期 CPU 采样，`perf-probe --profile-boot`）**：内宅块结算 **21.9 秒**（家族工作 8.3 /
历练 7.0 / 繁育 4.9 / 诞生 4.5 / 落背包 `gainItem` 8.5，互相重叠）· 封地 3.2 秒 ·
药浴 2.7 秒 · 日常循环 2.1 秒 · Vue 响应式 = 分散的 ≈8~10 秒自身耗时。
**模式不影响耗时**：三条线的共享块结算才是主体。重放期间家族从 1,436 涨到 **4,148**（新增 2,745 人）。

**结论**：**未达验收线**（镇守 ≤20 秒 / 探索 ≤10 秒）。P62 继续开着，下一轮候选方向
（内宅块内批量 / 内宅落账批量 / 非响应式重放）写进《下一步》P62 与《明日讨论-2026-11-15》A1。

**踩坑**：`MODES.SECRET_REALM` 真值是 **`'secretRealm'`（驼峰）**；造档时写成 `'secret_realm'`
会被模式分派当成未知值、**静默落回镇守兜底**（报告里的 `mode` 还会照抄你写的那串）。
已记进开发手册 §八 坑 19。

**已知边界 / 预期行为**：测速档是**派生档**，不是用户从当前档切模式导出的 —— 最终验收数要用
真导出档复核（用户 2026-11-14 选 C 先落账，复核留待下一轮）；`--profile-boot` 本身有约 +6 秒开销，
带采样跑的读档时间不能与裸跑直接比。

**提交 / 验证**：`6027392`（tool）· `verify:quiet` **3,612 / 3,612** · `check:docs` 通过。
