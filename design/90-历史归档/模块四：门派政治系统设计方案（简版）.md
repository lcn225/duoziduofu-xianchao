# 模块四：门派政治系统设计方案（简版）

## 一、模块定位

门派政治系统负责飞鹰门内部的派系关系、合议决策、职位任免和俸禄发放。它是玩家中期的主要玩法，连接内宅姻缘、封地经营和修行突破。

**核心循环**：完成门派任务 → 获取贡献和好感 → 参与合议站队 → 影响职位和资源分配 → 获取更多俸禄和封地 → 提升门派地位。

---

## 二、派系系统

### 2.1 主要派系

| 派系  | 领袖  | 核心成员         | 理念        | 对玩家态度  |
| --- | --- | ------------ | --------- | ------ |
| 门主系 | 洪晃  | 老五、老七、郑婉     | 平衡各方，稳住门派 | 中立，看表现 |
| 上柱系 | 老三  | 龙居义、陈廷胄      | 文治优先，清贵掌权 | 拉拢     |
| 中柱系 | 老四  | 岳敬尧          | 执法强权，制衡老八 | 拉拢     |
| 八柱系 | 老八  | 老九、老十、陶端、苏克文 | 武人掌权，抱团排外 | 敌对     |
| 将相系 | 关元归 | 明玉书、冯世俸、张谈   | 中立务实，各为其主 | 可争取    |

### 2.2 派系好感度

每个派系对玩家有独立好感度，范围 0–100。

| 好感度    | 关系  | 效果            |
| ------ | --- | ------------- |
| 80-100 | 同盟  | 主动示好，分享任务和资源  |
| 60-79  | 友好  | 配合互动，提供便利     |
| 40-59  | 中立  | 正常往来          |
| 20-39  | 冷淡  | 消极配合，可能刁难     |
| 0-19   | 敌对  | 主动打压，告状、抢功、陷害 |

**好感度变化**：

| 行为       | 变化                 |
| -------- | ------------------ |
| 完成门派任务   | +2~5（根据任务归属派系）     |
| 合议中附议某派系 | +10（该派系），-5（对立派系）  |
| 合议中保持沉默  | 无变化                |
| 为某派系辩护   | +15（该派系），-10（对立派系） |
| 告状       | -20（被告派系）          |
| 送礼       | +5~15              |
| 联姻       | +20                |
| 拒绝任务     | -10                |
| 私藏战利品    | -5（若被发现）           |

## 三、合议系统

### 3.1 合议触发

合议由洪晃召集，触发条件：

| 条件     | 频率                   |
| ------ | -------------------- |
| 定期合议   | 每月一次                 |
| 重大事件   | 随机，如发现萧家余孽、妖兽入侵、郑家施压 |
| 玩家职位晋升 | 晋升时需合议通过             |
| 门派财政危机 | 不定期                  |

### 3.2 合议议题

| 议题    | 提出者      | 选项           | 影响          |
| ----- | -------- | ------------ | ----------- |
| 职位任免  | 洪晃       | 附议/反对/沉默     | 影响派系好感和职位分配 |
| 战利品分配 | 老九       | 附议/反对/沉默     | 影响俸禄和资源     |
| 执法权归属 | 老四 vs 老八 | 附议老三/附议老八/沉默 | 影响老四老八好感    |
| 封地建设  | 各乡侯      | 附议/反对/沉默     | 影响封地资源和民心   |
| 对外征战  | 老八       | 附议/反对/沉默     | 影响战利品和风险    |
| 联姻    | 郑家/明家/冯家 | 附议/反对/沉默     | 影响势力和好感     |
| 玩家晋升  | 洪晃       | 附议/反对/沉默     | 影响职位和俸禄     |

### 3.3 合议流程

1. 洪晃提出议题。
2. 各派系发表意见。
3. 玩家选择：附议某派系、反对、保持沉默。
4. 系统根据派系力量、玩家好感、议题性质判定结果。
5. 结果影响职位、俸禄、封地、资源、好感。

## 五、俸禄系统

### 5.1 俸禄发放

| 时间      | 发放内容       |
| ------- | ---------- |
| 每月初一    | 月俸（年俸/12）  |
| 每年腊月初八  | 年俸现金       |
| 每年腊月操演后 | 军阵职务俸禄重新定级 |

### 5.2 俸禄支账

- 俸禄可**支账购物**（在老九处），也可**取现灵石**（腊月初八）。
- 支账购物享受**内部价**，比市价低 20%~30%。
- 取现灵石无折扣，但可自由使用。

### 5.3 私藏战利品

- 玩家可私藏战利品，不上缴。
- 被执法阁发现后，扣俸禄 + 派系好感下降。
- 老八系成员更容易被告发。

## 九、可玩性设计要点

1. **派系好感是核心资源**：影响合议结果、任务分配、职位晋升。
2. **合议是主要决策点**：玩家需在派系间站队，权衡利弊。
3. **职位晋升是长期目标**：从下柱到中柱再到上柱，需要贡献和好感。
4. **俸禄是稳定收入**：年俸、乡侯俸、驿守俸、军阵俸，构成多元收入。
5. **私藏战利品有风险**：可快速积累资源，但被执法阁发现后会扣俸禄。
6. **任务提供多样化玩法**：巡查、清剿、护送、出使、执法、传功。
7. **门派政治与内宅联动**：联姻势力影响门派好感，侍妾家族提供政治支持。
8. **门派政治与封地联动**：封地繁荣度影响门派贡献，门派职位影响封地安全。
