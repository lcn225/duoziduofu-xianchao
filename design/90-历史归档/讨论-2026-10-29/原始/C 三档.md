## A1-3 · 突破提示改弹窗（⚠ 翻案）

### 翻案声明

**2026-10-29 翻案**：突破提示从**第 2 档横幅**升到**第 3 档居中弹窗**。

- 原口径（2026-10-26 B0《开发手册》§二）：第 3 档弹窗**只有四类** —— 解锁、寿终、离线报告、二选一叙事。

- **新口径：五类，加「突破」。**

用户理由（记录在案，别再重开）：

1. 初期多弹窗能让玩家迅速得到反馈，帮助认知游戏系统。

2. 离线一次从练气一层升到六层已是极限，不会弹屏；「练气一层就离线挂机」才是设计失败。

### 口径

| # | 项 | 结论 |

|---|---|---|

| 1 | 形态 | 居中弹窗（`n-modal`） |

| 2 | 暂停 | **不暂停时钟**（不进 `PAUSE_ROUTES`，不调 `pauseClockForEvent`） |

| 3 | 合并 | **同一次突破结算内连升多级合并成一条**：`练气六层→练气九层` |

| 4 | 跨结算 | 弹窗未关又来新突破 → **分开弹**，**队列上限 5**；超出合并成「突破至练气 N 层（共 M 次）」放队尾，M = 总突破次数 |

| 5 | 绝对值 | **带**，格式 `属性 绝对值（+增量）` |

| 7 | 小数点 | 增量一位小数、整数省略 `.0`；`toFixed(1)` 后 `parseFloat` 去浮点尾 |

| 8 | 离线 | **只进离线报告**，同文案格式，不弹窗 |

| 9 | 外功 | 写生命 / 防御两项（`floor` 差分，整数） |

### 文案示例


**外功**：同上格式，两项（生命 / 防御）。

### 寿元公式（含随机偏移）

```
offset = FNV-1a(id + name) → [-5%, +5%] 的确定性连续值

lifespan = baseLifespanOf(realmLevel) × (1 + offset)
```

| 对象 | base | 偏移后区间 |

|---|---|---|

| 凡人子嗣 / 凡女妻妾 | 80 | **76.0 ~ 84.0** |

| 练气子嗣 / P9 妻妾 | 120 | 114.0 ~ 126.0 |

| 筑基子嗣 / P10 妻妾 | 200 | 190.0 ~ 210.0 |

| 结丹子嗣 / P11+ 妻妾 | 500 | **475.0 ~ 525.0** |

- **随境界缩放**：升境界 → 按新 base × 同一偏移比例重算。

- **妻妾同样适用**。

- 哈希种子 `id + name`，与性别补齐 / 配偶灵根补全同先例。

- hash 映射到 `[-500, 500]`（千分之五步长），凡人精度 ≈ 1.2 游戏天。

- **不存字段**，每次现算，结果稳定；渲染按 `id` 记忆化。
