**要定的分叉**

1. **一级页签怎么摆？**
   - **方案 A（全量重排）**：一级 = 修炼 / 多子多福 / 建设 / 百艺 / 商业 / 其他；镇守、探索、秘境降成「修炼」的二级。
     *玩家可见*：挂机状态不再一眼可见，切挂机要多点一次；「回镇守 = 唯一退出出口」的交互要重新设计。
   - **方案 B（分类只进「更多」）**：一级保留现在的挂机三连 + 管理页，「更多」按 6 大类分组。
     *玩家可见*：分类有了，但主界面几乎没变，等于只改下拉菜单。
   - **方案 C（折中）**：一级 = 6 大类，但「修炼」页签自带**挂机状态小标 + 常驻「回镇守」**；
     点「修炼」默认落到当前挂机页。*玩家可见*：分类是新的，但三选一互斥与退出出口不变。

2. **飞鹰门拆不拆？**（内政 / 任务 → 建设，飞鹰阁 → 商业）
   - **保留一页（推荐）**：`/faction` 仍是一页，从「建设」「商业」两个入口进，页内滚到对应区。
   - **真拆两页**：内政 + 任务一页、飞鹰阁一页。要动路由、`PAUSE_ROUTES`、页面状态。
   - **完全不拆**：飞鹰门继续当一级，不纳入这套分类。

3. **「任务」放「建设」语义偏了**（11-07 B3 已提过）：这里的任务是**门派任务**，不是乡间任务，
   语义在飞鹰门。按原分类放「建设」下，玩家会以为是建设任务。要么把「任务」挪到「修炼」下、
   要么单列「门派」，要么接受「入口在建设、但页内标题写清是门派任务」。

4. **「秘库」改名**：11-07 已定口径 —— 「商业」里的「秘库」应改成 **「飞鹰阁」**（原备忘录叫秘库）。
   同时飞鹰阁只收**贡献点**，和花银子的宝阁放同一组，入口要标死「贡献点」，否则玩家以为能花钱买。

5. **炼体落点**：药浴现在在 Day 页日常循环 + 封地「药浴池」区，没有独立页。
   百艺要收「炼体」= 新开页把它搬出来？还是承认炼体是日常循环的一环、百艺页只放四艺？

6. **命名冲突**：一级「修炼」下再有二级「修炼」，玩家会看到「修炼 > 修炼」。
   二级改名候选：**修行详情 / 功法·同参 / 修行面板**。

**建议**

- **方案 C + 飞鹰门保留一页 + 飞鹰阁入口标「贡献点」+ 炼体不新开页（仍是日常循环一环）+
  二级改名「修行详情」。**
  理由：① 方案 C 让分类落到一级，同时不破坏「回镇守」这个唯一退出出口；
  ② 飞鹰门的贡献点 / 周任务 / 俸禄 / 老九 / 月刷共用**同一个「现实秒」锚点**，拆页只会把一份状态拆成两半；
  ③ 炼体本来就不是配置页，搬出日常循环会违背「新模块默认是日常循环的一环」的既有约定。
- **「任务」的归属**：建议**把「任务」挪到「修炼」下**（沿用 11-07 B3 的建议），或接受
  「建设 → 飞鹰门」入口但页内标题写明「门派任务」。**不要**在建设下再出现一个语义含糊的「任务」。
- **先只改 `MainNav.vue` 一个文件**：路由全部不变，`PAUSE_ROUTES` 不变，断言不变。
  1 个会话可落地；真拆页再另开一批。

- 纯 UI + 导航归组：`verify:quiet` 全过即可，不改断言；`check:docs`。
- 若真拆飞鹰门页 / 新开炼体页：动 store、暂停表、页面状态，约 3~4 会话。
