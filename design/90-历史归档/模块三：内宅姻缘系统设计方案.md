# 模块三：内宅姻缘系统设计方案

## 一、模块定位

内宅姻缘系统是连接**修行模块**与**多子多福模块**的桥梁，负责：

- 侍妾的获取、位阶、月例、好感度管理。
- 晚间精力分配与互动。
- 内宅事件与稳定度。
- 侍妾技能与离线效率加成。
- 姻缘联姻与势力关系。

**核心循环**：获取侍妾 → 提升位阶 → 培养好感 → 晚间互动 → 怀孕生子 → 子嗣成长 → 获取资源 → 纳更多侍妾。

## 二、侍妾位阶系统

### 2.1 位阶定义

| 位阶  | 名称    | 月例       | 丫鬟  | 住所     | 怀孕率加成 | 子嗣灵根加成 |
| --- | ----- | -------- | --- | ------ | ----- | ------ |
| P1  | 通房丫鬟  | 50 大子    | 0   | 大通铺    | +0%   | +0%    |
| P2  | 一等丫鬟  | 100 大子   | 1   | 双人小间   | +1%   | +0%    |
| P3  | 三等侍妾  | 50 大子+衣物 | 2   | 两卧夹厅套间 | +5%   | +0%    |
| P4  | 四等如夫人 | 1 二阶灵石   | 4   | 独立厢房   | +10%  | +1%    |
| P5  | 五等夫人  | 3 二阶灵石   | 6   | 独立院落   | +15%  | +2%    |
| P6  | 六等正妻  | 10 二阶灵石  | 8   | 独立跨院   | +20%  | +3%    |

**注**：

- 大子 = 大铜钱，100 大子 ≈ 1 金页子 ≈ 0.03 二阶灵石。
- 月例消耗从家族账目自动扣除，不足则好感度下降。
- 子嗣灵根加成仅在该侍妾怀孕时生效。

### 2.2 位阶晋升

| 晋升条件            | 从   | 到   |
| --------------- | --- | --- |
| 互动 10 次         | P1  | P2  |
| 互动 30 次 + 好感 60 | P2  | P3  |
| 怀孕一次            | P3  | P4  |
| 诞下有灵根子嗣         | P4  | P5  |
| 诞下极品子嗣 或 联姻势力嫡女 | P5  | P6  |

**晋升奖励**：

- 好感度 +20
- 侍妾技能解锁或升级
- 全宅公告，其他侍妾好感度小幅波动

### 2.3 位阶降级

| 降级条件               | 从   | 到    |
| ------------------ | --- | ---- |
| 好感度低于 20 且 30 天未互动 | P4+ | 降一级  |
| 连续 3 次拒绝互动         | P3+ | 降一级  |
| 犯下大错（下毒、告密、出逃）     | 任意  | 打入冷宫 |

**降级后果**：

- 好感度 -30
- 侍妾技能失效
- 可能触发报复事件

## 四、好感度系统

| 好感度    | 等级  | 表现          | 怀孕率加成 | 子嗣质量加成 |

| 0-9    | 仇恨  | 可能报复、下毒、告密  | -20%  | -5%    |

### 4.2 好感度变化

| 行为         | 变化     | 说明           |
| ---------- | ------ | ------------ |

| 诞下极品子嗣     | +50    | 额外           |
| 冷落（7天未互动）  | -5     | 每 7 天        |
| 冷落（30天未互动） | -20    | 一次性          |

| 侍妾间争宠失败    | -5     | 事件触发         |
| 子嗣陨落       | -20    | 生母好感         |

### 4.3 好感度作用

| 作用    | 说明                  |
| ----- | ------------------- |
| 怀孕概率  | 好感/10，上限 +10%       |

| 内宅事件  | 好感低触发争宠、告状、下毒       |
| 侍妾技能  | 好感 80+ 解锁特殊技能       |
| 联姻价值  | 好感高时，其家族更愿联姻        |
| 离线效率  | 好感总和决定内宅稳定度         |
| 派遣成功率 | 对子嗣派遣成功率 +好感/10     |

## 五、内宅稳定度

### 5.1 稳定度定义

```
内宅稳定度 = 所有侍妾好感总和 / 侍妾人数
```

| 稳定度    | 等级  | 效果              |
| ------ | --- | --------------- |
| 90-100 | 和睦  | 离线效率 +20%，无内宅事件 |
| 70-89  | 安宁  | 离线效率 +10%，低概率事件 |
| 50-69  | 一般  | 离线效率 +0%，正常事件   |
| 30-49  | 紧张  | 离线效率 -10%，高概率事件 |
| 10-29  | 混乱  | 离线效率 -20%，频繁事件  |
| 0-9    | 崩坏  | 离线效率 -50%，侍妾出逃  |

### 5.2 内宅事件

| 事件   | 触发条件     | 效果       | 处理方式       |
| ---- | -------- | -------- | ---------- |
| 争宠   | 稳定度 < 60 | 两侍妾好感互降  | 调解、偏袒、冷处理  |
| 告状   | 稳定度 < 50 | 一侍妾告另一侍妾 | 调查、惩罚、息事   |
| 下毒   | 稳定度 < 30 | 一侍妾中毒    | 救治、追查、严惩   |
| 出逃   | 稳定度 < 20 | 侍妾携子出逃   | 追捕、放弃、和谈   |
| 结盟   | 稳定度 > 70 | 两侍妾好感互升  | 支持、拆散、无视   |
| 互助   | 稳定度 > 80 | 两侍妾共同照料  | 奖励、推广      |
| 生日   | 随机       | 侍妾生日     | 送礼、庆祝、遗忘   |
| 生病   | 随机       | 侍妾生病     | 医治、陪伴、忽视   |
| 回娘家  | 随机       | 侍妾回娘家    | 派人接回、送礼、放任 |
| 怀孕喜讯 | 怀孕时      | 全宅庆祝     | 赏赐、公告、忽视   |

### 7.2 自动模式规则

| 规则    | 说明           |
| ----- | ------------ |
| 优先高好感 | 优先选择好感度最高的侍妾 |
| 优先高位阶 | 优先选择 P4 以上侍妾 |
| 优先未孕  | 优先选择未怀孕的侍妾   |
| 平均分配  | 轮流选择，每人一次    |
| 自定义顺序 | 玩家手动排序，按顺序互动 |

### 7.3 精力分配策略

| 策略   | 说明         | 适用         |
| ---- | ---------- | ---------- |
| 广撒网  | 每个侍妾互动一次   | 追求数量       |
| 重点突破 | 集中精力给高好感侍妾 | 追求质量       |
| 平衡   | 兼顾数量和质量    | 常规         |
| 冲刺   | 全部精力给单一侍妾  | 冲 P6 或灵根子嗣 |

## 十一、可玩性设计要点

1. **位阶晋升是长期目标**：从 P1 到 P6，每次晋升都有明确条件和奖励。
2. **好感度是隐藏投资**：提升好感度可提高怀孕率、子嗣质量、解锁技能。
3. **内宅稳定度影响离线效率**：稳定度高时离线收益增加，稳定度低时事件频发。
4. **侍妾技能提供多样化加成**：不同出身的侍妾提供不同技能，鼓励收集。
5. **晚间精力分配是核心决策**：有限精力如何分配，是广撒网还是重点突破。
6. **内宅事件提供叙事和选择**：争宠、告状、下毒等事件，玩家需处理。
7. **联姻是政治工具**：与郑家、明家、冯家、张家联姻，获取势力好感和资源。
8. **女修侍妾是终极追求**：女修侍妾可自行修行，诞下子嗣灵根概率极高。
9. **精力无限彩蛋提供终极目标**：50 子嗣或 20 P4 侍妾后解锁，夜夜笙歌。
10. **家族谱系提供长期成就感**：看着子孙满堂、开枝散叶，是放置游戏的核心情感满足。
