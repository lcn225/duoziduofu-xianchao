# 2026-11-13 设计定稿备忘录 · 标签页 UI 重构（导航信息架构）

## 一句话结论

顶部导航从「挂机三连 + 管理页 + 更多」重排为 **6 大类（修炼 / 多子多福 / 建设 / 飞鹰门 / 百艺 / 商业） + 更多**；窄屏只显前 4 类；右上角时间状态旁加 `🏠` 图标，点击直达当前挂机页。

---

## 现状

- **宽屏**：一级 6 页签（镇守 / 探索 / 秘境 / 多子多福 / 建设 / 飞鹰门） + 「更多」下拉（9 项 + GM）。

- **窄屏**：页签不做折叠，直接**折行**（飞鹰门被挤到第二行）。

- **右上角**：显示「推进中 / 第N年 / 月 / 日 / 时辰 / 🌙」，不可点击。

---

## 方案

### 1. 宽屏一级导航结构

> **修炼 · 多子多福 · 建设 · 飞鹰门 · 百艺 · 商业 · [更多 ∨]**

| 一级 | 二级子页 | 变化说明 |

|---|---|---|

| **修炼** | 镇守 / 探索 / 秘境 / **功法·同参** | 挂机三连收编；原「修炼」更名为「功法·同参」；默认落当前挂机页 |

| **多子多福** | 内宅 / 子嗣 / 家族树 | 不变 |

| **建设** | 乡间建设 | 内政、任务移入「飞鹰门」 |

| **飞鹰门** | 内政 / 任务 / 飞鹰阁 | 不拆页，一页内三区；「秘库」统一叫「飞鹰阁」 |

| **百艺** | 炼器 / 炼丹 / 制符 / 炼阵 | 炼体不新开页，维持日常循环 |

| **商业** | 背包 / 郑家宝阁 | 飞鹰阁移出，仅保留花钱的地方 |

| **更多** | 成就 / 设置 /（GM 仅开发模式） | 取消原「其他」一级；固定低频项收于此 |

### 2. 窄屏响应式规则

- **断点规则**：不再折行，只显示前 4 个一级页签。

- **显示项**：`[修炼] [多子多福] [建设] [飞鹰门] [更多 ∨]`。

- **溢出项**：百艺、商业、成就、设置，按顺序追加进「更多」的下拉列表。

- **当前页高亮**：如果用户当前在百艺或商业页，窄屏下「更多」按钮高亮。

### 3. 挂机状态快捷入口（右上角）

- **UI 调整**：在右上角时间状态（`推进中 第N年...`）前方加一个 **`🏠`** 图标。

- **交互**：整个状态块（图标 + 文字）变为可点击。

- **悬停提示**：`返回挂机页（当前：镇守/探索/秘境）`。

- **点击动作**：跳转到当前的挂机页路由（读取 `idleMode` 决定落点）。

---

## 影响面

- **纯 UI 重构**：只改 `MainNav.vue` 与右上角日期组件的页面结构。

- **路由表不动**：所有底层 URL 保持不变，`PAUSE_ROUTES` 暂停逻辑不变。

- **断言不动**：`verify:quiet` 全量通过即可，无需新增断言。

- **不涉及产出与数值**：不影响《产出登记表》。
