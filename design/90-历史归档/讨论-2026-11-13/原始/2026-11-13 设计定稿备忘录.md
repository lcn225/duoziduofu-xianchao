> **待领取期间不能下新单。** 待领取即占着这次订单，领走才能下新单。

### 2.2 落点

| 层 | 落点 | 做什么 |

|---|---|---|

| UI | 老九下单入口 | 待领取非空时按钮灰显，文案「先领走上一单」 |

## 三、零散 #9 乡侯府等级卡附属建筑上限（定稿）

### 3.1 核心规则

> **附属建筑目标等级 ≤ 乡侯府当前等级。乡侯府自身豁免，只受自己的 `maxLevel`（5）限制。**

### 3.2 各等级实际上限

| 乡侯府 | 5 级建筑上限 | 3 级建筑上限 |

|---|---|---|

| Lv1 | 1 | 1 |

| Lv2 | 2 | 2 |

| Lv3 | 3 | 3（满级） |

| Lv4 | 4 | 满级 |

| Lv5 | 5（满级） | 满级 |

### 3.3 边界条件

| 场景 | 处理 |

|---|---|

| 乡侯府自身 | **豁免**，否则死锁 |

| 老档已超限（如乡侯府 Lv2、灵田 Lv3） | **保留不降级**，禁止继续升，直到乡侯府追上 |

| 在建项目跨限（灵田升 Lv3 期间乡侯府 Lv2→Lv3） | 开工时校验一次，在建期间不重复校验；完工后若超限按老档处理 |

| 超限返回值 | 「未解锁」状态 + `needManorLevel`，**不是 `null`** |

| UI 文案 | **「需乡侯府 Lv.N」**（主文案，本会话拍板） |

| 首次建造 | 同样受此规则：乡侯府 Lv1 时只有 Lv1 解锁的建筑可建，建完即 Lv1，不能升 Lv2 |

### 3.4 节奏预期（已确认接受）

| 阶段 | 乡侯府可达 | 附属建筑上限 |

|---|---|---|

| 练气期（可玩边界内） | Lv2~Lv3 | Lv2~Lv3 |

| 筑基期（24×） | Lv4~Lv5 | Lv4~Lv5 |

| 金丹期（168×） | Lv5 | 全部满级 |

**练气期封地建筑基本卡在 Lv2~Lv3，是设计意图，不是 bug。** UI 要让玩家明白「不是不能升，是要先升乡侯府」。

### 3.5 施工前置：产出重算（必做）

**建筑上限压低 → 练气段灵田 / 药圃 / 矿场实际等级下降 → 产出减少。** 施工前必须：

| 步 | 做什么 |

|---|---|

| 1 | 按新上限重算练气段封地产出（灵田 / 药圃 / 矿场 / 酒坊 / 市集 / 乡间百艺四栋） |

| 2 | 与旧口径对比，算出产出差 |

| 3 | 判断是否登《产出登记表》新行；若产出下降显著，评估补偿（降升级成本 / 调解锁节奏） |

| 4 | 重算结果写进施工单，开发组按重算后数施工 |

**这一步不做完，开发组不能开工。**
