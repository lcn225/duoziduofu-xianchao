## 2. 判定函数（三层回落）

`src/plugins/items.js`：

```js
export const affinityOf = (item, master) => {
  const sameCategory = item.category === master.category
  const sameSeries = sameCategory && item.series === master.series
  if (item.name === master.name) return { tier: 'owner', coef: 1.0 }
  if (sameSeries && isNearName(item.name, master.name)) return { tier: 'quasiOwner', coef: 0.8 }
  if (sameSeries) return { tier: 'series', coef: 0.6 }
  if (sameCategory && isNearKind(item.category, item.type, master.type)) return { tier: 'nearType', coef: 0.4 }
  if (sameCategory) return { tier: 'type', coef: 0.25 }
  return { tier: 'none', coef: 0.1 }
}
```

`src/plugins/harmony.js` 的入口：

- `affinityTierOf(item, fate)`：有显式 `affinity` 字段就用；否则 `同 id → 同 series → 同 kind → 无关`。
- `affinityTierVsFate(item, fate)`：本命（`PLAYER_FATES`）只存 id/name/kind/series，
  category/type 要回物品池反查，再走 `affinityOf`。
- **`quasiOwner` / `type` 两档至今没有判定规则**，只能靠显式字段标注。

## 5. 连乘里的另外两项

| 项 | 公式 | 代码位置 |
|---|---|---|
| 功法契合 | 品阶分（练气 .2 / 筑基 .3 / 金丹 .4）+ 覆盖率 × 40% + 熟练度 | `harmony.js` `TUNING.qiArt` |
| 熟练度 | 每 50 游戏小时 +1%，上限 20% | 同上 |
| 灵地契合 | `max(匹配百分比, 0.2)` | `harmony.js` `TUNING.spiritLand.minFit` |
| 综合 | 功法 × 同参 × 灵地（连乘） | `calcHarmony` |

**同参只进门槛（GateFit）和速度（SpeedFit），不进属性面板。**
速度项：`speed.base 0.98 + span 0.32 × 综合契合度`（0.98 ~ 1.30）。
