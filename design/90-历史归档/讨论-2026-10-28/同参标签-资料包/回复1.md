文字描述改：

```text
本命【饕餮玉牌】= 灵器 0.25 + 饰品 0.4 + 青金石 0.4 + 饕餮纹 1.0 + 暗金 1.0 = 3.05
同参【风磨铜盾】= 灵器 0.25 + 防御 0.4 + 风磨铜 0.4 + 坚固 1.0 + 饕餮纹 1.0 + 青金石 0.4 = 3.45
```
