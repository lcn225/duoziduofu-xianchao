### 2.2 映射规则

| 原器型         | 大类  | 理由        |
| ----------- | --- | --------- |

| 矛/棍/枪/戈/杖   | 长柄  | 长杆挥击/挑刺   |

| 其余          | 辅助  | 容器、法器、工具  |

### 2.3 审计提的“牌消失”

“牌”确实不再作为中层标签出现，改为 `饰品`。后果：

- 03/04 的“牌/盾”算例文字需改；
- 饕餮牌的中层从 `牌` 变 `饰品`，风磨铜盾从 `盾` 变 `防御`；
- **54.1% 数值不变**，因为 `饰品` 和 `防御` 本来就不相交，交集仍是 `灵器 + 青金石 + 饕餮纹 = 1.65`。

这是数值巧合，不是口径正确性证明。口径正确性靠“功能直觉”支撑：玩家判断两件灵器像不像，看的是“都是短兵”还是“都是护具”，不是“都是牌”。

## 三、灵兽中层

### 3.1 鸟类：4 生态类群

原 02 兽型 27 词含鸦/鹰/鹤/孔雀，覆盖不足。变更为：

| 生态类群    | 包含      | 件数  |
| ------- | ------- | ---:|
| 猛禽      | 鹰、雕、鹏   | 5   |
| 鸣禽      | 鸦       | 5   |
| 游禽（含涉禽） | 鸥、雁、鹅、鹤 | 7   |
| 陆禽      | 孔雀、鸠、鹧鸪 | 3   |

**为什么不用具体物种**：鹰 2、雕 2、鹤 2、孔雀 1，每个都 <3，且鹰和雕同属猛禽，分开反而让“鹰 ↔ 雕”契合变低，与直觉相反。生态类群合并后每类 ≥3，覆盖多阶。

**涉禽并入游禽**：鹤只有 2 件，单列 <3；鹤与鸥/雁/鹅同属水鸟，合并合理。

**攀禽不设**：池内 0 件，词表备注保留。

### 3.2 非鸟类：具体物种 + 归并

| 处理     | 词                                               | 件数  |
| ------ | ----------------------------------------------- | ---:|
| 保留具体物种 | 猪6、龟8、蛟5、鱼4、虎4、獾4、狐7、蜥3、蛇3、熊3、螳螂3、麒麟3、灵长5、鹿1、蟹1 | —   |
| 归并     | 貂/狸→狐；蜘蛛/蝎/蝶/蜂/蛾/蚯/蝙蝠→虫；犼→麒麟                    | —   |
| 新增     | 无                                               | —   |

**灵长 = 猴 + 猿**：猴 1、猿 1、白山凶猿 1，合并后 3 件，达标。

### 3.3 审计提的“鹰鹤互相加成”

鹰和鹤不再同属猛禽：鹰在猛禽，鹤在游禽。**审计提的“鹰鹤因同属猛禽而加成”不成立**，因为鹤不在猛禽。真正同属猛禽的是鹰/雕/鹏，这是设计意图——它们都是猛禽，契合高合理。

## 四、灵植中层

### 4.1 变更内容

原 02 植型 12 词不变，新增规则：**一件物品允许多个植型**。

| 例   | 中层   |
| --- | ---- |
| 人参  | 草\|参 |
| 霸竹  | 树\|竹 |
| 灰仙芝 | 草\|芝 |
| 莲花花 | 花\|莲 |

### 4.2 理由

`type` 字段只有一个值（草/树/花），但名称含参/竹/芝/莲/兰时，物品同时具备两种形态语义。多植型让“人参 ↔ 参类”和“人参 ↔ 草类”都能命中，不重复惩罚同参。

## 五、灵材中层

### 5.1 变更内容

原 02 材质 32 词不变，新增规则：

1. **名称命中具体材质词 → 打具体材质，不打 type 大类**；
2. **名称只含顶层特殊词 → 该词只打顶层，中层回落 type 大类**；
3. **type=花/叶/果 → 映射植型**；
4. **器胚/骨材 → 按系列打器胚/骨材**。

### 5.2 示例

| 物品   | 中层  | 说明               |
| ---- | --- | ---------------- |
| 风磨铜块 | 风磨铜 | 具体材质             |
| 暗金锭  | 金属  | 暗金只打顶层，中层回落 type |
| 厚土灵壤 | 灵壤  | 厚土只打顶层，中层具体材质    |
| 离火宝晶 | 宝晶  | 离火只打顶层；“离火晶”才是中层 |
| 赤焰花  | 花   | type=花 映射植型      |
| 万炼器胚 | 器胚  | 按系列              |

### 6.3 04 §4.3.2 算例

文字描述改：

```text
本命【饕餮玉牌】= 灵器 0.25 + 饰品 0.4 + 青金石 0.4 + 饕餮纹 1.0 + 暗金 1.0 = 3.05
```

## 七、两套词表并存的风险与约束

修订后 02 会有两套中层：

| 用途        | 词表                          | 谁在用                       |
| --------- | --------------------------- | ------------------------- |
| 同参打标/权重计算 | 器型组 8 + 生态类群 4 + 具体兽型/植型/材质 | `harmony.js`、`items.tags` |
| 展示/专精/装备槽 | 器型 43 + 兽型 27               | UI、`equipment.js`、子嗣专精    |

**约束：**

1. **同参计算只读 `tags.mid`**，不读 `type` 字段；
2. **UI/专精读 `type` 字段**，不读 `tags.mid`；
3. 两者不得混用；新增物品时 `type` 和 `tags.mid` 各自打，不互相推导。
