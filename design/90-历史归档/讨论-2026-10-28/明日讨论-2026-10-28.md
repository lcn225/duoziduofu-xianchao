### A1. B4b 药浴池的 UI 落点与独立仓交互（B4b 前置）

**现状**

- 规则已定稿、无空白：建池后**浴桶关闭**（A4），转换恒定 **1 件/小时 = 24 件/天**，
  存量上限 **100 / 300 / 1,000 / 3,000 / 10,000**，药力上限 **×1 / 1.5 / 2 / 3 / 4**，
  解锁 **乡侯府 Lv.2**，第 **16** 种封地建筑，权重 **1.0**（Lv2~Lv5 = 40 / 500 / 1,500 / 10,000 二阶）。
- **B4a 已落地的是浴桶**：Day 页五系药力条 + 「下一轮吞噬」预览，**勾了炼体才显示**。
- **还没落地**：独立仓（不占背包容量、未转换可取出）、品种锁（品种级 `series + tier`）、
  一键投入、池子本体的日结转换。

**要定**

1. **一键投入按钮放哪** —— 灵材页（背包）还是封地页的药浴池建筑卡片？
2. **独立仓在哪查看 / 取出** —— 封地页卡片内 / 灵材页新页签 / Day 页药力条旁？
3. **建池后 Day 页显示什么** —— 还显示「下一轮吞噬 N 件」，还是改成「从池中汲取」？
4. **品种锁图标挂哪一行** —— 灵材页每个品种一行（`series + tier`），还是一物一行？

**建议**：**配置面全部放封地页**。药浴池建筑卡片里显示池内存量 + 五系占比，带
「一键投入 / 全部取出」两颗按钮；灵材页只加锁图标、不加入口；Day 页保留药力条，
建池后把「下一轮吞噬」文案换成「从池中汲取 N 件」。
理由：药浴池是封地建筑，投入/取出属于**配置**；Day 页是执行面，不该出现第二套投入 UI
（和「一个主界面里自动循环」的口径一致）。

**影响**：B4b 会话量 1 → **1.5**；`views/Estate.vue` / `views/Inventory.vue` / `views/Day.vue`
三处；`verify-bath` + `verify-estate` 新增断言；离线报告加一行「药浴池转换了 X 件」。

**出处**

- 《下一步》P45 #2 / #8 / #10（`design/00-总览与状态/下一步.md`）
- 《炼体药浴》§9.2 运作、§9.3 防呆、§A.2 品种锁（`design/20-系统设计/炼体药浴.md`）

### A2. 子嗣寿命什么时候做、寿终算不算离线暂停点

**现状**

- **设计有**：《模块二》§15.5 已定 —— 寿元 **凡人 80 / 练气 120 / 筑基 200 / 结丹 500**，
  每年判定一次，`status:'passed_away'`，老死不算英烈、不给家族底蕴。
- **代码零**：子嗣无 `lifespan` 字段、无寿终判定；目前子嗣**唯一死法 = 秘境战死**（P53 #10 已核）。
- **时间尺度**：1 游戏天 = 96 现实秒 ⇒ 1 游戏年 ≈ **9.7 现实小时**；凡人 80 年 ≈ **32 现实天**，
  练气 120 年 ≈ **49 现实天**。离线单次上限 180 游戏天 ≈ **0.49 游戏年** ⇒ 一次离线**不可能老死**。

**要定**

1. **排哪批** —— 并入 **B6**（欠俸 + 四档通知）一起做，还是独立 0.5 批？
2. **寿终算不算「不可逆事件」** —— 离线要不要像子嗣陨落一样停下弹窗？
   （B2 已定：离线**唯一暂停点 = 子嗣陨落**）
3. **寿元按当前境界实时同步**，还是按出生时境界锁定？
4. **老档**怎么补 `lifespan`（读档归一化时按境界推？）

**建议**：独立 **0.5 批**、排在 B6 前后；**寿终不进离线暂停**（离线最多 0.49 年，撞不上；
且寿终可预期、有几十年缓冲，不值得打断托管）；寿元按**当前境界实时同步**（升级延长寿命，
与「侍妾寿元跟境界走」一致）；老档在读档归一化时按 `realm` 补 `lifespanYears`。

**影响**：模块二日结（每年判定）+ 家族树状态符号 + 讣告聚合 + 离线报告；
`verify-harmony` 新增断言；**不改存档版本号**，靠归一化补字段。

**出处**

- 《模块二》§15.5 寿命与死亡、§15.6.1 家族树状态符号（`design/10-模块设计/模块二-多子多福.md`）
- 《下一步》P53 #10（`design/00-总览与状态/下一步.md`）
- 《下一步》P52 B2 记录「子嗣寿终本批不做」（同文件）
- 《模块九》离线暂停点（`design/10-模块设计/模块九-离线结算.md`）

## 2. B 类：开工前一周定

### B1. 凡俗物品从哪来、定几件（B5 遗留）

**现状**：B5 判定已落地 —— 凡人子嗣只认**不入品**（`tierKey:'none'` / `tier<=0`）；
但物品池 **575 件全是有品阶灵器**（炼器 / 宝匣 / 探索都不产不入品）
⇒ **凡人子嗣现在什么都穿不上**，已登记为预期行为。来源是空的，等于「凡俗装备」整条线悬着。

**要定**

1. **做几件、哪些部位** —— 近战 / 防御 / 远程各一？还是按器型 43 细类铺？
2. **来源** —— 坊市常驻 / 探索练气 1~2 层低概率掉 / 炼器低阶产物 / 家族工作产出？
3. **价格与回收价** —— 回收价表按阶 2/7/29/115/461，不入品没有阶，挂哪一档？
4. **白板数值** —— T1 白板 5、几何 ×3/阶，凡俗从多少起？

**建议**：坊市**常驻 4 件**（刀 / 甲 / 弓 / 靴），白板 = **T1 × 30%**，售价 **1 一阶**，
回收价**固定 1 一阶**；探索练气 1~2 层低概率掉。理由：凡人是背景人口，装备只要「有个东西穿」，
不需要成长曲线；等真要做凡俗玩法再扩。

**影响**：物品池 + 坊市 + 掉落池 + 断言；0.5 批；《产出登记表》新增一条（收益增加）。

**出处**

- 《下一步》P51 #5、P52 表末「（未排期）凡俗物品产出源」（`design/00-总览与状态/下一步.md`）
