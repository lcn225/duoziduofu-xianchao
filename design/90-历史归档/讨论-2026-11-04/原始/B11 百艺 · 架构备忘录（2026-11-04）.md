## 一、两条产线

百艺分**两条产线**，产物与用途不同。

| 产线         | 谁在做                        | 怎么产                            | 产物去向              |
| ---------- | -------------------------- | ------------------------------ | ----------------- |
| **桂冈个人百艺** | 桂冈本人，插入每日循环（`dayLoop`）     | 百艺页自选丹方/配方 → 消耗材料 → 产**高一阶**成品 | 进背包，可自用（秘境耗材）/ 卖钱 |
| **乡间自动百艺** | 封地建筑（丹炉 / 工坊 / 符坊 / 阵堂），自动 | 自动消耗材料 → 产**低一阶**成品            | 进背包，可自用 / 卖钱      |

**共同约束**：**乡侯府升级 → 解锁附属建筑等级上限**。丹炉 / 工坊 / 符坊 / 阵堂能升到几级，由乡侯府等级卡。

**与封地经营链的分流**（见 §三）。

## 二、四艺统一

| 艺   | 乡间自动建筑     | 乡间产   | 桂冈个人产 |
| --- | ---------- | ----- | ----- |
| 炼器  | 工坊         | 低一阶灵器 | 高一阶灵器 |
| 炼丹  | 丹炉         | 低一阶丹药 | 高一阶丹药 |
| 制符  | **符坊（新增）** | 低一阶符箓 | 高一阶符箓 |
| 炼阵  | **阵堂（新增）** | 低一阶阵法 | 高一阶阵法 |

**四艺统一逻辑**：乡间低一阶、个人高一阶。

- **法器就是灵器，是装备**——不是抽象货物，进背包，可装备。
- **符坊 / 阵堂**是新增建筑，补齐四条线。**在 B11 里做，标 B14 追加**（见 §八）。

## 三、产物分流（⚠ 改 B14-b 的 R53 口径）

B14-b 已落地：封地三链（酒坊 / 丹炉 / 工坊）**全部即产即卖，不进背包**（抽象货物）。

**按百艺架构，封地建筑分两类：**

| 类         | 建筑                 | 产物                   | 性质                    |
| --------- | ------------------ | -------------------- | --------------------- |
| **经营链**   | 酒坊（以及以后的灵食坊 / 灵砖坊） | 灵酒 / 灵食 / 灵砖         | **抽象货物，即产即卖，不进背包**    |
| **百艺自动化** | 丹炉 / 工坊 / 符坊 / 阵堂  | 低一阶丹药 / 灵器 / 符箓 / 阵法 | **真实物品，进背包**，可自用 / 卖钱 |

**目的**：经营链提供模拟经营趣味性；百艺自动化解放玩家修行时间，不把时间浪费在批量生产低级物品上。

**⚠ 需要改的东西**：

- `R53` 重新登记（原登记三链全抽象货物，现在丹炉/工坊产物进背包）
- 封地建筑分类（`BUILDINGS` 表要区分「经营链」和「百艺自动化」）
- 存档体量：丹药/灵器进背包，需要堆叠规则（P62 已定 `buildCraftedItem` 可堆叠，但丹药/符箓是新物品类型，要确认）

## 四、熟练度

| 项           | 结论                   |
| ----------- | -------------------- |
| **低阶配方**    | **做一次就永久解锁**，之后乡间自动跑 |
| **玩家主要做什么** | 只做**高阶**（低阶由乡间自动供应）  |
| **熟练度来源**   | 通过「做」涨（乡间自动不涨熟练度）    |
| **熟练度数值**   | **待定**，交后续           |

**逻辑**：玩家不需要重复做低阶物品来刷熟练度——做过一次就解锁，乡间自动跑低阶。玩家只需要做高阶。

## 五、二阶定位

**难度分层**：高难度秘境需要多准备高级耗材。

- 低难度秘境：一阶丹药/符箓/阵法够用
- 高难度秘境：需要二阶（桂冈个人产的）才打得过

**「勾不勾百艺」= 「打不打高难度秘境」的决策**，不是「能不能打」。

## 七、秘境消耗品（⚠ 与 B10 完全独立）

### 7.1 基本规则

| 项            | 结论                                   |
| ------------ | ------------------------------------ |
| **回合定义**     | **一层 = 一回合 = 一场战斗**                  |
| **丹药**       | 每 5 层消耗 1 粒，效果**只管这 5 层**，没续上就断（脉冲式） |
| **符箓**       | 每层消耗 1 张，**本层有效**                    |
| **阵法**       | **持续整趟**，消耗品，每趟重新部署                  |
| **触发**       | **自动**（不需要玩家中途操作）                    |
| **与 B10 关系** | **完全独立**，不依赖战斗系统整理                   |

### 7.2 阶位选择

**默认高阶优先，可自选**。玩家在整备页设置消耗优先级。

### 7.3 不够时

**停止消耗，后续层无 buff**。不降级、不失败。

### 7.4 高阶 vs 低阶效果

**之后慢慢设计**（本次未定具体数值）。

### 7.5 整备页配置

**玩家自选**：带哪些、各带多少、优先级。

### 7.6 实装方式（交开发组）

现有 `simulateBattle` 是一次性算完整段（5 层），消耗品要在**层边界**生效。建议在 `runSegment` 的层循环里插「层开始时检查消耗品」的钩子，**不重写 `simulateBattle`**。
