## 三、本轮拍板（2026-11-04，用户逐条确认）

| # | 分叉 | 结论 |
|---:|---|---|
| 1 | 乡间自动化是否与 B11 同批 | **否，拆 B11-b**。B11-a = 桂冈个人百艺 + 配方/熟练度/残页底座 + 凡俗杂物落地（+ 秘境消耗品）；B11-b = 乡间自动化 + 符坊/阵堂 |
| 2 | 「低一阶 / 高一阶」基准 | **按配方所在境界段**：练气 乡间一阶 / 个人二阶；筑基 二阶 / 三阶；金丹 三阶 / 四阶 |
| 3 | 丹药 5 层脉冲 vs 现有 5 层 buff 门 | **并存**，同一层边界触发，不替换 |
| 4 | 低阶一次解锁 vs 残页拼图 | **低阶免残页、做一次永久解锁；二阶及以上才拼图**；熟练度只作学高阶门槛 |
| 5 | 消耗品作用对象 | **全队**（与 `applyBuffIds` 同口径） |
| 6 | 段内提前结束的消耗 | 丹药**按已跨过的 5 层边界实扣**，撤退 / 阵亡不追扣 |
| 7 | 与 B10 独立是否改排序 | **不改**：B11 仍排 B10 后；「独立」只表示消耗品不依赖战斗系统整理 |
| 8 | B14-b 代码是否本次改 | **不改**：丹炉 / 工坊 继续产抽象成品，换实物在 B11-b |

## 四、明确否掉 / 纠错（也要留痕）

| 原文 | 判定 | 理由 |
|---|---|---|
| 「乡间自动化放 B11 同批做」 | **不采纳** | B14-b 刚落地，一次改两块经济面（R53 收入 −50% + 背包体量）风险最大；拆 B11-b |
| 「丹炉 / 工坊 现在就换实物」 | **不采纳** | 同上；等原料来源 / 卖价 / 堆叠键定完 |
| 「`simulateBattle` 一次性算完整段（5 层）」 | **事实错误** | `simulateBattle` = 一场战斗 = 一层；5 层循环在 `runSegment`（`plugins/secretRealm.js:960-1027`） |
| 「一层 = 一回合 = 一场战斗」 | **术语错误** | 回合（round）是战斗内部概念（`maxRoundsPerBattle`），一层 = 一场含多回合的战斗 |
| 「《数据定案》E4 建筑数」按单个 21 改 | **不完整** | E4 口径是「封地 + 据点」；正确改法 21 + 6 = 27 → **23 + 6 = 29** |
| 「整备页」现有 | **不存在** | 秘境只有「整备出发」界面；带什么/多少/优先级是新 UI 工作 |
| 秘境没有 5 层机制 | **漏看** | 现有 `buffEveryFloors:5` + `pendingBuff` 选增益，消耗品必须与其并存 |
