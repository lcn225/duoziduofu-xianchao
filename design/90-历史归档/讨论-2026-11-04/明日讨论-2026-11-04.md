## 0. 明天先看这五句

1. **现状是 v1 炼器**：45 分钟/轮、**凭空出 3 件金饰装备**、不扣料、无熟练度。B11 要把它换成
   「真实扣料 + 时间成本 + 熟练度」，其余三艺仍是数据位。
2. **凡俗杂物（B2）设计已定、代码没落**：金饰三件应改成无属性杂物，炼器默认勾选应改成**不勾**。
   B11 第一件事很可能就是先把这条落地，否则「真实扣料产装备」会和 B2 结论打架。
3. **炼丹页是上游遗留**：`pillRecipes` 的 9 条丹方用旧 `herbs` id（`spirit_grass` 等），
   当前 494 件物品池里**没有这些 id**（只有同名不同 id 的物品）—— 即使探索/秘境把丹方塞进
   `pillRecipes`，也永远凑不齐材料。B11 必须先重建丹方数据。
4. **材料供给**（494 件底材，按 type 计）：金属 **58** / 宝晶 **59** / 灵植 **96**（草 34·花 21·树 23·藤 18）/
   叶 **10** / 藤 **18** / 妖兽类 **48** / 灵土 **38** / 骨材 **9** / 灵木 **9**。
   **炼阵最先见底**（骨材 9），制符次之（叶 10）。
5. **时间口径没定**：百艺 45 分钟/轮跟**游戏时钟**走；筑基 24×、金丹 168× 后一天的百艺会跟着瞬间跑完。
   飞鹰门则走**现实秒**。百艺跟哪套时钟，决定筑基/金丹后「一天炼多少轮」。

## A 类：不定就没法开工

### A1. B11 第一批的范围与顺序

**现状**

- 代码只有炼器：`plugins/arts.js` 的 `RECIPES` **3 条**（素金戒指 / 金簪 / 金钗），
  每轮随机一条，**不扣任何材料**，产物是带属性的装备。
- 炼丹 / 炼符 / 炼阵在 `ARTS` 常量里占位，`stores/modules/arts.js` 的 `setArtEnabled` 直接
  `if (art !== 'forge') return`。
- 《模块七》§十 定的 v2 第一批是「**真实扣料 + ≤1 游戏天配方**」，但没写四艺的先后。
- 封地 B14-b 的三链（酒坊 / 丹炉 / 工坊）当前产的是**抽象货物**，明确写着「B11 炼丹 / 炼器上线后再换实物」。

**要定的分叉**

1. 第一批是 ① 只重构炼器；② 炼器 + 炼丹；③ 四艺一起开；④ 先做配方/残页/熟练度底座，产物后接？
2. 封地三链要不要在第一批换成实物？还是继续保持抽象货物？
3. 百艺第一批是否包含「凡俗杂物落地」（B2 遗留代码）？

**建议**

- **第一批 = 炼器重构 + 凡俗杂物落地 + 配方/残页/熟练度底座**；炼丹放**第二小批**，
  制符 / 炼阵继续数据位。理由：残页、配方锁、熟练度是三艺共用的底座，先把一条完整链跑通，
  再复制到另外三艺；炼丹还多一道「重建丹方数据」的活（见 A3）。
- **封地三链保持抽象货物**，第一批不换实物。理由：封地是「自动低阶货源」，百艺是「玩家排班做高阶」，
  两套并存不冲突；换实物会同时改 R53 的经济账和背包体量。
- **B2 杂物必须进第一批**：它是炼器 v1→v2 的产物形态前提，单独拖一批会让炼器中间态很奇怪。

**影响**：**1.5~2 会话**；新增 `verify-arts` 或并入 `verify-dayloop` 约 15~20 条；
产出登记 **R05 / R40 数值回填**，R53 不动。

### A2. 炼器 v2 的配方、扣料与产物形态

**现状**

- v1：3 条金系一阶配方，`stats` 直接写死（攻 8 / 防 6 血 60 / 防 4 血 50 速 2），成色固定 `common`。
- B2 已定稿但**代码未落**：金饰三件改**杂物**（`tier:0`、无属性、不可装备、回收 30 大子/件），
  物品池补 4~6 件凡俗物品（粗布 / 陶器 / 粮草 / 酒 / 铁锭 / 柴薪）。
- 炼器产物 P62 后按 `baseId + 成色 + 等级` 合并成堆；杂物没有成色，合并键会退化成 `baseId`。
- 当前每轮 **1 件**，练气期 10 小时小循环里大约 **5~6 轮/天**。

**要定的分叉**

1. 配方是保留 3 件金饰改杂物，还是换成 6 件凡俗杂物？产率仍是 1 件/轮吗？
2. 每轮扣多少料：金属 / 宝晶各几件？越阶怎么放大（×2 / ×4）？
3. 失败率与返还（见 C1）在第一批就做，还是先 100% 成功？
4. 炼器还要不要产**装备**？如果暂时只产杂物，装备系统 §十七 的验算继续挂起。

**建议**

- **第一批只产杂物**：把 3 件金饰按 B2 改成杂物，再补 3 件凡俗物品（粗布 / 陶器 / 柴薪），
  **1 件/轮**不变；装备类炼器等装备系统验算（§十七）另开一批。
- **扣料 = 2 金属 + 1 宝晶/轮**（一阶），二阶配方 ×2。按 5~6 轮/天 = **10~12 金属 + 5~6 宝晶/天**，
  先用真实档统计验证够不够；不够就降到 1+1，**不要为此加掉落**（改掉落要走产出登记）。
- **失败先不做**：第一批 100% 成功，熟练度只做「降耗时」一项；成功率 / 品质放第二批。
  理由：杂物没有品质，失败率只会让玩家反复读条，不产生决策。

**影响**：**1 会话**；`verify-arts` 约 10 条；R05 / R40 回填；不动 R53。

### A3. 炼丹数据重建：旧丹方与残页机制

**现状**

- `plugins/pills.js` 有 **9 条上游丹方**（一品聚灵丹 … 九品），材料写的是 `herbs` 的旧 id
  （`spirit_grass` / `cloud_flower` / `thunder_root` / `dragon_breath_herb`）。
- 当前 494 件物品池里**没有这些 id**：`spirit_grass` / `cloud_flower` / `thunder_root` 全部查不到；
  只有 **同名物品**（灵精草 / 云雾花 / 龙息草）挂在新的灵植 id 上。**即使解锁也炼不了。**
- 解锁路径仍是「探索 / 秘境 / 事件随机塞一整本丹方进 `pillRecipes`」，与《模块七》§二
  「残页拼图解锁」冲突。
- 丹药效果有 4 类：灵力 / 修炼 / 属性 / 特殊；但**战斗系统（B10）未落地**，
  回血、攻击类丹药目前没有消费点。

**要定的分叉**

1. 旧 9 条丹方：作废归档，还是改名换 id 保留？
2. 第一批做几条丹方？效果只做**修炼类**，还是连回血/战斗类一起？
3. 解锁用整本丹方还是残页拼图？残页从哪掉？

**建议**

- **旧 9 条作废归档**（它们绑死旧 herbs 池），按新物品池**重建 4~6 条一阶丹方**。
- **第一批只做修炼类**（加修为 / 短时修炼速度），因为这是当前唯一有消费点的效果；
  回血 / 破境 / 延寿**等 B10 / B16**——尤其破境丹会直接动宪法第二章门槛，必须先登产出登记再重算。
- **解锁 = 残页拼图**（`fragmentsNeeded = 5 × 品阶 + 5`，与《模块七》§二一致）；
  残页来源第一批只挂**探索「无字石碑」同池**，宝匣 / 秘库后补。整本丹方的旧随机路径下线。

**影响**：**1.5 会话**；`verify-shop` 增丹方段约 8~10 条；产出登记**新增修炼丹收益**（先登记再定数值）；
`pills.pillFragments` 字段的去留见 C4。

### A4. 熟练度模型（P15.8）

**现状**

- 代码里**没有熟练度**：`stores/modules/arts.js` 只有 `crafted` 计数。
- 设计只给定性口径（《模块七》§四）：四档「熟练 / 精通 / 大师 / 宗师」，降耗时最多 −50%、
  提成功率、提品质；**没有经验曲线、没有阈值、没有每档具体数值**。
- 产出登记 R05 还挂着「炼器改数值时按宪法第二章重算门槛」的提醒。

**要定的分叉**

1. 经验按什么涨：完成轮数 / 成品件数 / 越阶加成？
2. 四档阈值给多少？（练气期一天约 5~6 轮）
3. 降耗时四档怎么摊（0 / −10 / −25 / −50%）？成功率和品质第一批做不做？

**建议**

- **经验 = 每完成一轮 +1**；越阶制作 ×2（第一批没有越阶则先不启用）。
- **阈值 0 / 50 / 200 / 600 轮**：按 5~6 轮/天 ≈ **9 / 36 / 108 游戏天**，
  练气期约 **0.24 / 0.96 / 2.9 现实天**；数值可调，先让「宗师」是一个可见的长期目标。
- **降耗时 0 / −10% / −25% / −50%**；成功率和品质**第二批再做**（杂物无属性，品质先无意义）。
- 熟练度**按艺独立**，不跨艺共享；四艺各自一条经验条。

**影响**：**1 会话**；新增 `verify-arts` 约 8 条；R05 数值回填；改 `TUNING` 不影响门槛。

### A5. 百艺的时间口径与封地三链的边界

**现状**

- 百艺挂在 `dayLoop` 的队列里（`practice → forge → practice → …`），每轮 **45 游戏分钟**；
  精力 **−35/天**（每艺每天一次）、体力 **−6/游戏小时**。
- 时钟三档：练气 1×、筑基 **24×**、金丹 **168×**（`gameClock.TIME_SCALE_BY_TIER`）。
  筑基后一个游戏天 = **4 现实秒**，金丹 = **0.571 现实秒**；小循环在 UI 上退场，引擎照跑。
- 飞鹰门（任务 / 秘库 / 老九）走 **`faction.realSeconds`（现实秒）**，不跟世界时钟加速。
- 封地 B14-b 三链按**游戏天**结算，成品即产即卖、不进背包。

**要定的分叉**

1. 百艺继续跟**游戏时钟**，还是改成跟**现实秒**（像飞鹰门）？
2. 筑基 / 金丹后百艺要不要降密度或加上限？
3. 百艺成品与封地三链成品是两套，还是合并？

**建议**

- **继续跟游戏时钟**：百艺是 `dayLoop` 的一部分，拆成现实秒会和队列 / 体力 / 精力打架。
- 筑基后「百艺自动跑、只在战报里看结果」是**预期行为**，写进真源；金丹 168× 下
  一天约 5~6 轮 = **约 3 轮/现实秒**，产物靠 P62 堆叠吸收，**不加额外上限**。
  若实测背包被撑爆，再按 B15-c 的灵材箱思路处理，不在 B11 提前优化。
- **两套成品并存**：封地三链 = 自动低阶货源（抽象货物、即产即卖）；百艺 = 玩家排班做实物
  （进背包、可自用 / 交任务 / 卖钱）。第一批**不合并**。

**影响**：**0.5 会话**（主要是文案与断言）；`verify-dayloop` / `verify-offline` 各补 2~3 条；
产出登记不改（时间口径不是产出增减），但要在《当前实现》§四标「预期行为」。

### B1. 配方锁与抢料优先级

**现状**

- 设计已定：排班配方所需材料进「配方锁」；药浴一键投料**自动跳过**被锁品种；
  **优先级 配方锁 > 药浴**（《模块七》§六.3 /《炼体药浴》§9.5）。
- 代码**没有配方锁**：药浴只有「品种锁」（`baseId` 一物一行）与装备 / 灵宠剔除；
  回收也没有跳过逻辑。
- 金属同时是炼器原料与药浴金系燃料，第一批真扣料后立刻会抢。

**要定的分叉**

1. 锁在哪一层：`baseId` 集合 / 整个 type（金属）/ 阶位？
2. 锁是「自动写 + 手动可改」，还是只读？
3. 回收 / 出售要不要也跳过被锁物品？

**建议**

- **锁在 `baseId` 集合**（`arts.lockedMaterials`），排班配方自动写入，玩家可在百艺页手动解除。
- **药浴一键投料自动跳过**；**手动回收不拦**（只做自动路径，避免玩家被自己锁死）。
- 第一批**只做自动跳过 + UI 标记**，不做「锁定整类」的复杂规则。

**影响**：**0.5 会话**；`verify-bath` / `verify-items` 各补 2~3 条；无数值产出变化。

### B3. 百艺的解锁条件与默认勾选

**现状**

2. 炼器默认勾选：保持现状（开）还是按 B2 改为关？

## D. 网页端可并行产出（不阻塞代码）

百艺的配方表是纯内容，不依赖任何未拍板项。建议按这个顺序：

| 优先级 | 产出 | 约束 |
|---|---|---|
| 1 | **炼器 6 件凡俗杂物配方**（名称 / 用哪类材料 / 每轮件数） | 只能用现有 494 件里的材料类型（金属 / 宝晶），**不发明新物品** |
| 2 | **炼丹 4~6 条一阶丹方**（名称 / 修炼类效果 / 材料 / 残页数） | 材料只能写**类型 + 件数**，具体物品由开发组按池子填；破境 / 延寿 / 回血先不做 |
| 3 | **熟练度四档文案**（熟练 / 精通 / 大师 / 宗师） | 只写描述，不写数值 |
| 4 | **制符 / 炼阵各 3~5 条**（可后置） | 先给「名字 + 材料类型」，不给效果数值 |

**三条纪律照旧**：一次只做一组；不自己发明数值（找不到锚点写「待定」）；
看到「已翻案」要停（尤其 B2 杂物与默认不勾）。
