二、功法系统核心机制（⚠ 新设定）

2.1 方向：装备位 + 修炼池（C 方案）

概念 作用

active 功法 只影响该功法自身升级速度，不影响门槛

已修功法池 所有炼过的功法，保留等级与效果

门槛 看历史最高契合度（已修心法中的最高值 + 通用心法加成）

2.2 心法：取最高

所有已修心法中，取契合度最高的那本生效。

例：A 心法 20 级 50%、B 心法 5 级 60% → 取 60%。

通用心法：加全局契合度，可与其他心法叠加。加值「随品阶和修炼等级增加，可叠加，加值不能太高」。

⚠ 通用心法的具体加值，等品阶分和门槛重算后倒算（交数值组）。

2.3 非心法：叠加 + 软上限 B

法术 / 身法 / 炼体 / 器诀：每本都生效，叠加，走软上限 B（渐近）：

```
总加成 = cap × (1 − e^(−原始/cap))
```

与子嗣加成、陨落词条 A 类同一套公式。

⚠ cap 具体值交数值组（功法库文档 §7.5 建议：攻击 +80% / 速度 +60% / 血防 +80%，待定）。

2.4 器诀：熟练度增加对应装备的百分比属性

器诀的「熟练度」= 功法等级。

效果：按功法等级，增加对应类型装备的百分比属性，类似词条效果。

⚠ 具体百分比、是否只加对应类型（如剑诀只加剑）、与词条加算还是乘算——交数值组。

2.5 修炼速度完全取决于契合度

功法库文档 §7.3 的「心法 → 修炼速度 +5% × coef」作废。

功法对修炼速度的影响，完全通过契合度（0.98 + 0.32×Fit）体现。不存在独立的「心法速度加成」。

2.6 效果系数（§7.2）保留给非心法

· 心法：走契合度，§7.2 的 coef 不用于心法

· 非心法：保留 §7.2 的 coef + §7.4 的等级成长公式

```
totalAtMax = categoryBase × coef

valueAtLevel(L) = totalAtMax × L / maxLevel
```

⚠ categoryBase（占位 5%/4% 等）与 coef 具体值交数值组。

三、契合度公式（⚠ 改造）

3.1 现行公式（改造前）

```
功法契合 = 品阶分 + 覆盖率 × 40%

覆盖率 = |功法 elements ∩ 修士灵气| / |修士灵气|
```

3.2 改造后

项 变化

品阶分 从三档改为十六档指数分布（§1.3）

心法等级加成 加到品阶分（A 方案），固定值/级，不加覆盖率

覆盖率 公式不变

门槛 看历史最高契合度（已修心法 max + 通用加成）

⚠ 心法等级加品阶分的固定值（如 +0.005/级）交数值组。

3.3 门槛重算（待重算）

现行门槛 0.15 / 0.24 / 0.35 / 0.40 / 0.76 是按「三档品阶分 + 覆盖率 × 40%」反推的。改成十六档 + 等级加成 + 通用心法后，门槛必须重新验算。

⚠ 四阶极品品阶分 0.50 + 覆盖率 1.0 × 40% = 0.90，远超筑基门槛 0.40 —— 是设计意图还是门槛要抬，待重算时定。
