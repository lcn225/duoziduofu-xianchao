# 模块九：离线结算系统设计方案

## 一、模块定位

离线结算系统是放置游戏的核心体验闭环。玩家离线时，各模块自动运转；上线后，系统汇总所有变化，生成一份**综合离线报告**。

**核心循环**：离线 → 各模块自动结算 → 上线 → 查看离线报告 → 处理事件队列 → 调整策略 → 再次离线。

---

## 二、离线结算范围

### 2.1 各模块离线行为

| 模块   | 离线行为        | 结算周期  |
| ---- | ----------- | ----- |
| 修行突破 | 自动积累灵力      | 每秒    |
| 多子多福 | 子嗣成长、人口繁育   | 每天    |
| 内宅姻缘 | 侍妾状态变化、精力恢复 | 每天    |
| 封地经营 | 资源产出、建筑建设   | 每天    |
| 任务战斗 | 进行中任务结算     | 到期    |
| 经济交易 | 商队贸易、投资分红   | 到期/每月 |
| 事件叙事 | 事件触发、排队     | 每天    |

### 2.2 离线效率

```
离线效率 = 基础效率 0.8 
         × 内宅稳定度系数 
         × 洞府等级系数 
         × 侍妾技能加成
```

| 因素          | 系数   |
| ----------- | ---- |
| 内宅稳定度 90+   | ×1.2 |
| 内宅稳定度 70-89 | ×1.1 |
| 内宅稳定度 50-69 | ×1.0 |
| 内宅稳定度 30-49 | ×0.9 |
| 内宅稳定度 0-29  | ×0.8 |
| 洞府等级 5      | ×1.3 |
| 洞府等级 3-4    | ×1.2 |
| 洞府等级 1-2    | ×1.0 |
| 侍妾温婉技能      | +5%  |
| 侍妾灵茶妙手      | +10% |

**离线效率上限 1.5，下限 0.4。**

## 四、离线结算流程

### 4.1 结算步骤

1. **记录离线时间**：关闭页面时写入 `lastOnlineTime`。
2. **计算离线时长**：上线时 `offlineDuration = now - lastOnlineTime`。
3. **计算离线效率**：根据内宅稳定度、洞府等级、侍妾技能。
4. **逐模块结算**：
   - 修行：灵力积累 = 离线秒数 × 灵力/秒 × 离线效率
   - 封地：资源产出 = 离线天数 × 产出/天 × 离线效率
   - 子嗣：成长 = 离线天数 × 成长速度
   - 内宅：侍妾状态变化、怀孕判定、精力恢复
   - 任务：到期任务结算
   - 经济：商队收益、投资分红
   - 事件：按概率触发，进入队列
5. **汇总报告**：生成离线报告，按优先级排序。
6. **弹出事件队列**：优先处理紧急事件。
7. **更新存档**：写入新状态。

### 4.2 离线时长上限

| 时长      | 效率   |
| ------- | ---- |
| 0-8 小时  | 100% |
| 8-24 小时 | 90%  |
| 1-3 天   | 80%  |
| 3-7 天   | 70%  |
| 7-30 天  | 60%  |
| 30 天以上  | 50%  |

**上限 30 天，超出部分不再结算。**

## 八、可玩性设计要点

1. **离线报告是核心爽点**：上线时看到资源入库、子嗣诞生、事件触发，像开盲盒。
2. **离线效率可优化**：内宅稳定度、洞府等级、侍妾技能，玩家可主动提升。
3. **离线时长有上限**：超过 30 天效率降至 50%，鼓励定期上线。
4. **事件队列是主要叙事载体**：离线触发事件，上线集中处理。
5. **批量处理节省操作**：低优先级事件可一键处理。
6. **离线报告分板块**：修行、子嗣、内宅、封地、任务、经济、事件，清晰明了。
7. **离线报告可查看详情**：每个板块可展开查看具体变化。
8. **离线事件有优先级**：紧急事件立即处理，低优先级可延后。
9. **离线效率与内宅联动**：内宅稳定度高时离线效率高，形成正反馈。
10. **离线结算与各模块深度联动**：子嗣成长、封地产出、商队收益、事件触发。
