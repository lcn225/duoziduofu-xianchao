# Q2 · 探索动画播片方案 v1.0

> 2026-10-22 定稿。解决探索页“没有动画”的问题。

> 本文只定**播片方案**（什么时候播、播什么、切页/后台怎么处理），不定动画素材本身。

---

## 一、核心机制

**横版卷轴跑酷：背景跑，人物原地踏步；事件触发时背景停，人物换动作。**

```
常态：背景向左无缝滚动 + 人物播 walk（原地踏步）

事件：背景暂停 + 人物切到对应动作 + 播完切回 walk
```

---

## 二、素材清单

| 动画 | 用途 | 状态 |

|---|---|---|

| walk（走路） | 常态循环 | 新画 |

| loot（拾取） | 采集/拾遗事件 | 新画 |

| fight（战斗） | 战斗事件 | 新画 |

| rest（休息） | 休息/空包事件 | 新画 |

| 倒地 | 战败 | 新画（没有则复用 rest） |

| 背景图 | 无缝滚动（黄土高原） | 新画 |

**素材不在本方案范围内**，本文只定播片逻辑。

---

## 三、事件 → 动画映射

| 事件类型 | 动画 | 时长（参考） |

|---|---|---|

| 采集灵植 / 废弃矿洞 / 拾遗 | **loot** | 2–3 秒 |

| 妖兽袭击 / 劫修拦路 / 战斗 | **fight** | 3–4 秒 |

| 休息 / 一无所获 / 空包 | **rest** | 3–5 秒 |

| 战败 | **倒地** | 配合养伤读条 |

| 叙事弹窗 | **停在当前动画**，弹窗覆盖 | 20 秒超时（Q1） |

**普通事件（非叙事）**：只进流水账，**不阻塞 UI**，播完动画即恢复 walk。

---

## 四、结算与动画解耦（核心原则）

**结算走 `gameClock` 的 tick，动画只是表现层。**

| 错误做法 | 正确做法 |

|---|---|

| `setTimeout` 调度下一次事件 | `gameClock` 按游戏时间推进，到点结算 |

| 动画播完才结算 | 结算先发生，动画后播（或同时） |

| 后台时 `setTimeout` 被节流，事件节奏乱 | 后台时钟照走，事件按游戏时间结算 |

**这条不满足，后台/切页会出 bug。**

---

## 五、切页与后台处理

### 5.1 切页

**探索页没有 `keep-alive`**，切页时组件销毁，`<video>` 元素移除，动画自然停。**不需要额外代码。**

### 5.2 后台

监听 `document.visibilitychange`：

```
隐藏时：

所有 video.pause()

背景 animation-play-state: paused

记录「已结算但未播」的事件（不补播）

显示时：

所有 video.play()

状态机强制重置到 walk

清空未播的事件动画队列（历史只进日志）

背景滚动恢复
```

### 5.3 不补播

后台期间结算的事件**不补播动画**，只进日志。切回直接 walk。

**理由**：后台 1 小时可能几十个事件，补播会积压且状态错乱。

## 六、叙事弹窗（配合 Q1）

| 项 | 定稿 |

|---|---|

| 弹窗形态 | 阻塞 UI，**不暂停时钟** |

| 超时 | 20 秒自动选善意 |

| 积压 | 排队，上限 3 个，超了最旧的自动善意 |

| 动画 | **停在当前动画**，弹窗覆盖；选完恢复 walk |

| 日志 | 记「你选择相助（超时自动）」 |

---

## 七、技术实现要点

| 点 | 做法 |

|---|---|

| 视频切换 | `visibility: hidden`（不用 `display: none`），避免重新缓冲 |

| 视频预加载 | 页面加载后所有 video `play()` 再隐藏，切换瞬间呈现 |

| 背景无缝 | 两张背景图交替滚动，或单图 `translateX` 循环 |

| 影子 | 人物底部加椭圆半透明 div，增强“踩地”实感 |

| 防滑步 | 事件触发时背景必须停（`.paused`），否则人物边平移边打怪 |
