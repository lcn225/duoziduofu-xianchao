## 二、页面布局

```
【子嗣】
┌──────────────────────────────────────────┐
│ 统计条：总数 / 有灵根 / 可出战 / 已传 N 代  │
├──────────────────────────────────────────┤
│ ┌─────────────┐ ┌─────────────┐          │
│ │ 历练汇报     │ │ 家族工作汇报 │          │
│ │ （实时更新） │ │ （实时更新） │          │
│ └─────────────┘ └─────────────┘          │
├──────────────────────────────────────────┤
│ ┌──────────────────────────────────────┐ │
│ │ 子嗣主表（全宽，12 列）                │ │
│ │ 姓名/阶段/境界/历练岗位/状态/加成/…    │ │
│ └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

- **汇报区在上**：主表可超长，放下方更难看到；主表排序后通常只看前几行。
- **主表全宽**：12 列信息多，独占一行。
- **窄屏**：汇报区上下堆叠，主表退回卡片。

## 三、家族树

### 3.1 树形态

纵向缩进树，每代缩进一层，节点可折叠。

```
▾ 桂冈
  ▾ 侍妾 A（萧金桂）
    ▾ 桂大（练气五层）
      ▾ 桂大之妻（儿媳）
        · 桂小一（练气二层）
        · 桂小二（凡人）
    · 桂二（凡人）
    · 桂三（已外嫁）
  ▾ 侍妾 B（丁赛喜）
    · 桂四（练气三层）
```

### 3.2 节点显示

| 类型    | 显示                 |
| ----- | ------------------ |
| 桂冈    | 姓名 + 境界            |
| 侍妾    | 姓名 + 位阶            |
| 有灵根子嗣 | **姓名（境界）** + 状态符号  |
| 无灵根子嗣 | **只有姓名**（凡人无境界）    |
| 配偶    | 姓名（标注「儿媳」或「女婿」）    |
| 已外嫁女儿 | 姓名 + 「已外嫁」标记，不展开   |
| 陨落    | 姓名 + 状态符号（如 ✝），不展开 |

**状态符号**：

- 🟢 存活
- ✝ 陨落
- 💍 已外嫁
- 🏠 已分家（未来）

### 3.3 挂载规则

| 代    | 挂载依据                |
| ---- | ------------------- |
| 第一代  | 按**生母**（侍妾）分组，挂在桂冈下 |
| 第二代+ | 按**生父**挂载；生母用来反查生父  |
| 女儿   | 显示节点，不展开后代          |

### 3.4 折叠规则

- 默认只展开桂冈 + 第一代。
- 点击节点展开/折叠该分支。
- 626 人规模下，默认折叠是必须的，否则节点爆炸。
