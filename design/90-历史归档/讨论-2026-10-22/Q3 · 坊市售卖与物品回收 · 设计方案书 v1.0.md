## 三、卖出：物品回收

### 3.1 回收价公式

```
回收价 = 物品折价 × 30%

物品折价 = 基础价(tier) × 成色系数(quality)

成色系数：下 1.0 / 中 1.2 / 上 1.5 / 极 2.0
```

### 3.2 可卖 / 不可卖

| 类型 | 可卖 | 说明 |

|---|---|---|

| 灵器（未装备、未锁定） | ✅ | |

| 灵兽（未装备、未锁定） | ✅ | |

| 灵植（未锁定） | ✅ | |

| 灵材（未锁定） | ✅ | |

| 灵器（装备中） | ❌ | 需先卸下 |

| 任意（品种锁） | ❌ | 锁定的不卖 |

| 特殊道具 | ❌ | Q2 定稿 |

| 残页/功法 | ❌ | 定价表 §七 |

| 宝匣 | ❌ | 宝匣单独走“卖宝匣”还是只能开？见 §3.4 |

### 3.3 单件卖出

背包/坊市里每件物品旁一个「卖」按钮，点击卖出，弹确认。

### 3.4 宝匣能不能卖？

**Q4 定价表只定了“买价”，没定“卖价”。** 两个选项：

| 选项 | 含义 |

|---|---|

| **A · 宝匣也能卖** | 按买价的 30% 回收（如 1 阶卖 0.3 二阶） |

| **B · 宝匣只能开** | 不能卖，只能开或合成（合成已砍） |

**需要你定。** 我推荐 B：宝匣是“买来开”的，不是“买来倒卖”的。能卖会引入套利路径（低买高卖）。

## 四、一键售出

### 4.1 范围

**全部未锁定物品**，包括灵器/灵兽/灵植/灵材。

**排除**：

- 装备中的物品

- 品种锁定的物品

- 特殊道具

- 残页/功法

- 宝匣（如果 §3.4 选 B）

### 4.2 流程

```
点击「一键售出」

→ 弹确认框：「将卖出 N 件物品，合计 X 二阶，确认？」

→ 确认 → 逐件卖出，灵石入账

→ 结果提示：「已售出 N 件，获得 X 二阶」
```

### 4.3 防误操作

- 确认弹窗必须显示**件数 + 总价**。

- 装备中的物品**自动排除**，不需要玩家手动卸。

- 锁定的物品**自动排除**。

- 卖完后如果背包还有可卖的（比如新开出来的），再点一次即可。

## 五、灵石开箱

**开箱掉落的灵石直接进 `currency.spiritual`**，不变成物品，不走卖。

**理由**：灵石是货币，不是物品。走卖会让玩家多一步操作，且回收价 30% 会让灵石贬值。
