## 一、核心定位与基础规则

| 项 | 定稿 |
|---|---|
| **定位** | 基础资源产出地：灵石、基础材料、低概率宝匣 |
| **双轨制** | 桂冈亲征（动画 + 流水账）/ 子嗣历练（后台日结报表） |
| **互斥** | 桂冈探索时，镇守练功/百艺停止；封地产出、子嗣繁衍照常 |
| **安全** | **绝不产生不可逆陨落**（战败只养伤） |
| **结算频率** | 每 **1 游戏时辰（2 游戏小时）** 结算 1 次，一天 **12 次** |
| **模式** | **持续挂机**，手动停止或战败养伤 |
| **越阶** | 禁止去高于自身境界的地图 |
| **产出铁律** | **阶看境界段，段内高低阶看地图深度**（§2.4）；宝匣只出现在极低概率事件 |

> 时钟不暂停，按游戏时间结算（当前 1 现实秒 = 0.25 游戏小时；1 游戏小时 = 4 现实秒）。
> 「每时辰一次」= 每 2 游戏小时 = 8 现实秒出一次结算。
>
> ⚠ **12 次/天是名义值**：同境界战败率 70% 会截断当天剩余事件，加上养伤半天，
> 长期实际约 **7.33 事件/天**（高 1 小境界约 7.77、高 2 小境界才是 12）。
> R10 的经济期望必须按实际值复核，详见
> 《[数值真值表](../00-总览与状态/数值真值表.md)》§6.3。

### 2.4 掉落阶（2026-10-22 P30 定稿）

**阶看玩家/子嗣自己的境界段，不看地图；地图只决定段内**高低阶的概率。

| 境界段 | 等级 | 低阶 | 高阶 |
|---|---|---:|---:|
| 练气 | 1~10 | 一阶 | 二阶 |
| 筑基 | 11~14 | 二阶 | 三阶 |
| 结丹 | 15~18 | 三阶 | 四阶 |

- 段内取哪一档 = 地图的**段内高阶概率**（§2.1 最后一列；代码 `locations.highTierChance`）。
- 物品和**宝匣走同一条**：练气段最多二阶，练气六层**不再掉三阶**。
- 特例：`tierPolicy: 'high'`（妖兽头目）恒取段内高阶，`'low'`（部分采集）恒取段内低阶。
- ⚠ **预期行为不是 bug**：练气段拿不到三/四阶物品。筑基/结丹图开放前，三阶以上物品只有秘境高难度宝匣（秘境宝匣阶按**难度**，不按境界，见《三大挂机》§4.3）。物品池的骨材最低二阶，`pickBaseItemForEvent` 会**宁可换阶也不换类型**，所以长岭乡外仍可能掉二阶骨材。
- 旧口径「地图阶 = 物品阶」（长岭关外 = 三阶材料）是旧版「探索地等级」表的残留，2026-10-22 作废。

## 五、宝匣规则

### 5.1 宝匣来源（探索侧）

- **常规事件不给宝匣**，只有古修洞府（1%）给 1 个。
- 宝匣阶级按 **玩家境界段**，不按地图的绝对阶；段内低阶/高阶的概率**跟地图深度走**（§2.4、§2.1）：

| 玩家境界段 | 宝匣阶级 | 段内高阶 |
|---|---|---|
| 练气 | 1~2 阶 | 0% / 30% / 60% / 90%（长岭乡外 → 飞鹰镇外） |
| 筑基 | 2~3 阶 | 同上 |
| 结丹 | 3~4 阶 | 同上 |

> 2026-10-22 P30 改：旧口径是「段内各 50%」，现在深图更容易给高阶。
> 元婴行已删：境界只到结丹圆满（18 级），没有元婴段。
>
> 宝匣的 TC 树、成色与开箱规则见《[宝箱系统](宝箱系统.md)》。
> 全局宝匣来源汇总见《宝箱系统》§一。
>
> **代码落点（2026-10-20）**：宝匣进 `inventory.chests`，按阶级计数（`{1..7}`），
> 不生成物品实例；古修洞府**事件命中即给 1 个**，不再二次掷概率。
> 开箱 UI 未做，背包「宝匣」页签只展示数量。

### 5.2 战斗类掉落

- 骨材 / 妖丹 / 兽皮 / 毒囊（归灵材 `骨材` type）。
- 灵石（少量）。
- 比采集类多 **50–100%**，符合风险回报。

5. **出战门槛**：受「有灵根 + 练气二层」限制。
6. **报表位置**：子嗣页顶部卡片；内宅日志另写一条聚合摘要。
7. **同时上限**：10 人（每名子嗣产出约桂冈的 80%，不限会线性打穿经济）。

### 9.2 探索动画（✅ 2026-10-22 Q2 定稿）

**核心机制**：横版卷轴跑酷 —— 背景向左无缝滚动，人物原地踏步；事件触发时**背景暂停**、
人物切到对应动作，播完切回 walk。

```
常态：背景向左无缝滚动 + 人物播 walk
事件：背景暂停 + 人物切到对应动作 + 播完切回 walk
```

**事件 → 动画映射**：

| 事件类型 | 动画 | 参考时长 |
|---|---|---:|
| 采集灵植 / 废弃矿洞 / 拾遗 | loot | 2–3 秒 |
| 妖兽袭击 / 劫修拦路 / 战斗 | fight | 3–4 秒 |
| 休息 / 一无所获 / 空包 | rest | 3–5 秒 |
| 战败 | 倒地（没素材时复用 rest） | 配合养伤读条 |
| 叙事弹窗 | **停在当前动画**，弹窗覆盖 | 20 秒超时（§9.1） |

**硬要求：结算与动画解耦。** 结算走 `gameClock` 的 tick，动画只是表现层。
**不要**用 `setTimeout` 调度下一次事件；**不要**等动画播完才结算。后台时时钟照走、
事件按游戏时间结算 —— 这条不满足，切页/后台会出 bug。

**切页与后台**：

| 场景 | 处理 |
|---|---|
| 切页 | 探索页没有 `keep-alive`，组件销毁、`<video>` 移除，动画自然停；**不需要额外代码** |
| 后台（`visibilitychange` 隐藏） | 全部 `video.pause()`；背景 `animation-play-state: paused`；记录「已结算但未播」 |
| 回到前台 | 全部 `video.play()`；状态机强制重置到 walk；清空未播动画队列（历史只进日志）；背景恢复 |
| 不补播 | 后台期间结算的事件**不补播**，只进日志。后台 1 小时可能几十个事件，补播会积压错乱 |

**技术要点**：视频切换用 `visibility: hidden`（不用 `display: none`，避免重新缓冲）；
页面加载后所有 video 先 `play()` 再隐藏，切换瞬间呈现；背景两张图交替或单图 `translateX`
循环；人物底部加椭圆半透明影子；**事件触发时背景必须停**，否则人物会边平移边打怪。

> **子嗣历练不做动画**（后台日结报表）。`components/DayAnimation.vue` 不复用，探索页单独做。
