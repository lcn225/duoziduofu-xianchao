一、核心框架

1.1 一天的时间结构

```
晨起 6:00

↓

巡视乡间（默认 2 小时，可调 1~5 小时）

↓

小循环（8:00 开始，18:00 下班）

练功（1h）→ 百艺（45m~1h）→ 练功（1h）→ 百艺 → …

下班前能完成几轮算几轮

正在执行的任务必须完成才下班

↓

妻妾互动（下班后，到体力耗尽 / 主动停止 / 天亮）

↓

睡觉（剩余时间）

↓

次日 6:00 上班
```

1.2 双资源系统

资源 上限 恢复方式 消耗方式 作用

精力 100（固定，不随炼体涨） 打坐 +10/h，睡觉 +5/h 百艺 决定能不能做百艺

体力 145 起（公式见 §4.3，无硬上限） 睡觉 +体力上限/4 每小时（4 小时回满） 所有活动 决定能不能做事、能不能互动

设计意图：

· 精力管脑力，体力管身体

· 精力耗尽 → 打坐一轮后提前下班

· 体力耗尽 → 自动睡觉

三、小循环机制

3.1 队列生成

按勾选的百艺，生成循环队列：

练功（1h） → [炼体（1h）] → 百艺1（45m） → 百艺2（45m） → … → 百艺N（45m） → 练功（1h） → 循环

⚠ 「炼体」是**独立勾选项**（1h/轮，不占百艺轮次），勾选后插在「练功」和「百艺」之间。

勾选百艺数 队列

0 个 练功 → 练功 → 练功 → …

勾选炼体 练功 → 炼体 → 练功 → 炼体 → …

1 个 练功 → 百艺 → 练功 → 百艺 → …

N 个 练功 → 百艺1 → 练功 → 百艺2 → … → 练功 → 百艺N → 循环

3.2 轮次计算（10 小时小循环）

一个完整周期 = 练功 1h + N × 45m（勾选炼体时再加 1h）。

勾选百艺数 周期时长 完整周期数 练功轮次 百艺轮次

0 — — 10 0

1 1.75h 5（余 1.25h） 6 5

2 2.5h 4（余 0） 4 各 4

3 3.25h 3（余 0.25h） 3 各 3

4 4h 2（余 2h） 3 各 2~3

5 4.75h 2（余 0.5h） 2 各 2

⚠ 旧表把百艺当 1h 算，1 个百艺那行写的 5/5 是错的 —— 45m 下应为 6 练功 + 5 百艺（余 1.25h 够再开一轮练功）。

勾选「炼体」时，周期 = 练功 1h + 炼体 1h + N × 45m，每周期另得 1 次炼体：

勾选百艺数 周期时长 练功轮次 炼体轮次 百艺轮次

0 2h 5 5 0

1 2.75h 4 3 各 3

2 3.5h 3 3 各 2~3

3.3 精力耗尽处理

如果白天精力耗尽：

```
打坐一轮（1 小时，+10 精力）→ 放弃当天剩下的工作安排 → 提前下班
```

跳过剩余小循环。

⚠ 旧版写的是「自动打坐 → **精力回满** → 直接下班」，那是错的：打坐就是练功（+10 精力/小时），
从 0 回满要 10 小时，根本不叫「直接下班」。**现在是打坐一轮就走人**，当天剩下的工作安排全部放弃。

四、体力权衡

4.1 核心取舍

一天体力总量固定（开局 145）。玩家决定白天花多少，晚上留多少。

白天策略 白天消耗 剩余体力 互动次数 睡眠

全天练功 50 95 6 次 9h

练功+2 百艺 80 65 4 次 10h

练功+4 百艺 90 55 3 次 10.5h

全天炼体 170 0 0 次 12h

4.2 子嗣与体力

子嗣出生率 = 互动次数 × 怀孕概率。

选择 后果

白天多干活 体力耗尽，晚上互动少，子嗣少

白天少干活 体力充足，晚上互动多，子嗣多，睡眠少

想多生子嗣，就得白天少干活。

4.3 睡眠与次日恢复

**体力恢复 = min(睡觉时长 × 体力上限/4, 体力上限)** —— 4 小时回满，不足 4 小时按比例。

⚠ 本节此前写的是「+20/h，7.25 小时回满」，已被「上限/4 每小时」取代（2026-10-16 定案）。

睡眠时长 体力恢复（上限 145） 精力恢复

12h 回满 +60

9h 回满 +45

7.5h 回满 +37.5

6h 回满 +30

4h 回满 +20

3h 108.75 +15

2h 72.5 +10

1h 36.25 +5

**夜晚结构**：18:00 下班 → 妻妾互动（每次 1h、体力 20）→ 睡觉（剩余时间）→ 6:00 上班。夜晚共 12 小时。

| 互动次数 | 互动时长 | 睡觉时长 | 恢复 |
|---:|---:|---:|---|
| 0 | 0h | 12h | 回满 |
| 4 | 4h | 8h | 回满 |
| 8 | 8h | 4h | 刚好回满 |
| 10 | 10h | 2h | 50% |
| 12 | 12h | 0h | 0 |

**临界点：8 次互动 = 8h 互动 + 4h 睡觉 = 刚好回满。** 超过 8 次，次日体力按比例减少。
（旧设计是 0.5h/15 体力、16 次临界；2026-10-17 改为 1h/20 体力后，临界点降到 8 次。）

**体力上限 = 145 + 外功加成**：

| 外功段 | 每级加成 | 段末上限 |
|---|---:|---:|
| 炼体一~十层 | +3 | 172 |
| 锻骨初/中/后/圆满 | +6 | 196 |
| 洗髓初/中/后/圆满 | +9 | 232 |
| 超级炼体（19 级起） | +25 | 357~382 |

精力上限恒 100，不随炼体涨。当前开局体力上限 145，最多互动 9 次，**前期不会触发次日体力不足**；
后期炼体加上限后才出现（外功 23~24 级开始）。前期互动受体力限制，后期受时间限制。

玩家可主动提前停止互动，换取更多睡眠。

十二、设计原则

原则 说明

练功是主业 1h/轮，恢复精力

炼体独立 1h/轮，消耗体力高

百艺是副业 45m/轮，消耗精力

玩物丧志 勾选越多百艺，练功轮次越少

巡视加班 巡视时间越长，小循环越短

双资源 精力管百艺，体力管互动

体力权衡 白天多干活 → 晚上互动少 → 子嗣少

睡眠权衡 多睡补体力 vs 少睡多互动

主界面收日常 观战型放主界面，配置型放独立页

十四、与现有代码的对应（命名约定）

新设计的两条资源跟现有代码里的名字**打了一架**，先把对应关系钉死：

新设计 代码现状 关系

精力（上限 100；百艺消耗；打坐 +10/h、睡觉 +5/h） 无 全新资源
体力（145 起；所有活动消耗；睡觉恢复） innerCourt.energy（代码仍是上限 100 + 炼体×5、每次互动 −15、每游戏天回满） **同一个东西** —— 都是「互动 −15」那个节流阀；设计值已改为 145 起、20/次、睡觉恢复

定死：

· **代码里的 `innerCourt.energy` 语义上就是新「体力」。** 它的值和存档都不动，只把**中文标签**从「精力」改成「体力」，上限由 TUNING 从「100 + 炼体×5」调到「145 起」。

· **新「精力」是另一回事**（百艺的脑力），代码里另开字段（建议 `focus`），**不要复用 `energy`**。理由：把 `energy` 的语义从「体力」静默翻成「精力」，同一个键两套含义最容易出鬼。

· 落地时机：等 P10（桂冈的一天）真开工时一起改。**现在不动代码。**

⚠ 在 P10 开工前，别用 `energy` 表示新「精力」，也别用「精力」表示那个 −15 的节流阀 —— 两边都会埋雷。
