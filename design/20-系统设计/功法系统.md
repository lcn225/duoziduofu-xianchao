## 二、属性与大类

### 2.1 属性：七选

**金 / 木 / 水 / 火 / 土 / 兽 / 器**，可多选。另有两种特殊标记：

| 标记 | 写法 | 含义 |
|---|---|---|
| 通用 | `elements: ["通用"]` | 所有修士视同**完全匹配** |
| 无属性 | `elements: []` | 不锁属性；契合度按**中性**处理（口径见 §八 #9） |

**原表非七选值映射**：通用 → `["通用"]`；青玉 → 土；碧火 → 火；风雷电 → 木+金+火；
养魂木 → 木；阳极水 → 水+火；硫磺地火 → 火+土；独眼银斑蛇 → 兽。

> ⚠ **兽 / 器 算不算修士灵根**：桂冈是兽 + 器双灵根，所以本项目**算**。
> 原方案 §8.5 第 4 条提的「灵根只有五行」不成立，别照抄。

## 三、契合度公式（改造）

### 3.1 改造前（现行，2026-10-28 B7 口径）

```
功法契合 = 品阶分（三档 0.20/0.30/0.40）+ 覆盖率 × 40%
覆盖率   = |功法 elements ∩ 修士灵气| / |修士灵气|
```

综合契合度 = 功法契合 × 同参契合 × 灵地契合（《模块一》§4.1）。

### 3.2 改造后

| 项 | 变化 |
|---|---|
| 品阶分 | 三档 → **十六档指数分布**（§1.3） |
| 心法等级加成 | **加到品阶分**（A 方案），固定值/级，**不加覆盖率**（值见 §八 #2） |
| 覆盖率 | 公式不变 |
| 门槛 | 看**历史最高**契合度：已修心法里的 max + 通用心法加成 |

> ### ⚠ 2026-10-30 拍板：**心法等级算进契合度，也就是算进门槛**
>
> 用户的模型是「**修炼心法 → 契合度涨 → 门槛更容易过**」，按这个执行。
> 这条**推翻了 2026-10-28 B7 的「熟练度只加速（SpeedFit），不帮门槛（GateFit）」**，
> 也推翻了 CLAUDE.md 那条硬口径（已改）。
>
> **同时把「熟练度」和「心法等级加成」合并成一项**，不能并存 —— 代码里它们本来就是同一把时钟：
> `hoursPerLevel = 100`（100h 一层）与 `profPer50Hours = 0.01 / profCap = 0.2`（50h +1%、上限 20%）
> **在 1,000 小时同时到顶**（T1 十层 = 20%）。并存 = 同一段时间算两遍加成。
> 合并后只剩：**每级 +X（§八 #2），上限 = 该功法 `maxLevel`**。
>
> ⚠ **代价（P56 必须吸收）**：现有开局 `品阶 0.20 + 熟练度满 0.20 = 0.40`，
> × 同参 0.541 × 灵地 1.0 = **0.216**，早就过了练气三层的 0.15 ——
> 也就是说**不动功法、纯挂机一小时就能自己过三层**，§6.2「练气三层换功法」的引导会消失。
> 所以十六档门槛重算时**必须把等级加成算进去**（抬高各槛，或压低每级值），
> 否则「一槛一换」的路线整条塌掉。

### 3.3 门槛重算（**待重算，P56**）

现行门槛 `0.15 / 0.24 / 0.35 / 0.40 / 0.76`（《模块一》§6.1）是按「三档品阶分 + 覆盖率 × 40%」
反推的。改成十六档 + 等级加成 + 通用心法后**必须重新验算**。

> ⚠ **四阶极品 = 0.50 + 覆盖率 1.0 × 40% = 0.90**，远超筑基门槛 0.40。
> 是「设计意图」还是「门槛要抬」，**留到重算时定**，现在不倒推。

## 四、已修功法池（**C 方案：装备位 + 修炼池**，⚠ 新设定）

| 概念 | 作用 |
|---|---|
| **active 功法** | **只影响该功法自身的升级速度**，不影响门槛 |
| **已修功法池** | 所有炼过的功法，保留等级与效果 |
| **门槛** | 看**历史最高**契合度（已修心法 max + 通用心法加成） |

### 4.1 心法：取最高

所有已修心法中，**取契合度最高的那本生效**。
例：A 心法 20 级 50%、B 心法 5 级 60% → 取 60%。**不叠加**。

**通用心法**是例外：加**全局契合度**，可与任意心法叠加。
「随品阶和修炼等级增加，可叠加，**加值不能太高**」—— 具体值等门槛重算后倒算（§八 #3）。

### 4.2 非心法：叠加 + 软上限 B

法术 / 身法 / 炼体 / 器诀：**每本都生效，叠加**，走软上限 B（渐近）：

```
总加成 = cap × (1 − e^(−原始/cap))
```

**与子嗣加成（R07）、陨落词条 A 类同一套公式**，cap 各自取（§八 #4）。

### 4.3 器诀：熟练度 → 对应装备的百分比属性

器诀的「熟练度」= **功法等级**。效果 = 按等级增加**对应类型装备的百分比属性**，类似词条。
只加对应类型（如剑诀只加剑）、与词条加算还是乘算 —— **交数值组**（§八 #5）。

### 4.4 UI：软上限感知

- **平时只显示当前值**（法术攻击 +42%），不显示上限。
- **超过 70% 上限后**追加一行「收益递减」提示（文案待定，不出戏）。
- **不显示精确上限、不改公式、不引入分段公式。**

## 五、效果系数（只给非心法）

### 5.1 比较口径

- 以**满级总效果**比较；同阶同类别 `peak > high > mid > low` 严格成立。
- 跨阶锚点：**二阶下品满级 ≈ 一阶极品满级**。
- 未满级：`当前效果 = 满级总效果 × 当前等级 / maxLevel`。

### 5.2 品阶系数

```
qIndex = low:0, mid:1, high:2, peak:3
score  = 3×(tier−1) + qIndex
coef   = 1.12^score        // 1.000 ~ 3.896
```

### 5.3 类别基准（占位，§八 #6 / #7）

| category | 主效果 | 一阶下品满级基准 |
|---|---|---|
| 心法 | ~~修炼速度~~ → **走契合度**（§六） | — |
| 法术 | 攻击 `+5% × coef` | 待数值组 |
| 身法 | 速度 `+5% × coef` | 待数值组 |
| 炼体 | 气血 `+4% × coef` + 防御 `+2% × coef`（2:1） | 待数值组 |
| 器诀 | 装备百分比（§4.3） | 待数值组 |

```
totalAtMax   = categoryBase × coef
valueAtLevel(L) = totalAtMax × L / maxLevel
```

### 5.4 叠加与软上限建议

1. 同 effectType **加算**：所有法术攻击先加总，再套软上限。
2. 跨系统 **乘算分区**：功法总加成 × 装备总加成 × 灵根 / 丹药总加成。
3. 条件效果（「配合本命 / 阵法」）**一期只保留文字**，不进数值；二期再加 `conditional` 字段。
4. 软上限建议（**待定**）：修炼速度 +100% / 攻击 +80% / 速度 +60% / 血防 +80% / 熟练度 +100%。

## 六、修炼速度 = 只看契合度（⚠ 翻案）

**方案文档 §7.3 的「心法 → 修炼速度 +5% × coef」作废。**

功法对**桂冈修炼速度**的影响，**完全通过契合度**体现：

```
修炼速度系数 = 0.98 + 0.32 × Fit
```

**不存在独立的心法速度加成**。心法的价值在于**抬高 Fit 过门槛**，不在直接加速度。

> 与 §五 的关系：§五 的 `coef` 只给**非心法**用；心法不进 §五。

## 七、功法残页（2026-10-30 定稿）

### 7.1 只有心法有残页

| 类别 | 外面掉（探索） | 秘库卖 |
|---|---|---|
| **心法** | **残页** | **整本**（2026-10-30 拍板，秘库不卖残页） |
| 法术 / 器诀 / 身法 / 炼体 | **整本** | 不进秘库（《模块五》§13.3） |

理由：非心法走「多炼几本叠加」的设计，残页拼图太慢，破坏爽感。

### 7.2 张数（**四档，⚠ 翻案**）

旧 `ART_FRAGMENT_NEEDED = { qi: 10, foundation: 15, core: 20 }` **三档作废**，改为按 `tier`：

| tier | 张数 | maxLevel |
|---|---:|---:|
| 1 | 10 | 10 |
| 2 | 15 | 15 |
| 3 | 20 | 20 |
| 4 | **25** | 25 |

**张数不按 quality 细分**，同阶四品张数相同。

### 7.3 命名（**2026-10-30 改：秘库不卖残页，本条只作用于探索掉落**）

| 场景 | 命名 |
|---|---|
| **秘库级心法的残页**（探索掉出来的，如《万兽御器经》） | **逐张命名**（「上卷·兽形」「中卷·器理」「下卷·双修」） |
| 其余心法 | 通用编号（如「《庚金诀》残页（三）」） |

90 本全部逐张命名不现实，**只给秘库级那几本逐张命名**。
**秘库本身卖整本、不卖残页**（用户 2026-10-30 拍板），所以逐张命名只服务探索文案。

> ⚠ **旧口径「秘库残页 3 张 ×600 点 = 1,800 点」作废**：换成功法栏整本 200~300 点、全随机。
> 《产出登记表》R22 已改。
