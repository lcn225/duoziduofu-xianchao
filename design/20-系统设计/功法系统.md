## 一、功法库规模与品阶体系

### 1.1 规模

| 项 | 值 |
|---|---:|
| 目标 | **90 本** |
| 现有代码（`cultivationData.QI_ARTS`） | 8 本 |
| 掌门路素材 | 55 本 |
| 三维去重后 | **44 本** |
| 补填 | **46 本** |

去重键 = `tier + category + elements` 完全相同 → 保留 1 本。
保留优先级：**quality 高 → 介绍丰富 → 机制独特 → 开局 / 代码保护**。
唯一例外：组 2 因 `unlockAtStart` 保护，批准保留 2 本（吕氏练气次第论 + 离山经）。

### 1.2 品阶（**四阶 × 四品**，⚠ 翻案）

**现有三档（练气 0.2 / 筑基 0.3 / 金丹 0.4）作废**，改为四阶 × 四品：

| tier | quality | grade 编码 | maxLevel |
|---|---|---|---:|
| 1 | low / mid / high / peak | `qi_low` … `qi_peak` | 10 |
| 2 | low / mid / high / peak | `foundation_low` … `foundation_peak` | 15 |
| 3 | low / mid / high / peak | `core_low` … `core_peak` | 20 |
| 4 | low / mid / high / peak | `nascent_low` … `nascent_peak` | **25** |

`maxLevel` 的 10 / 15 / 20 与代码现有 `ART_GRADES` 一致，**第四阶 25 是新增**。

### 1.3 品阶分（十六档，指数分布）—— **已定稿（2026-10-31）**

**品阶分与效果系数是两把尺子（B 方案）**：品阶分管**门槛**，效果系数（§五）管**非心法效果**。

十六档按 `1.12^score` 的形状铺开，映射到 **0.20 ~ 0.50**（低阶密、高阶疏）：

| tier | low | mid | high | peak |
|---|---:|---:|---:|---:|
| 1 练气 | 0.20 | 0.21 | 0.22 | 0.23 |
| 2 筑基 | 0.25 | 0.26 | 0.28 | 0.29 |
| 3 金丹 | 0.32 | 0.34 | 0.36 | 0.38 |
| 4 元婴 | 0.42 | 0.44 | 0.47 | 0.50 |

**定稿口径（§八 #1 已结）**：

- 同阶 `peak > high > mid > low` 严格成立；边界对齐保留：**二阶下品 0.25 略高于一阶极品 0.23**。
- 与旧的**三档**（练气 0.20 / 筑基 0.30 / 金丹 0.40）对照，新表中位是 **0.21 / 0.26 / 0.34**，
  四阶 `0.42~0.50` 是**新增段**。⇒ **筑基 / 金丹功法的品阶分是下降的**（−0.04 / −0.06），
  属**收益减少，已在《产出登记表》登记**；门槛由 §3.2 的等级加成补回来。

**金 / 木 / 水 / 火 / 土 / 兽 / 器**，可多选。另有两种特殊标记：

| 标记 | 写法 | 含义 |

## 三、契合度公式（改造）

### 3.1 改造前（现行，2026-10-28 B7 口径）

```
功法契合 = 品阶分（三档 0.20/0.30/0.40）+ 覆盖率 × 40%
覆盖率   = |功法 elements ∩ 修士灵气| / |修士灵气|
```

综合契合度 = 功法契合 × 同参契合 × 灵地契合（《模块一》§4.1）。

### 3.2 改造后

| 项 | 变化 |
|---|---|
| 品阶分 | 三档 → **十六档指数分布**（§1.3，已定稿） |
| 心法等级加成 | **加到品阶分**（A 方案），**每级 +0.25%**（`+0.0025`），**不加覆盖率** |
| 覆盖率 | 公式不变（`× 40%`） |
| 通用心法 | **不进「取最高」**，只按 §4.1 给全局小加成 |
| 门槛 | 看**历史最高**契合度：已修心法里的 max + 通用心法加成 |

**等级加成定稿（§八 #2 已结）**：

```
L = 0.0025 × (等级 − 1)      等级 1 = 0（新学一本不加分）
```

- 100 游戏小时一级（沿用 `hoursPerLevel`）。**满级加成**：T1 `+0.0225` / T2 `+0.035` / T3 `+0.0475` / T4 `+0.060`。
- **取代旧「熟练度」**（50h +1%、上限 20%）：旧项整条删除，**同一段时间只算一次**。
- `baseFit` 类功法（吕氏 0.38）**照吃等级加成**。
- ⚠ **GateFit / SpeedFit 两套口径从此合并成一套** —— 旧拆分的唯一理由是「熟练度只加速、不帮门槛」，
  等级加成两边都算之后两者同源。代码里 `includeProficiency` / `harmonyPair` 在 P56 删除。

> ### ⚠ 2026-10-30 拍板：**心法等级算进契合度，也就是算进门槛**
>
> 用户的模型是「**修炼心法 → 契合度涨 → 门槛更容易过**」，按这个执行。
> 这条**推翻了 2026-10-28 B7 的「熟练度只加速（SpeedFit），不帮门槛（GateFit）」**，
> 也推翻了 CLAUDE.md 那条硬口径（已改）。
>
> **同时把「熟练度」和「心法等级加成」合并成一项**，不能并存 —— 代码里它们本来就是同一把时钟：
> `hoursPerLevel = 100`（100h 一层）与 `profPer50Hours = 0.01 / profCap = 0.2`（50h +1%、上限 20%）
> **在 1,000 小时同时到顶**（T1 十层 = 20%）。并存 = 同一段时间算两遍加成。
> 合并后只剩：**每级 +0.25%（§八 #2），上限 = 该功法 `maxLevel`**。
>
> ⚠ **代价（P56 必须吸收）**：现有开局 `品阶 0.20 + 熟练度满 0.20 = 0.40`，
> × 同参 0.541 × 灵地 1.0 = **0.216**，早就过了练气三层的 0.15 ——
> 也就是说**不动功法、纯挂机一小时就能自己过三层**，§6.2「练气三层换功法」的引导会消失。
> 所以十六档门槛重算时**必须把等级加成算进去**（抬高各槛，或压低每级值），
> 否则「一槛一换」的路线整条塌掉。
>
> **✅ 2026-10-31 已吸收（#2 = +0.25%/级）**：桂氏满级 `0.21 + 0.0225 = 0.2325`，
> × 盾 0.541 = **0.126 < 0.15** —— 纯挂机顶不掉练气三层；吕氏 0.38 仍是主路线（0.206）。
> 另有一处必须跟着改：**练气六层 0.24 → 0.26**，否则满级吕氏 `0.4025 × 0.623 = 0.251` 会顶掉
> 「换《兽器双修经》」。五道门槛的完整验算见 §八 #8。

### 3.3 门槛重算 —— **已定稿（2026-10-31），代码待 P56**

**新门槛 `0.15 / 0.26 / 0.35 / 0.40 / 0.76`**（《模块一》§6.1），
相对旧的 `0.15 / 0.24 / 0.35 / 0.40 / 0.76` **只有练气六层 +0.02**。

验算口径：`功法契合 G = 品阶分 + 覆盖率×0.40 + 等级加成`，`综合 = G × 同参 × 灵地(1.0)`；
同参取《数值真值表》§2.8 校准值（盾 **0.541** / 猪妖 **0.623** / 完美 **0.95**）。

| 槛 | 门槛 | 关键路线 | 值 | 过否 |
|---|---:|---|---:|:--:|
| 练气三层 | 0.15 | 开局桂氏 `qi_mid` 覆盖率 0 × 盾 | 0.114 | ❌ |
| | | 桂氏**满级** × 盾（挂机最坏情况） | 0.126 | ❌ |
| | | 吕氏 `baseFit 0.38` × 盾 | **0.206** | ✅ |
| 练气六层 | **0.26** | 吕氏**满级** × 猪妖 | 0.251 | ❌ |
| | | 兽器双修经（0.21+0.40）× 盾 | **0.330** | ✅ |
| 练气九层 | 0.35 | 双修经**满级** × 盾 | 0.342 | ❌ |
| | | 双修经 × 猪妖 | **0.394** | ✅ |
| 筑基 | 0.40 | 双修经**满级** × 猪妖（练气书顶满） | 0.394 | ❌ |
| | | 万兽御器经 `foundation_mid` × 猪妖 | **0.411** | ✅（余量 2.8%） |
| 金丹 | 0.76 | 兽器同源经 `core_high` × 完美同参 | 0.722 | ❌ |
| | | 同上 + 心法 **17 级**（L=0.04） | **0.760** | ✅ 卡线 |
| | | 同上 + 满级 20 级 | 0.767 | ✅ |

> ⚠ **金丹门槛的含义变了**：从「完美同参」变成「**完美同参 + 心法练到 17 级以上**」。
> 这正是 2026-10-30「修炼心法 → 契合度涨 → 门槛更容易过」的落地形态，**不是 bug**。
>
> ⚠ **元婴 0.95 在新表下不可达**：四阶极品 `0.50 + 0.40 + 满级 0.06 = 0.96`，× 0.95 = **0.912**。
> 元婴 31~40 本轮未落地（P61），**等元婴落地时重定**，本批不修。
>
> ⚠ **代码仍是旧口径**：`harmony.js` 走三档 0.20/0.30/0.40 + 熟练度、`realm.js` 六层仍是 0.24。
> 本表是**设计定稿**，P56 代码落地时一起改；在那之前别单独改某一个门槛。

## 四、已修功法池（**C 方案：装备位 + 修炼池**，⚠ 新设定）

| 概念 | 作用 |
|---|---|
| **active 功法** | **只影响该功法自身的升级速度**，不影响门槛 |
| **已修功法池** | 所有炼过的功法，保留等级与效果 |
| **门槛** | 看**历史最高**契合度（已修心法 max + 通用心法加成） |

### 4.1 心法：取最高

所有已修心法中，**取契合度最高的那本生效**。
例：A 心法 20 级 50%、B 心法 5 级 60% → 取 60%。**不叠加**。

**通用心法**是例外：加**全局契合度**，可与任意心法叠加。

**定稿（§八 #3 已结）**：

```
通用加成 = 0.01 × 阶 × (等级 / maxLevel)      多本加算，总额封顶 +0.05
```

- 2 本叠满 = 黄庭经（T1）`+0.01` + 通明经（T3）`+0.03` = **+0.04**，在封顶线内。
- ⚠ **通用心法不参与「已修心法取最高」的候选**，其品阶分**不进门槛**。
  否则黄庭经（`0.23 + 0.40 = 0.63`）会压过《兽器双修经》（0.61）、通明经（0.76）与《兽器同源经》持平，
  各阶最优解全部变成通用书，「一槛一换」的功法引导就没有意义了。
- 通用书的价值 = **无灵根限制 + 随时可练的固定小加成**，不是「最强心法」。

### 4.2 非心法：叠加 + 软上限 B

法术 / 身法 / 炼体 / 器诀：**每本都生效，叠加**，走软上限 B（渐近）：

```
总加成 = cap × (1 − e^(−原始/cap))
```

**与子嗣加成（R07）、陨落词条 A 类同一套公式**，cap 各自取（§八 #4）。

### 4.3 器诀：熟练度 → 对应装备的百分比属性

器诀的「熟练度」= **功法等级**。效果 = 按等级增加**对应类型装备的百分比属性**，类似词条。

**定稿（§八 #5 已结）**：

- 走和别的非心法**同一条公式**：`totalAtMax = categoryBase × coef`，`valueAtLevel = totalAtMax × L / maxLevel`
  （所以「按等级线性增长」是公式自带的，不需要另写一套）。
- `categoryBase = 4%` ⇒ 满级 **T1 下品 4.0% ~ T4 极品 15.6%**。
- **只加对应器型**（剑诀→剑、盾诀→盾…）⇒ 数据要加 `equipType` 字段；**缺失时按「全部灵器」处理**。
- **与词条加算**：两者同属「装备百分比」一个加区，先加总再乘装备白板；
  跨系统（功法 / 装备 / 灵根丹药）仍然**乘算**（§5.4 第 2 条不变）。

### 4.4 UI：软上限感知

- **平时只显示当前值**（法术攻击 +42%），不显示上限。
- **超过 70% 上限后**追加一行「收益递减」提示（文案待定，不出戏）。
- **不显示精确上限、不改公式、不引入分段公式。**

## 五、效果系数（只给非心法）

### 5.1 比较口径

- 以**满级总效果**比较；同阶同类别 `peak > high > mid > low` 严格成立。
- 跨阶锚点：**二阶下品满级 ≈ 一阶极品满级**。
- 未满级：`当前效果 = 满级总效果 × 当前等级 / maxLevel`。

### 5.2 品阶系数

```
qIndex = low:0, mid:1, high:2, peak:3
score  = 3×(tier−1) + qIndex
coef   = 1.12^score        // 1.000 ~ 3.896
```

### 5.3 类别基准（**已定稿 2026-10-31**，§八 #6 / #7 已结）

| category | 主效果 | 一阶下品满级基准 |
|---|---|---|
| 心法 | ~~修炼速度~~ → **走契合度**（§六） | — |
| 法术 | 攻击 `+5% × coef` | **5%** |
| 身法 | 速度 `+5% × coef` | **5%** |
| 炼体 | 气血 `+4% × coef` + 防御 `+2% × coef`（2:1） | **4% + 2%** |
| 器诀 | 装备百分比（§4.3） | **4%** |

```
totalAtMax   = categoryBase × coef
valueAtLevel(L) = totalAtMax × L / maxLevel
```

### 5.4 叠加与软上限建议

1. 同 effectType **加算**：所有法术攻击先加总，再套软上限。
2. 跨系统 **乘算分区**：功法总加成 × 装备总加成 × 灵根 / 丹药总加成。
3. 条件效果（「配合本命 / 阵法」）**一期只保留文字**，不进数值；二期再加 `conditional` 字段。
4. 软上限（**已定稿 2026-10-31**，§八 #4 已结）：**攻击 +80% / 速度 +60% / 气血 +80% / 防御 +80%**。
   旧的「修炼速度 +100% / 熟练度 +100%」两项**删除** —— 心法不直接加速度（§六），熟练度已并入心法等级。

## 六、修炼速度 = 只看契合度（⚠ 翻案）

**方案文档 §7.3 的「心法 → 修炼速度 +5% × coef」作废。**

功法对**桂冈修炼速度**的影响，**完全通过契合度**体现：

```
修炼速度系数 = 0.98 + 0.32 × Fit
```

**不存在独立的心法速度加成**。心法的价值在于**抬高 Fit 过门槛**，不在直接加速度。

> 与 §五 的关系：§五 的 `coef` 只给**非心法**用；心法不进 §五。

## 七、功法残页（2026-10-30 定稿）

### 7.1 只有心法有残页

| 类别 | 外面掉（探索） | 秘库卖 |
|---|---|---|
| **心法** | **残页** | **整本**（2026-10-30 拍板，秘库不卖残页） |
| 法术 / 器诀 / 身法 / 炼体 | **整本** | 不进秘库（《模块五》§13.3） |

理由：非心法走「多炼几本叠加」的设计，残页拼图太慢，破坏爽感。

### 7.2 张数（**四档，⚠ 翻案**）

旧 `ART_FRAGMENT_NEEDED = { qi: 10, foundation: 15, core: 20 }` **三档作废**，改为按 `tier`：

| tier | 张数 | maxLevel |
|---|---:|---:|
| 1 | 10 | 10 |
| 2 | 15 | 15 |
| 3 | 20 | 20 |
| 4 | **25** | 25 |

**张数不按 quality 细分**，同阶四品张数相同。

### 7.3 命名（**2026-10-30 改：秘库不卖残页，本条只作用于探索掉落**）

| 场景 | 命名 |
|---|---|
| **秘库级心法的残页**（探索掉出来的，如《万兽御器经》） | **逐张命名**（「上卷·兽形」「中卷·器理」「下卷·双修」） |
