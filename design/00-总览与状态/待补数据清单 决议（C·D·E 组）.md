## 二、D 组：容量

### 2.1 D1：本命池 = 物品池（概念修正）

| 旧设计 | 新设计 |
|---|---|
| `FATE_POOL` 独立表（17 条） | **删除** —— 子嗣本命从物品池抽 |
| 单独维护本命池 | 扩充物品池 = 扩充本命池 |

```
物品池（灵兽 / 灵草 / 灵器 / 灵岩）
├── 子嗣抽本命 → 从物品池抽
├── 同参     → 从物品池筛选
├── 装备     → 灵器类
└── 灵宠     → 灵兽类
```

**扩充物品池就自动扩充了本命池。**

**当前问题**：物品池里 `灵器` 类偏少 → 子嗣抽到「器」灵根的概率低。
**解决**：扩充物品池的 `灵器` 类。

> ⚠️ 这条要动 `src/stores/modules/innerCourt.js`（抽卡逻辑）与 `innerCourtData.js` 的 `FATE_POOL`
> —— **模块二的代码改动**，不是纯数据。

### 2.2 D2：词条池

| 改动 | 说明 |
|---|---|
| 加 `effect` 字段 | 每条词条有具体效果（现在是同档同效） |
| 扩充稀有 | 4 → **8** 条 |
| 扩充传说 | 2 → **4** 条 |
| 后续持续扩充 | 多多益善 |

### 2.3 D3：灵宠池

**同 D1 —— 灵宠池也是物品池的一部分。**

| 改动 | 说明 |
|---|---|
| 扩充物品池的 `灵兽` 类 | 低品阶各扩到 **8** 只 |
| 不再单独维护灵宠池 | 统一从物品池读取 |

### 6.1 灵草系列（2026-10-16 定）

**按形态分五种**：`shu` 树类 / `cao` 草类 / `hua` 花类 / `guo` 果类 / `ye` 叶类。
（示例：崖木参 · 养心草 / 回春草 / 凝气草 · 云雾花 · 朱果 · 灵茶叶）

> ⚠ 原 P11 §2.2 写的是「灵草**按药性**分系列」，已改为「按**形态**」。理由：series 只服务于
> **同参契合度**（灵草反正都归「木」），形态分类够用且好扩充；「药性」（补血 / 解毒 / 回气 / 清心）
> 留给以后的**丹方字段**。
> 见 [`同参系统`](../10-现行设计/同参系统%20—%20完整方案书.md) §9.2b。
