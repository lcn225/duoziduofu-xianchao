### 2.1 游戏年龄换算（2026-10-29 P55-b 增补）

**上面这张表是「现实时间」锚点** —— 练气段与筑基段一个字没动，**只有结丹段因本条 §2.1
被收窄过一次**（72 → 60 小时，理由见第二章表下的订正框）。2026-10-29 起时钟**按境界分两速**，
所以同样的现实时间折成**游戏内时间**要分段算：

```
练气期    1 游戏天 = 96 现实秒    1 仙龄岁 = 365 游戏天 = 9.73 现实小时
筑基后    1 游戏天 =  4 现实秒    1 仙龄岁 = 365 游戏天 = 24.3 现实分钟   （24×）
```

**关键节点的游戏内累计**（换算明细见《数值真值表》§1.2）：

| 节点 | 现实累计 | 游戏内累计 |
|---|---:|---:|
| 练气三层 | 4 分钟 | 2.5 天 |
| 练气六层 | 37 分钟 | 23.1 天 |
| 练气十层 | 5.5 小时 | 206.3 天 |
| **筑基一层** | 7.5 小时 | **0.77 岁** |
| 筑基十层 | 31.9 小时 | 60.9 岁 |
| 金丹一层 | 55.9 小时 | 120.1 岁 |
| 金丹十层 | **7.83 天** | **445.6 岁** |

> **为什么筑基后游戏内时间会「膨胀」**：不是数值改了，是**钟变快了** ——
> 24× 让同样的现实小时数走过 24 倍的游戏岁月。这正是「仙凡永别」要表达的东西：
> 筑基之后，外界的一年只值你的一刻钟（见《日常循环》§十五「昨日战报」与
> 《模块二》§15.5 的寿终后果）。
>
> ✅ **这条冲突已于 2026-10-29 拍板解决**：24× 折算原本把结丹圆满推到 **506 游戏岁**，
> 超过 B1 的结丹寿元 **500 岁**（差 6 岁）。用户拍板「**收窄宪法第二章结丹段的现实锚点**」，
> 即上面表下的订正 —— 结丹圆满改 **60 小时 / 累计 7.9 天 ⇒ 445.6 游戏岁**，余量 54 岁。
> **寿元表没动**（仍是 120 / 200 / 500）；桂冈自己的寿元仍未建模，等《子嗣寿命》批一起做。

*注：子嗣与妻妾的年龄**不走这张表** —— 他们按 365 游戏天/岁自己推，见《模块二》§7.1 / §16.1。*

## 第三章 突破门槛体验路线（动作导向）

**数值不硬性规定，但玩家的动作体验不可动摇。** 门槛的设计必须迫使玩家在特定阶段做出特定的“更换”动作。

| 门槛       | 玩家必须做的动作            | 强度约束       |
| -------- | ------------------- | ---------- |
| **第一门槛** | 换功法（开局功法必须不足以过槛）    | 逼玩家点开功法界面  |
| **第二门槛** | 换同参（获取第一件同系列同参）     | 逼玩家去抽奖或打秘境 |
| **第三门槛** | 换同参（高标签契合）+ 换功法（高覆盖率） | 逼玩家追求高品质同参 |
| **筑基门槛** | 换筑基级功法 + 熬熟练度       | 体验长线挂机积累   |
| **金丹门槛** | 换同参（标签完全重合）+ 金丹级功法      | 追求完美配置     |
| **元婴门槛** | 完全匹配 + 同参完全重合           | 终极追求       |

> 2026-10-26：术语「准正主 / 正主」废止，同参契合改**标签权重连续值**（《模块一》§4.3）。
> 2026-10-28（B7）已一次性重算门槛：**0.15 / 0.24 / 0.35 / 0.40 / 0.76**。
> **本章的动作体验不变。**

**铁律**：同参对综合契合度的杠杆，必须始终不小于功法（连乘下体现为同参档位跨度大于功法品阶跨度）。

## 第四章 桂冈的一天（时间结构）

决定玩家的微观操作节奏。所有日常管理功能，必须塞进此框架，不允许做分散的独立页面（配置页除外）。

```
晨起 6:00 
  → 巡视乡间（默认 2h，可调 1~5h）
  → 小循环（**6:00 + 巡视时长 S 开始**，18:00 硬下班；L = 12 − S）
     练功（内功，1h）→ 炼体（外功，1h）→ 百艺（45m）→ 循环
     勾选百艺越多，练功轮次越少（玩物丧志）
  → 妻妾互动（下班后，消耗体力到耗尽或天亮）
  → 睡觉（剩余时间）
```

*2026-10-21 Q8 定稿、**2026-10-26 代码落地**：旧的「8:00 开始」作废。默认巡视 2h 时仍是
10 轮练功；S=1 → 11 轮、巡视拉满 5h → 7 轮，取舍才真正成立。巡视期间主界面
**显示小循环预览**（B 方案）。实现上巡视一结束就开工，没有「候工」段。*

*注：精力耗尽时，打坐一轮（1h，+10）后放弃当天剩余安排、提前下班。*

## 第五章 核心取舍博弈（体力与精力）

**数值不硬性规定，但博弈体验不可动摇。** 所有消耗与恢复数值，必须配平出以下体验：

1. **双资源分工**：
   * 精力 = 脑力（管百艺）。
   * 体力 = 身体（管所有活动与妻妾互动）。
2. **体力博弈**：
   * 玩家一天的体力总量是受限的（开局 145，无上限）。
   * **白天多干活** = 晚上体力少 = 互动次数少 = 子嗣出生率低。
   * **白天少干活** = 晚上体力多 = 互动次数多 = 子嗣出生率高，但挤占睡眠时间。
3. **睡眠与次日状态**：
   * 睡眠不足（<4小时）会导致次日体力/精力不满。
   * 玩家必须在“多互动多生子”与“多睡觉保次日状态”之间做权衡。
4. **子嗣的叙事驱动**：
   * 子嗣系统的一切机制（高颜值侍妾、互动快感、多子多福系统面板），首要服务于“男主好色、不遗余力繁衍”的剧情模拟。
   * **但**，子嗣提供的修行数值加成（如子嗣对修炼速度的百分比加成），必须严格受控，绝不能破坏第二章的《突破时间表》。子嗣是用来“加速”的，不能用来“跳级”。

## 第六章 基础数据结构铁律

以下结构已冻结，不再推翻重来：

1. **境界体系**：
   * 内功：**30 级（练气 10 + 筑基 10 + 金丹 10）**，元婴 10 级（31~40）**尚未落地**。
   * 外功：平行同构 30 级（炼体 10 + 锻骨 10 + 洗髓 10）。
   * ⚠ 2026-10-30 由「18 级（10+4+4）」改成「每大境界 10 层」，用户拍板对齐原作；
     「结丹」统一改称「**金丹**」。段总量守恒，宪法第二章的时间锚点不变。
2. **物品池四大类**：
   * **灵兽**（灵宠/同参/子嗣本命）
   * **灵草**（炼丹/同参/子嗣本命）
   * **灵器**（装备/同参/子嗣本命）
   * **灵岩**（金属/宝晶/灵土等，炼器/同参/子嗣本命）
   * *原则：同一件物品，可以装备、可以出战、可以参悟。*
3. **同参判定**：**标签权重连续值**（交集权重 / 本命权重，0.1~1.0 动态计算；2026-10-26 起六档作废）。
4. **灵地属性**：五行 + 兽 + 器，匹配度直接算契合度，等级决定基础产出并卡门槛。

## 第七章 产出登记与门槛反推（2026-10-17 增补）

**铁律：任何新增系统/玩法，只要引入新的产出渠道、或**增加 / 减少**既有产出量，必须在最晚不超过测试阶段登记到《产出登记表》。未登记的产出，不得进入测试。**

⚠ **收益减少同样要登记。** 只记加不记减，重算门槛时会拿旧产出当基准，算出来的门槛是错的。
每一次增减都写进《产出登记表》末尾的「变更记录」，注明从多少改到多少、为什么改。

登记的最小粒度：

| 字段 | 说明 |
| ---- | ---- |
| 来源 | 哪个系统/环节（镇守、探索、秘境、封地、家族工作……） |
| 产出物 | 灵石 / 材料 / 功法 / 同参 / 修为 / 子嗣 / 加成…… |
| 频率与数量 | 每次多少、每天多少、什么条件下给 |
| 是否唯一来源 | 该物品是否只能从这里获得（决定门槛能不能卡它） |
| 状态 | 设计定稿 / 待定 / 已实现 |

**门槛反推的唯一口径**：所有境界突破门槛，必须基于**全部已登记产出**、按第二章《突破时间表》的绝对时间反推。
不允许用「拍脑袋加个数」「给个上限」来配平。流程固定为：

```
新增产出 → 先登记 → 按第二章重算门槛 → 再改代码
```

**Boss 首破奖励也属于产出**：秘境 BOSS 的首次击破额外奖励必须**单独登记**（一次性）；
扫荡或重复爬塔只给基础奖励，不得按「每次都给额外奖励」计入成长曲线。
