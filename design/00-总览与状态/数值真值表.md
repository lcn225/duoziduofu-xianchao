### 0.3 三条必须先钉死的账

**① 你给的 Sheet 2 公式有一处代数反了。**

原式：

```
实际修为上限 = Base × (1 + Child + Other)
综合修炼速度 = Land × (0.5 + Fit×1.5) × Fate × spiritRate × (1 + Child)
```

两式相除，子嗣项**不会完全对消**：

```
耗时 = T0 × (1 + Child + Other) / (1 + Child)
     = T0 × (1 + Other / (1 + Child))
```

后果有两个，方向都反了：

- `Other` 越大，突破**越慢**（其他加成变成了惩罚）；
- 子嗣越多，`Other` 的拖慢**越小**，但永远不可能加速。

这与「子嗣只让数字变大、不改突破时间」的设计意图不符。**本表采用修正版：**

```
Cap_eff = Base × K × (1 + Child)                 // 子嗣只膨胀上限
R       = Land × (0.5 + Fit×1.5) × Fate × spiritRate × Bandwidth
          × (1 + Child) × (1 + Other)            // 子嗣同时膨胀速度
耗时    = Cap_eff / (R × k) = Base × K / (…)     // Child 精确对消
```

结果：**子嗣数量对突破时间的影响 = 0；`Other` 是真正的加速项。** 这正是你要的「肝帝看着爽、节奏不崩」。

**② 宪法第二章的「累计」列不能简单相加。**
它只列了 8 个**锚点**，中间还有 L4/L5/L7/L8/L9/L12/L13/L16/L17 等未列出的级。
把 8 个「目标现实时间」直接相加会得到 101 小时，而累计列写的是 7.9 天 —— 差的正是这些中间级。
按「锚点逐节点 + 中间级几何插值」重建后：L6 37.4 分钟（表 38）、L10 272.5 分钟（表 283）、
L14 31.9 小时（表 33）、L18 7.83 天（表 7.9）—— **全部吻合**。
（2026-10-29 P55-d 收窄结丹段后，这两处由 113 小时 / 8.9 天改为 101 小时 / 7.9 天。）
所以第二章是自洽的，**读法是「逐节点目标 + 插值」，不是「把表里的数字相加」**。

**③ 代码现在跑的是旧一代。**
三维加权（0.15/0.50/0.35）、18 级、门槛 0.55/0.60/0.68/0.71/0.85、灵地 1.0~15.0、子嗣封顶 2.0。

**打坐转化率的来源**（`cultivationMath.js`）：
每次打坐消耗 `floor(10 × 1.5^(L-1))` 灵力，获得 `floor(1 × 1.2^(L-1))` 修为，
30%×luck 概率本次翻倍。所以：

```
k(L) = 1.2^(L-1) / 1.5^(L-1) × (1 + 0.3×luck)
     = 0.8^(L-1) × 1.3
```

⚠ 这个 0.8 的指数是**后期变慢的主刹车**：L18 时 0.8^17 = 0.0225，即 1 点修为要 44 点灵力。
它比灵地产出涨得慢，所以后期必须靠 `K` 抬门槛。

```

  → 18:00 下班

### 4.2 公式

```
L = 12 − S                         // 小循环可用小时（默认 S=2 → 10）
C = 1 + B + 0.75×N                 // 一个周期：练功 1h + 炼体 B×1h + N 个百艺×45m
k = floor(L / C)                   // 完整周期数
r = L − k×C                        // 余时

练功轮次 = k + (r ≥ 1 ? 1 : 0)
炼体轮次 = B=1 ? k + (r−1 ≥ 1 ? 1 : 0) : 0
百艺轮次 = 每项先得 k 次，余时按队列顺序补（先排到的可能 +1）

体力消耗 = S×10 + 练功×3 + 炼体×15 + Σ(百艺轮次×0.75×5或6)
精力变化 = 练功×10 − (炼丹/炼符各30 + 炼阵/炼器各35) + 睡觉×5
互动次数 = min(floor(剩余体力 / 20), 12 / 1h)   // 2026-10-17：15→20，0.5h→1h
睡觉时长 = 12 − 1×互动次数
次日体力 = min(睡觉时长 × 体力上限/4, 体力上限)
```

```

炼体 2~10 级：每级 +3  → 十层 172

```

**博弈 A：白天多干活 → 晚上体力少 → 互动少 → 子嗣少。**

**博弈 B：互动多 → 睡觉少 → 次日体力/精力不满。**
✅ **中期起成立。** 1h/次之后，夜晚只有 12 个互动位：

| 选择 | 互动 | 子嗣期望/晚 | 次日体力 |
|---|---:|---:|---:|

**这是玩家自己的取舍，不是数值 bug。** 如果实测发现大家都选保睡眠，再调高单次怀孕率或降低睡眠惩罚。

|---|---|---|---|
| 0.5h + 20（旧方案） | 4 / 10h / 145 | 9 / 7.5h / 232 | 16 / 4h / 382 |
| 0.5h + 25 | 3 / 10.5h / 145 | 7 / 8.5h / 232 | 13 / 5.5h / 382 |

**读法：**
- **只加体力成本（15→20/25/30）不会制造睡眠博弈**：开局/洗髓期怎么改都睡 ≥7.5h、次日照样回满；
  只有超级炼体 24 级（382）时，20/次刚好压到 4h，15/次才会 1h 睡到崩。
- **真正制造睡眠博弈的是时长**：互动 0.5h → 1h 后，洗髓期 9 次就是 3h 睡，次日只剩 75% 体力。
- **代码的 30 点阈值会抵消这个效果**：1h+20 在洗髓期会被阈值压到 7 次（5h 睡，回满）。
  所以已拍板**去掉 30 阈值**。
- **成本 25/30 只是让子嗣更少**，不是让睡眠更紧张。要「少子」选 25；要「睡眠博弈」选 1h + 去阈值。

### 5.5 子嗣战力（**2026-10-21 Q3 定稿，唯一口径**）

```
四属性 = 基础值 × 境界系数 × 灵根系数 × 本命系数 × (1 + Σ词条) + 装备面板
战力（展示）= 攻击 × 有效生命 / 100，其中 有效生命 = 气血 × (100 + 防御) / 100
```

> **战力口径（2026-10-23 落地）**：与 `resolveAttack` 的承伤公式同口径（防御 100 = 减伤一半），
> 所以「战力」≈ 这个单位能打出的总伤害。**速度不进战力** —— 它只决定出手顺序，
> 不改变输出量。暴击/连击/闪避那些百分比字段只有灵宠和桂冈带，**没算进去**（估算）。
> 代码：`secretRealm.combatPowerOf`；断言在 `verify-idle` §七。
> **只进展示、不参与任何战斗判定**；编队页的「队伍战力」= 桂冈 + 已选，加总。

> **装备面板**（2026-10-23 P36 第 3 步接入）：攻/防两槽的 `stats` 直接加在最后，
> **不乘境界/灵根/本命**；攻击 → `damage`、速度 → `speed` 平加。
> 子嗣只能穿武器与防具，阶位按**境界段定阶**（练气一/二阶、筑基二/三阶、结丹三/四阶）。

| 项 | 系数 |
|---|---|
| 境界 | **练气一~十层线性 1.0 → 5.0**（每层 +0.444）；**筑基 10.0**；**结丹 30.0**；元婴待 22 级落地再定 |
| 灵根 | 五 0.8 / 四 1.0 / 三 1.2 / 双 1.5 / 单 2.0（无灵根 0.5） |
| 本命 | **tier 1 → 1.0 / 2 → 1.2 / 3 → 1.5 / 4–5 → 2.0**（按物品池基阶） |
| 词条 | **`effect.cultivation + effect.combat` 加算**（P60，2026-10-31）—— 修行/战力 普通 **1%** / 稀有 **2%** / 传说 **4%**；专精走装备面板「取最高不叠乘」，**不进这里**。旧口径「普通 +5% / 稀有 +10% / 传说 +20%」已作废 |
| 基础 | 生命 60 / 攻击 6 / 防御 3 / 速度 8 |

**已删除的因子**：品质（low/mid/high/top）、仙龄等级。
仙龄只用于「成年、能否出战、成长曲线」，**不再进战斗属性**。

**桂冈**：属性管线**不变**（现有 `baseAttributes` 10/100/5/10 + 装备 + 灵宠 + 炼体），
只有界面上的「战力」数字按同一公式展示。→ 桂冈与子嗣不能直接比属性，只能比「战力」显示。

**锚点**：练气二层、单灵根子嗣，能打过难度 1 第 5 层 Boss。
**队伍**：桂冈 + 3 子嗣，战力**加总**（只做展示）。

**影响**：旧档子嗣战力会变（品质乘区消失），**不补偿**。

```

| 配置 | 练功 | 炼体 | 每种百艺 |
|---|---:|---:|---:|

**产出计划**：

```

计划修为 = min(60 × 计划练功轮次, 计划灵力 / 打坐成本) × 每次修为 × (1 + 0.3×幸运)
计划体魄 = 同上，用外功等级与计划炼体轮次；内外功按各自可打坐次数分配灵力

计划熟练度 = 计划练功小时 / 50 / 100     // 1% / 50 游戏小时 → 0.0002/小时
```

> ✅ **2026-10-19 起代码已按 1%/50h 返工**（`0.0002/小时`），日志上的「熟练度达成率」
