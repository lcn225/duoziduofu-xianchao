## 一、必须定死的（会直接变成实现 bug）

### 1. 金页子→二阶汇率

| 文档      | 算法                 | 隐含汇率           |
| ------- | ------------------ | -------------- |
| 子嗣与家族经济 | 6,000 金页子 = 17 二阶  | 353 金页子 = 1 二阶 |
| 经济体系    | 3,000 金页子 = 857 二阶 | 3.5 金页子 = 1 二阶 |

**结论**：经济体系那张表把「一阶」写成了「二阶」。正确链是：

```
100 大子 = 1 金页子
3.5 金页子 = 1 一阶灵石
100 一阶 = 1 二阶
∴ 350 金页子 = 1 二阶
```

**子嗣文档那套 353 是对的**（3.5 × 100 = 350，差 3 是四舍五入）。经济体系 §3.2 的「857」应该是「857 一阶」，不是二阶。

**定死**：1 二阶 = 350 金页子。

### 2. 仙朝年收入 110,000 vs 84,000

子嗣文档用 110,000 算月饷占比 5.9%，经济体系合计 84,000+（修正 §1 汇率后为 80,000+）。

按基础档重算：(6,490 + 3,677) / 80,000 = **12.7%**，超过 10% 财政线。

**结论**：经济体系的 84,000 是**保守估计**（不含跨域贸易），子嗣文档的 110,000 是**含跨域贸易**的估计。两个数都对，只是口径不同。

**定死**：仙朝年收入分两档——基础 **80,000**（不含跨域，修正 §1 汇率后由 84,000 下修），完整 **110,000**（含跨域）。月饷占比按基础算 **12.7%**，按完整算 9.2%。

### 3. 侍妾月饷 P7/P8 单位不同

| 文档   | P7     | P8      |
| ---- | ------ | ------- |
| 模块二  | 1 一阶   | 3 一阶    |
| 经济体系 | 30 金页子 | 100 金页子 |

按 3.5 金页子 = 1 一阶：30 金页子 = 8.6 一阶，100 金页子 = 28.6 一阶。两边对不齐。

**结论**：模块二和经济体系各写各的，没有统一。

**定死**：原正文写「P7 = 10 一阶、P8 = 30 一阶」，与下方表格自相矛盾（且 P7 = P9 = 10 一阶，不满足「P7/P8 应在 P6 和 P9 之间」）。**以表格版为准**：

| 位阶  | 月饷     | 年成本     | 折金页子  |
| --- | ------ | ------- | ----- |
| P6  | 10 金页子 | 120 金页子 | 10    |
| P7  | 3 一阶   | 36 一阶   | 10.5  |
| P8  | 10 一阶  | 120 一阶  | 35    |
| P9  | 30 一阶  | 360 一阶  | 105   |
| P10 | **待定** | —       | —     |

折金页子按 `3.5 金页子 = 1 一阶` 换算，P6 → P9 严格单调递增。

两处连带改动：

- **P9 由 10 一阶 提到 30 一阶**——模块二 §2.1 与经济体系 §5 都要一起改。
- **P10 待定**——模块二写 1 二阶（=100 一阶），经济体系写 30 一阶。P9 提到 30 一阶后 P10 必须 > 30 一阶，模块二的 1 二阶是唯一可用候选，但尚未最终确认。

参考锚点：P11 5 二阶 / P12 50 二阶 / P13 500 二阶（两份文档一致，不动）。

### 4. 门派俸禄挂在废案上

这是最大的结构性问题。

**现象**：

- 生存阶段俸禄 10,000 二阶/年，占收入 100%
- 扎根阶段俸禄 15,350，占收入 80~96%
- 封地税收只有 143~857 二阶，不到 5%
- 俸禄从练气到元婴只涨 2 倍（10,000 → 20,000）
- 门派政治是废案

**结论**：俸禄是全前期最大收入，但它挂在废案上。要么保留门派政治（哪怕简版），要么把俸禄改为其他来源。

**建议**：俸禄改为**飞鹰门职位津贴**，不依赖门派政治模块。职位体系可以简化——下柱/中柱/上柱 + 乡侯 + 驿守 + 军阵将佐，只作为**俸禄等级**，不做派系、合议、站队。

**定死**：俸禄保留，但门派政治不做。俸禄只跟职位挂钩，职位只跟贡献挂钩。

### 5. 时间系统速度常数自相矛盾

| 位置   | 值                                            |
| ---- | -------------------------------------------- |
| §2.1 | 1 现实秒 = 1 游戏小时                               |
| 数据结构 | `secondsPerGameHour: 2.5`                    |
| 代码示例 | `deltaGameSeconds = deltaRealSeconds * 3600` |

副作用：

- §2.2「功法熟练度 约 4 现实分钟」是按 2.5 算的（100 × 2.5 = 250 秒）
- 按真正的 B 速度应该是 1.7 分钟
- 同表其他行（怀孕 1.8 小时、子嗣成年 43.7 小时、俸禄月 12 分钟）都是按 1 秒 = 1 小时算的

**定死**：1 现实秒 = 1 游戏小时。`secondsPerGameHour = 1`。§2.2 那两行改为 1.7 分钟 / 0.83 分钟。

## 二、公式矛盾的

### 6. 灵地契合会突破 100%，五阶不存在

> **本条已被《灵气系统 — 最终设计文档》覆盖。** 灵地契合不再是「等级系数 × 五行匹配」，而是**纯匹配百分比**（0%~100%），天然不会越界；灵地等级改走独立的「基础产出」（一阶下品 1.0 ~ 五阶 15.0）进速度公式。上面写的 `min(1.0, ...)` 和那张系数表都已作废。五阶灵地缺失的问题仍在，已列入《灵气系统》§十一 待办。

原问题（留档）：

```
灵地契合 = 灵地等级系数 × (1 + 五行匹配)
三阶 1.5 × 相生 1.3 = 1.95 → 195%
```

但上限表写「100%，达成条件：三阶灵地 + 五行相生」。同时元婴门槛要求五阶灵地，但灵地等级系数表只列到三阶 1.5。

---

### 7. 功法契合下限表和相克行打架

> **本条已被《灵气系统 — 最终设计文档》§4.2 覆盖。** 功法契合改成 `品阶分 + 灵根匹配分 + 熟练度`，不再有「五行相生/相克」概念，也就没有负值。下限变成「不匹配 + 零熟练度」：练气篇 40% / 筑基级 50% / 金丹级 60%。下面那张负下限表作废。

原问题（留档）：

表说练气篇下限 10%、金丹级下限 0%，但五行匹配里练气篇相克是 -10%、金丹级相克是 -20%。

### 8. 抽卡规则有两套

§6.1 灵根概率按母方位阶给到 20%~100%（P11 起超过 100%），§6.2 又是一张独立的综合概率表。

**定死**：两步走。

**第一步：判有无灵根**

```
灵根概率 = 基础 10% × 母方位阶系数 × 父方身份系数
```

| 母方位阶  | 系数  |
| ----- | --- |
| P1-P2 | 0.5 |
| P3    | 0.7 |
| P4    | 0.8 |
| P5    | 0.9 |
| P6    | 1.0 |
| P7    | 1.2 |
| P8    | 1.5 |
| P9    | 2.0 |
| P10   | 2.5 |
| P11   | 3.0 |
| P12   | 3.5 |
| P13   | 4.0 |

父方系数：凡人 1.0 / 练气 2.0 / 筑基 3.0 / 结丹+ 4.0。

**上限 100%**。

**第二步：有灵根后，在品质分布里抽**

| 品质  | 概率  |
| --- | --- |
| 下品  | 60% |
| 中品  | 25% |
| 上品  | 12% |
| 极品  | 3%  |

### 9. 同参祭炼在新公式里没有位置

时间系统和离线结算都把「同参祭炼」当修行钩子（+20% 满），但修炼文档里同参契合 = 接近度系数 × 品阶系数，完全不含祭炼项。

**定死**：同参祭炼**取消**。同参不能升级，只能更换。时间系统的钩子里删掉祭炼，离线结算的托管表里删掉祭炼。

## 三、结构性缺口

### 11. 双轨时间没有落地

时间系统文档只有一个可暂停的单时钟，没有双轨设计。示例代码里 `hooks.tick` 注册了却在 `tick()` 里从没被调用。

### 12. 品阶体系三套粒度

| 体系  | 粒度                          |
| --- | --------------------------- |
| 同参  | 最高四阶，一阶分下/中/上品              |
| 灵地  | 最高五阶，二阶分下/中品                |
| 建筑  | Lv.1-5，但经济表里炭场/矿场/工坊只到 Lv.3 |

**定死**：统一品阶 enum。

```
不入品 → 一阶下品 → 一阶中品 → 一阶上品 → 二阶下品 → 二阶中品 → 二阶上品 → 三阶 → 四阶 → 五阶
```

## 四、两个平衡观察

### 15. 「深度」是最弱的杠杆

> **本条的建议已被《灵气系统》§5 否决，而且方向相反。** 新公式用的是 `0.7 + 契合度 × 0.6`——契合度 0%→100% 只把速度从 0.70× 拉到 1.30×（1.86 倍），比原来还弱；桂冈从开局到元婴实际只从 0.83× 到 1.04×。已确认这是**有意设计**：契合度只当门槛，不当收益引擎，收益侧交给 spiritRate（×1.2/次突破）、子嗣（最高 3×）和行功带宽（最高 5×）。「提高契合度杠杆」的建议作废。

原问题（留档）：

练气→结丹，契合度只贡献 1.70×，带宽 2.0×，子嗣加成 3.0×。后期最优解是一路堆子嗣。

---

### 16. 熟练度和祭炼是按现实分钟计的

**门槛部分已解决（数值已再次修订）**：本条写于**四维版**（开局 56.6%、三层 55% 只余 1.6 个点）。**三维版把本命维删掉后开局掉到 50.25%，三层真的要拦人了**；门槛也改成 55/60/**68**/**71**/85。以《灵气系统》§6 / §7.4 为准。

**祭炼部分已解决**：祭炼机制整体取消。

**熟练度部分仍未处理**：`每 100 游戏小时 +1%，上限 20%` 被《灵气系统》§4.2 保留，按定死的 `1 现实秒 = 1 游戏小时` 算仍是 **33 现实分钟满**。它现在是每档功法契合上限的**必要组成**（如练气篇部分匹配 60% = 品阶 20 + 匹配 20 + 熟练 20），不算白送，但也几乎不花时间。建议按原议改为按游戏年计。

原问题（留档）：

熟练度满 20% 只要约 33 现实分钟，祭炼满 20% 只要约 8 分钟——对比子嗣成年要 43.7 小时。另外开局 51.6% 已经越过练气三层（20%）、练气六层（40%）两道门槛，这两道是装饰。

---

**总结**：这份清单抓得很准，16 条全部成立。建议按「先定死数字 → 再修公式 → 再补结构 → 最后调平衡」的顺序处理。
