## 文档体积与读法（2026-10-31 整理后）

> token 成本 ≈ 往返次数 × 上下文。**能整读的只有前七份**，其余一律按目录取节或 grep。

| 文档 | 规模 | 读法 |
|---|---|---|
| `README.md`（本文） | ~300 行 | 可整读（索引） |
| `下一步.md` | ~360 行 | **可整读**；查历史批次看 P 编号索引 → 落地记录 |
| `CLAUDE.md`（仓库根） | ~400 行 | 自动加载，不用读 |
| `当前实现.md` | ~260 行 | 可整读（模块表 + 预期行为） |
| `00-总览与状态/开发手册.md` | ~930 行 | 按 § 取节 |
| `数值真值表.md` | 2,350 行 / 140KB | **按 Sheet 取节**，别整读 |
| `产出登记表.md` | 264 行 / 71KB | **按 R / O / S 编号 grep**（超长表格行） |
| `10-模块设计/*` · `20-系统设计/*` | 单份 300~1,200 行 | 只读对应模块那一份 |
| `30-数据与决议/*` | 单份 300~600 行 | 按 § 取节 |
| `90-历史归档/*` | 累计 4MB+ | **默认不读**，只在回查时按日期/批次号取 |

> ⚠ **`模块一` / `日常循环` / `物品池设计方案` 三份没有 `##` 标题**（章节写成加粗段落），
> `docs:toc` 因「标题少于 3 个」跳过它们，**目前只能整份读或 grep**。要补目录得先把
> `**一、…**` 改成 `## 一、…`。
