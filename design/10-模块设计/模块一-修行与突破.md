四、综合契合度（连乘）

4.1 公式

```
综合契合度 = 功法契合 × 同参契合 × 灵地契合
```

维度 范围

功法契合 0.2 ~ 1.0（吕氏破境硬编 0.38）

同参契合 0 ~ 1.0（标签权重连续值，见 §4.3；代码过渡期 0.1 保底）

灵地契合 0.2 ~ 1.0（保底 0.2，见 §3.4）

连乘，任何一项短板都拖累整体。

4.2 功法契合

```
功法契合 = 品阶分 + 覆盖率 × 40% + 熟练度
```

> **吕氏破境（2026-10-18）**：《吕氏练气次第论》的 `baseFit = 0.38`，覆盖「品阶分 + 覆盖率」
> 的结果，熟练度仍在其上累加。`0.38 × 0.40 × 1.00 = 0.152`，刚好过练气三层 0.15。
> 这是原著「散功重修、按次第破境」的路线，**不是**品阶分能解释的加成。

项目 分值

品阶分 练气篇 20% / 筑基级 30% / 金丹级 40%

覆盖率 \|功法灵气 ∩ 修士灵气\| / \|修士灵气\|

熟练度 每 **50** 游戏小时 +1%（2026-10-17 起 ×2），上限 20%

功法契合上限：

品阶 不匹配 部分匹配 完全匹配

练气篇 40% 60% 80%

4.3 同参契合（**标签权重连续值**；2026-10-26 A1 废弃「正主/准正主」）

> **2026-10-26 拍板**：不再有「XX 的正主」这种定向绑定。同参契合 = **两件物品标签集合的
> 重合度**，0~1 连续，不设档位。落地排期 = 《下一步》**P37**（B7）。

4.3.1 公式

```
同参契合 = Σ(交集标签权重) / Σ(本命标签权重)     // 0 ~ 1.0
```

标签权重按层（《[装备词条表](../30-数据与决议/装备词条表.md)》§1）：
**顶层 1.0 · 中层 0.4 · 底层 0.25**（底层 = `category` / `fateElement`）。

- 分母永远是**本命自己的标签权重和**，所以「同一件物品」天然 = 100%。
- 只看标签集合，不看 id / 名字 / `series` 号 —— id 相等只是「恰好完全同标签」的特例。
- **不加防呆、不设保底**（P37 拍板 C）：完全不重合就是 0，同参槽放错东西就该没有收益。
  旧六档的「0.1 保底」只是代码过渡值。

4.3.2 算例（《装备词条表》§8，唯一口径）

```
本命【饕餮玉牌】= 灵器 0.25 + 牌 0.4 + 青金石 0.4 + 饕餮纹 1.0 + 暗金 1.0 = 3.05
同参【风磨铜盾】= 灵器 0.25 + 盾 0.4 + 风磨铜 0.4 + 坚固 1.0 + 饕餮纹 1.0 + 青金石 0.4 = 3.45
交集 = 灵器 0.25 + 青金石 0.4 + 饕餮纹 1.0 = 1.65
同参契合 = 1.65 / 3.05 = 54.1%
```

4.3.3 过渡期（P37 未落地前，**代码现状**）

- 物品上的 `affinity` 字段仍写死六档值，代码按它读 —— **不要把档位名当成设计口径**。
- 六档只是连续值的临时离散化：`1.0 / 0.8 / 0.6 / 0.4 / 0.25 / 0.1`。
  没有字段才走「同 id → 同 series → 同 category+kind → 其他」的粗回落。
- **开局五件硬编值保留**：`wu_li_zhu_yao` 0.6、`taotie_shield` 0.4（默认主同参）、
  `qingyu_sword` / `jinggang_ci` / `lingteng_shield` 0.25 ——
  这是保住「开局 0.08 → 吕氏 0.152」破境数学的前提。
- **P37 落地 = 删档位、改连续值、门槛一次性重算**（B7）。在那之前
  **不要单片调门槛**，也不要给某件物品临时加 `affinity`。

> 同参品阶不影响契合度，只影响稀有词条获得率（§10）。

五、修炼速度

5.1 公式

```
灵力/游戏小时 = 灵地基础产出
  × (0.98 + 综合契合度 × 0.32)
  × spiritRate
  × 本命数量系数
  × 行功带宽
  × (1 + 子嗣修炼加成)
  × 门控补偿 9.6
```

系数 说明

灵地基础产出 **5 阶**，20~140（见 §3.2 /《数值真值表》§1.4；2026-10-19 定）

契合度项 0% → 0.98×，100% → 1.30×（2026-10-18 按旧曲线重标定，见下）

spiritRate 每次内功突破 ×1.1

本命数量系数 单本命 1.0 / 双本命双灵根 0.8 / 三本命 0.7

行功带宽 占位，恒 1.0（设计见 §十四）

子嗣修炼加成 设计**无上限**（2026-10-17 决议）；真源在《模块二》§九

门控补偿 9.6 = 门控 2.4 × 时钟 4；灵力只在练功环节产出

**速度项为什么是 0.98/0.32**：连乘后综合契合度天然比加权和小（开局 0.5025 → 0.08），
沿用旧的 `0.7 + 0.6×Fit` 会让开局灵力掉 25%。新直线按旧曲线各阶段反推：

| 阶段 | 旧综合 → 旧因子 | 新综合 → 新因子 | 偏差 |
|---|---|---:|---:|
| 开局 | 0.5025 → 1.0015 | 0.08 → 1.0056 | +0.4% |
| 同系列同参 | 0.6425 → 1.0855 | 0.24 → 1.0568 | −2.6% |
| 筑基配置 | 0.7175 → 1.1305 | 0.56 → 1.1592 | +2.5% |
| 结丹配置 | 0.8500 → 1.2100 | 0.80 → 1.2360 | +2.1% |
| 满配 | 1.0000 → 1.3000 | 1.00 → 1.3000 | 0 |

开局灵力/游戏小时 **11.58**（重构前 11.54），游戏节奏基本不变；契合度的速度带宽
收窄到 0.98~1.30 —— 它仍然主要管门票，不是收益引擎。

十四、行功带宽（散功重修）

14.1 核心机制

```
行功带宽 = 基础带宽 1.0 + Σ(每次散功重修的带宽扩展)
```

14.2 五种散功情况

| 情况 | 说明 | 带宽扩展 |
|---|---|---|
| a. 旧功法重修 | 散功后重修同一本 | +0% |
| b. 差不多的功法 | 五行相同、类型相同、同级 | +10% |
| c. 全新功法 | 五行不同或类型不同 | +20% |
| d. 差不多的高级功法 | 五行相同、类型相同、高级 | +30% |
| e. 全新高级功法 | 五行不同或类型不同、高级 | +50% |

14.3 边际衰减

```
第 n 次重修的实际带宽扩展 = 基础扩展 × (1 / (1 + 0.1 × n))
```

14.4 带宽上限

```
行功带宽上限 = 1.0 + 已收集功法总数 × 0.5
```

14.5 散功代价

| 项目 | 变化 |
|---|---|
| 灵力 | 清零 |
| 内功修为 | 清零 |
| 境界 | 回练气一层 |
| 功法熟练度 | 减半 |
| 同参 | 不变（本就不能升级，只可更换） |
| 子嗣 | 不受影响 |
| 行功带宽 | 永久扩展 |

> 代码现状：`TUNING.bandwidth` 恒 1.0，五种散功/边际衰减/上限尚未实现。
> 散功重修的最小可行版（清空灵力与内功、熟练度减半、永久加成）已在 `practice.js` 落地。
