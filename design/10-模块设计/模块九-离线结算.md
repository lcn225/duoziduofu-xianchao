二、离线时长上限（修正版）

时长 收益效率 说明

0-8 小时 100% 正常结算

8-24 小时 90% 正常结算

1-2 天 80% 正常结算

2-3 天 70% 正常结算

3 天以上 收益停止 超出部分不结算

注：3 天以上收益停止，但时间是否继续推进取决于托管：

模式 3 天以上行为

全托管 时间继续推进，收益停止，托管日志继续记录

半托管 时间停在第一个未托管事件处

不托管 时间停在第一个特殊事件处

推荐：半托管 + 3 天收益上限。玩家最多离线 3 天，收益拿满；3 天后收益停止，但时间可继续推进到第一个未托管事件。

三、离线结算完整流程

```
1. 下线时记录 lastOnlineRealTime

2. 上线时计算 offlineRealSeconds

3. 判断离线时长：

- ≤ 3 天：正常结算

- > 3 天：只结算前 3 天

4. 按粒度批量结算：

- 秒级（灵力）：乘法

- 小时级（熟练度）：乘法

- 天级（侍妾状态、商队、建筑、子嗣成长）：遍历

- 月级（俸禄、投资）：乘法

- 年级（秋收、登仙大典）：乘法

5. 特殊事件处理：

- 已托管：自动处理，进托管日志

- 未托管：入队，时间暂停

6. 生成离线报告

7. 上线后展示报告 + 托管日志 + 事件队列
```

五、托管模式对比

模式 离线推进 上线处理 适用

全托管 一直推进，不停止 看报告和日志 长期挂机

半托管 停在第一个未托管事件 处理事件队列 默认

不托管 停在第一个特殊事件 处理所有事件 喜欢手动

七、关键设计原则

原则 说明

离线收益上限 3 天 超过 3 天不结算，防止长期挂机

默认半托管 子嗣诞生自动接受，其余弹窗

托管日志保留 玩家可查看离线期间自动处理的事件

特殊事件统一队列 在线离线统一处理

时间推进受托管影响 全托管一直推进，半托管停在未托管事件

离线效率随时长递减 0-8 小时 100%，3 天 70%
