## 一、模块定位

事件叙事系统是各模块的**粘合剂**，负责把修行、子嗣、内宅、封地、任务、经济中的关键节点串成故事线。

玩家离线时，事件自动触发、排队；上线后，以**事件卡**或**时间线**形式呈现，玩家做出选择，结果影响多个模块的数值和后续剧情。

**核心循环**：挂机等待 → 事件触发 → 上线处理 → 选择分支 → 影响各模块 → 触发后续事件。

> **v1 落点（✅ 2026-10-22 Q1 定稿）**：先做**探索叙事弹窗** —— 弹窗阻塞 UI 但**不暂停时钟**，
> 20 秒超时自动选善意，队列上限 3；**只做善意分支**（相助 / 离开），不加风险分支；
> 文案先用《探索系统》四图现有的 8 条（各图 2 条），模块八正式上线后替换。
> **✅ 2026-10-22 P31 已落地**（弹窗、队列、超时；动画另属 §9.2，未做）。
> 规则真源见《[探索系统](../20-系统设计/探索系统.md)》§9.1，时间口径见《[时间系统](../20-系统设计/时间系统.md)》§3.3。

## 二、事件类型

### 2.1 主线事件

跟随小说剧情推进，不可跳过，影响全局。

| 事件   | 触发条件   | 选项         | 影响          |
| ---- | ------ | ---------- | ----------- |
| 穿越首充 | 游戏开局   | 无          | 解锁系统，获得首充礼包 |
| 初见洪晃 | 首次进入山门 | 认错/犟嘴/沉默   | 洪晃好感        |
| 金盆洗手 | 门派开创   | 无          | 解锁飞鹰门       |
| 分封八柱 | 分赃大会后  | 无          | 获得下柱、长岭乡侯   |
| 长岭建设 | 首次进入封地 | 优先长墙/驿站/亭卫 | 封地建筑解锁顺序    |
| 登仙大典 | 每年秋分后  | 无          | 测灵根，人口增长    |
| 接孙任务 | 老五通知   | 接受/拒绝      | 触发远行剧情      |
| 腊月操演 | 每年腊月   | 无          | 军阵俸禄定级      |

### 2.2 角色事件

与特定 NPC 相关，影响派系好感。

| ----- | --------- | -------- | --------- |

| 老三递话  | 老三好感 > 50 | 附议/拒绝/沉默 | 老三好感，老八好感 |
| 老九吃差价 | 支账 > 10次  | 查账/忍让/告状 | 老九好感，灵石   |
| 老十挑衅  | 老十好感 < 30 | 还击/忍让/告状 | 老十好感，洪晃好感 |
| 洪晃暴怒  | 随机        | 认错/辩解/沉默 | 洪晃好感，可能挨罚 |

### 2.3 子嗣事件

| 发现遗迹  | 探索时  | 探索/上报/保密 | 功法，法器，风险 |

## 三、事件触发机制

### 3.1 触发条件

| 类型   | 说明             |
| ---- | -------------- |
| 时间触发 | 每月、每年、特定日期     |
| 数值触发 | 好感度、稳定度、民心达到阈值 |
| 行为触发 | 玩家完成特定操作       |
| 随机触发 | 每日概率判定         |
| 连锁触发 | 前序事件完成后触发后续    |

### 3.2 事件队列

- 离线时，事件自动触发并进入**事件队列**。
- 队列上限 20 条，超出则合并或丢弃低优先级事件。
- 上线时，按优先级依次弹出事件卡。
- 玩家可**批量处理**低优先级事件。

### 3.3 事件优先级

| 优先级 | 类型             | 说明     |
| --- | -------------- | ------ |
| 紧急  | 子嗣陨落、侍妾下毒、妖兽入侵 | 立即处理   |
| 高   | 合议、职位晋升、子嗣诞生   | 当日处理   |
| 中   | 争宠、告状、商队遇劫     | 3 日内处理 |
| 低   | 怀孕喜讯、侍妾生病、流民来投 | 7 日内处理 |
| 背景  | 秋收、登仙大典、幡阵操演   | 自动结算   |

## 五、事件分支与连锁

### 5.1 分支示例

**子嗣陨落事件**：

```
子嗣陨落
├── [复仇] → 对相关势力发起攻击 → 可能触发征战任务
├── [抚恤] → 安抚生母 → 生母好感 +10，其他子嗣好感 +5
└── [遗忘] → 无变化 → 生母好感 -20，其他子嗣好感 -10
```

**老九吃差价事件**：

```
老九吃差价
├── [查账] → 发现贪墨 → 老九好感 -20，返还灵石
│         └── 老九可能报复 → 后续事件
├── [忍让] → 无变化 → 老九继续吃差价
└── [告状] → 洪晃介入 → 老九好感 -30，洪晃好感 +5
          └── 老八系报复 → 后续事件
```

### 5.2 连锁事件

| 前序事件  | 选择  | 后续事件        |
| ----- | --- | ----------- |
| 子嗣陨落  | 复仇  | 征战任务，势力好感变化 |
| 老九吃差价 | 告状  | 老八系报复，执法调查  |
| 争宠    | 偏袒  | 被冷落侍妾出逃     |
| 妖兽入侵  | 求援  | 门派支援，贡献消耗   |
| 流民来投  | 接纳  | 人口增长，民心变化   |
| 矿脉发现  | 上报  | 门派奖励，郑家觊觎   |

## 九、可玩性设计要点

1. **事件卡是主要叙事载体**：每次上线处理事件队列，像看故事一样。
2. **选择有实际影响**：每个选择影响多个模块的数值和后续剧情。
3. **连锁事件提供深度**：前序选择触发后续事件，形成分支叙事。
4. **优先级系统减少负担**：紧急事件立即处理，低优先级可批量处理。
5. **批量处理节省操作**：玩家可一键处理低优先级事件。
6. **时间线提供回顾**：所有事件按时间排序，可回顾历史。
7. **离线事件自动触发**：离线时事件自动排队，上线后集中处理。
8. **事件类型多样化**：主线、角色、子嗣、内宅、封地、门派、奇遇。
9. **奇遇提供惊喜**：低概率触发，提供额外奖励或风险。
10. **事件与各模块深度联动**：子嗣陨落触发修行返还，内宅争宠影响稳定度。
