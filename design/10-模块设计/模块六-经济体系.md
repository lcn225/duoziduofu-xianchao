## 零、三条前置口径（先钉死）

### 0.1 时间单位：游戏月

· 所有收支按游戏月（30 游戏天）计。

· 阶段长度：生存 5.9 月 / 扎根 35.4 月 / 扩张 225.8 月 / 仙朝待定。

· 「年」只作展示（12 月），不作配平单位。原因：生存阶段只有 5.9 个月，按年算会得出「玩家活不到一年」的错数。

### 0.2 三层字段、四阶面额（2026-10-20 货币 v2）

货币单位，不是货币种类——同一层内自动进位，不再手动兑换。**数据结构改成三个字段**：

```js
currency = {
  secular: 0,   // 总大子数（整数）；100 大子 = 1 金页子，自动进位
  spiritual: 0, // 总一阶灵石数（整数）；100 一阶 = 1 二阶，800 二阶 = 1 三阶，自动进位
  strategic: 0  // 四阶灵石数（整数）；不进位、不兑换、不参与商品流通
}
```

| 字段 | 最小单位 | 进位链 | 用途 |
|---|---|---|---|
| `secular` | 大子 | **100 大子 = 1 金页子** | 凡俗层一切消费 |
| `spiritual` | 一阶灵石 | **100 一阶 = 1 二阶；800 二阶 = 1 三阶** | 修仙层一切消费 |
| `strategic` | 四阶灵石 | 不进位 | 战略级支出（仙朝建设、跨域贸易） |

· **同层自动进位**：大子↔金页子、一阶↔二阶↔三阶都由显示层自动拆面额，**没有手动兑换按钮**。
  P17 的「大子↔金页子 100:1 兑换」作废。

· **跨层手动兑换**：只有凡俗 ↔ 修仙要手动，用**买卖价差**收手续费（§十）。
  三阶 = 800 二阶 = 80,000 一阶。

· **四阶灵石** `strategic` 独立：不进位、不参与跨层兑换、不参与商品流通；
  获取途径与消耗口待模块五/八。

· 两条账本分开记，不合并成「折算二阶」。v1 的「折算二阶」列全部删除。

**显示规则**（代码：`plugins/currency.js` 的 `formatSecular` / `formatSpiritual` / `formatStrategic`）：

| 条件 | 显示 | 示例 |
|---|---|---|
| 金页子 < 10,000 | `X 金页子 Y 大子`（大子为 0 也写） | `123 金页子 0 大子` |
| 金页子 ≥ 10,000 | `X.X 万金页子`（省略大子零头，余额不动） | `1.2 万金页子` |
| 一阶 < 100 | `X 一阶` | `34 一阶` |
| 100 ≤ 一阶 < 80,000 | `X 二阶 Y 一阶`（中间 0 也写） | `12 二阶 0 一阶` |
| 一阶 ≥ 80,000 | `X 三阶 Y 二阶 Z 一阶`（全写） | `1 三阶 0 二阶 34 一阶` |
| 四阶 | `X 四阶` | `5 四阶` |

## 三、封地税收（✅ 2026-10-19 已反推）

### 3.1 公式

```
月税收（金页子）= 人口
                 × 0.003（金页子/人/月）
                 × 2^(乡侯府等级 − 1)
                 × 民心系数
                 × (1 + 繁荣度/100)
```

| 参数 | 值 | 说明 |
|---|---:|---|
| 人均税收 | **0.003 金页子/人/月**（0.3 大子） | 5,600 人时是「每级乡侯府 ×2」的阶梯 |
| 乡侯府等级系数 | **2^(等级−1)** = 1/2/4/8/16 | Lv1 征收未开；Lv2 起有进度条 |
| 民心系数 | **分级表** 1.20/1.10/1.00/0.90/0.80/0.50 | 见模块四 §4.2；**不是 `民心/50`** |
| 繁荣度系数 | `1 + 繁荣度/100` | 繁荣度 30→100 时 ×1.3→×2.0 |

> **`民心/50` 已删除**：它在民心 100 时给 ×2，与「拥戴 +20%」直接矛盾。
> 繁荣度只乘税收，不乘建筑产出（模块四 §十）。

### 3.2 覆盖约束（已验证）

| 阶段 | 乡侯府 | 民心/繁荣 | 月税收（金页子） | 凡俗月支出 | 覆盖率 |
|---|---:|---|---:|---:|---:|
| 扎根 | Lv2 | 50 / 30 | **43.7** | 72.3 | 60% |
| 扩张早期 | Lv3 | 70 / 60 | **118.3** | 201 | 59% |
| 扩张后期 | Lv4 | 70 / 80 | **266.1** | 201 | 132% |
| 仙朝 | Lv5 | 90 / 100 | **645.1** | 436 | 148% |

→ 符合原约束：生存 0；扎根 50–70%；扩张中后期 100%+；仙朝 100%+。
凡俗支出 = 侍妾月饷（均 1 金页子）+ 无灵根子嗣月钱 + 家仆，假设见真值表 §6.8.2。
**仙朝的 148% 盈余**留给 §2.1 的两项待反推支出：联姻彩礼（凡俗部分）与封地凡俗建设；
不是税收给多了。

### 3.3 人口增长曲线（⚠ 待重算，第一批不做）

· 旧 v1 的「建设次数 ×1.5 成本曲线、招揽流民 ×1.3 成本曲线」**与 v2 基准不相容**：
  20 次建设后单次成本会到 24,354 二阶，远超扩张阶段 315–360 二阶/月的预算。

· **第一批不做人口增长**，人口固定 5,600。若要做，改用 ×1.2 或线性曲线，
  并把人均税 0.003 下调（否则税收随人口线性膨胀）。

· 详见模块四 §10.6 与真值表 §6.8.6。

## 一、三个核心量（替代“盈余率”）

| 概念 | 公式 | 用途 |

|---|---|---|

| **必要支出** | 丹药 + 月饷 + 月钱 + 维护 | 不花活不下去 |

| **投资需求** | 封地建设 + 商队投资 + 联姻 + 开拓 | 设计上希望玩家投的钱 |

**两条约束**：

1. **可支配资金 ≥ 投资需求 × 覆盖率**（覆盖率前紧后松）

## 三、回收口：硬约束 + 抽象兜底

| 项 | 处理 |

|---|---|

## 四、反推链条（修正后）

```
① 定必要支出（丹药/月饷/月钱，按境界和人口）

② 定投资需求（封地建设/商队/联姻，按阶段目标）

③ 定覆盖率（生存 1.0–1.1 / 扎根 1.1–1.3 / 扩张 1.3–1.6 / 仙朝 1.5–2.0）

④ 收入 = 必要支出 + 投资需求 × 覆盖率

⑤ 回收口容量 ≥ 收入 − 必要支出 − 投资需求

⑥ 生存阶段覆盖率缺口用一次性福利补（事件/首杀/开局礼包/宝箱赠送）
```

**第 ⑥ 步是生存阶段的关键**：覆盖率 1.0–1.1 下，收入可能刚好够投资，抽奖靠宝箱，不靠灵石。宝箱是一次性/低频率产出，不计入重复产出（产出登记表 O 类），不影响长期门槛重算。
