## 一、系统定位

任务战斗系统是**纯挂机**系统，玩家不操作具体战斗，只负责**配置队伍、选择任务、派遣、等待结算**。

**核心循环**：

```
接任务 → 勾选人选 → 填充战阵 → 出发 → 自动战斗 → 结算战报
```

**统一范围**：任务派遣、大型探索/任务、子嗣挂机，全部统一为同一个系统。

- 战斗过程不影响结果（结果是出发时已确定的）

### 4.1 阶段设计

| 阶段  | 内容   | 耗时   | 风险  |

| 1   | 侦察   | 7 天  | 低   |

**每个阶段结束后，进入阶段间界面。**

### 4.2 阶段间功能

**阶段间可以：**

| 功能         | 说明           |
| ---------- | ------------ |
| **查看阶段战报** | 了解本阶段战果      |
| **触发随机事件** | 阶段间概率触发      |
| **调整队伍**   | 更换队员、调整战阵    |

| **补充物资**   | 消耗灵石购买丹药、符箓  |
| **撤退**     | 放弃任务，保留已获得收益 |

| 士气高涨 | 下阶段战力 +10%   |
| 内讧   | 队伍战力 -15%    |

### 4.6 阶段增益（原《大型探索阶段增益系统》）

> ⚠ 本节是**多阶段大型任务**的增益；《三大挂机》里的「探索」是另一套文字挂机系统，
> 两者暂未对齐（见《下一步》P5）。阶段增益与秘境层间增益**互不影响**。

**流程**：阶段结算 → 随机事件触发 → 主动选择增益（3 选 1）→ 据点建设/调整队伍 → 继续推进。

| 品质 | 概率 | 示例 |
|---|---:|---|
| 普通 | 70% | +10% 战力、-10% 受伤概率、+10% 成功率 |
| 稀有 | 25% | +20% 战力、+15% 成功率、+20% 资源产出 |
| 史诗 | 5% | +50% 战力、免疫一次陨落、+30% 全属性 |

**增益池**：

- 普通（70%）：战力提升 +10%、防御强化 -10% 受伤、战术优化 +10% 成功率、资源采集 +15%、
  士气激励 +10% 经验、粮草储备 -20% 消耗、情报收集 -10% 事件概率。
- 稀有（25%）：战力大增 +20%、铜墙铁壁 -20% 受伤、运筹帷幄 +15% 成功率、资源丰收 +30%、
  士气如虹 +25% 经验、灵脉共鸣 +30% 建设速度、丹药储备（一阶 ×10）。
- 史诗（5%）：极限突破 +50% 战力、不朽之躯（免疫一次陨落）、战圣至尊 +30% 全属性、
  大道共鸣 +30% 成功率、天材地宝（二阶 ×5）、灵脉贯通 +50% 建设速度、阵法精通（阵法加成翻倍）。

**叠加规则**：

```
最终战力 = 基础战力 × (1 + 所有战力增益之和)
```

- 不同名增益可叠加；**同名只取最高值**。
- 上限：战力 +200%、受伤减免 -80%、成功率 +50%、资源产出 +100%。
- 增益永久生效到本次任务结束；任务结束即失效。

**与秘境层间增益的区别**：触发时机（阶段结束 vs 每层通关）、生效范围（本次任务 vs 本次爬塔），
其余形式（3 选 1、三档品质）相同；两套系统独立。

## 五、战斗结算

### 5.1 成功率公式

```
成功率 = 基础 50% 
       + (队伍战力 - 推荐战力) / 推荐战力 × 30%
       + 子嗣好感加成
       + 词条加成
       + 阵法加成
       - 风险惩罚
```

**上限 95%，下限 5%。**

### 5.2 失败惩罚

| 失败程度 | 判定          | 后果          |
| ---- | ----------- | ----------- |
| 轻败   | 成功率差 10% 以内 | 队员受伤，奖励减半   |
| 中败   | 成功率差 10-30% | 队员重伤，奖励 30% |
| 重败   | 成功率差 30% 以上 | 队员陨落，无奖励    |

**队员陨落**：有灵根子嗣陨落触发修行返还；无灵根子嗣陨落不返还。

### 5.3 战报类型

| 类型  | 内容              |
| --- | --------------- |
| 大胜  | 全额奖励，队员经验 +100% |
| 小胜  | 全额奖励，队员经验 +50%  |
| 惨胜  | 奖励减半，队员受伤       |
| 失败  | 奖励 30%，队员重伤     |
| 惨败  | 无奖励，队员陨落        |

## 六、事件中的战斗与单挑

### 6.1 处理方式

| 场景              | 处理方式           |
| --------------- | -------------- |
| 简单事件（妖兽袭击、路遇劫匪） | 事件选择（简单判定）     |
| 复杂事件（妖兽入侵、商队遇劫） | 触发任务（进入任务派遣系统） |
| 单挑（老十挑衅等）       | 事件选择（简单判定）     |

### 6.2 事件选择判定

```
成功概率 = 基础 50% + 主角战力加成 + 队伍加成 + 词条加成
```

**示例**：

```
┌─────────────────────────────────────────┐
│  【事件】妖兽袭击                         │
│                                         │
│  长岭关外发现一只变异恐獾，正向村庄逼近。   │
│                                         │
│  [亲自出手] 消耗精力 30，成功率 85%        │
│  [派子嗣处理] 派遣队伍，进入任务系统       │
│  [求援门派] 消耗贡献 100，自动成功         │
│  [放任不管] 民心 -10                      │
└─────────────────────────────────────────┘
```

### 6.3 单挑判定

```
胜率 = 基础 50% + (我方战力 - 对方战力) / 对方战力 × 30%
```

**示例**：

```
┌─────────────────────────────────────────┐
│  【事件】老十挑衅                         │
│                                         │
│  老十当众辱骂你，要和你比试。              │
│                                         │
│  [应战] 消耗精力 20，胜率 70%             │
│         胜：老十好感 -20，威望 +10        │
│         败：老十好感 +10，威望 -10        │
│  [忍让] 老十好感 +5，威望 -5              │
│  [告状] 洪晃好感 +5，老十好感 -30         │
└─────────────────────────────────────────┘
```

## 七、队伍配置

### 7.1 队伍槽位

| 槽位  | 职责      | 推荐          |
| --- | ------- | ----------- |
| 大盾将 | 防御，保护全队 | 桂冈、桂大（盾将词条） |
| 天幡将 | 阵法主攻    | 老三、桂二（剑修词条） |
| 地幡将 | 阵法辅助    | 老四、桂四       |
| 人幡将 | 阵法辅助    | 老八、桂六       |
| 游击将 | 输出/支援   | 老十、桂五       |
| 替补  | 随时递补    | 任意          |

### 7.2 阵法加成

| 配置       | 加成   |
| -------- | ---- |
| 三才幡阵完整   | +30% |
| 大盾将 + 剑修 | +15% |
| 纯输出      | +5%  |
| 无阵型      | +0%  |

### 7.3 子嗣战力计算

```
子嗣战力 = 基础战力 × 境界系数 × 灵根系数 × 本命系数 × 词条系数
```

| 项目   | 系数                                              |
| ---- | ----------------------------------------------- |
| 境界系数 | 练气一层 1.0 → 练气十层 5.0 → 筑基初期 10.0                 |
| 灵根系数 | 五灵根 0.8 / 四灵根 1.0 / 三灵根 1.2 / 双灵根 1.5 / 单灵根 2.0 |
| 本命系数 | 1 阶 1.0 / 2–3 阶 1.2 / 4 阶 1.5 / 5 阶 2.0（按物品池基阶；旧词作废） |
| 词条系数 | 普通 +5% / 稀有 +10% / 传说 +20%                      |

### 13.1 任务刷新与接取

### 13.2 三类任务

### 13.3 贡献点与秘库（**2026-10-26 A1 重写：三层机制**）

> 来源：`90-历史归档/讨论-2026-10-26/原始/备忘录：A1…md`。**取代**本文 2026-10-25 版的

|---|---|
| 归属 | 家主（桂冈）资源，家族共享 |

#### 13.3.1 三层机制

| 层 | 机制 | 定价 | 作用 |
|---|---|---|---|
| **① 基础福利** | 每游戏月自动刷新 3~4 件 | 200~300 点/件；残页 600 点/张 | 稳步推进，**保底线** |
| **② 赌狗速刷** | 花贡献点**手动刷新**货架 | **50 → 100 → 200 → 400 …**（当月内指数递增，**下月重置回 50**） | 货架不对味时止损，防无尽刷新 |
| **③ 老九订货** | 下单 → **游戏内 1 个月**（≈48 名义分钟）→ 带回货 | **400 点/次**，**不缩短时间** | 死活刷不到想要标签时的**定向保底** |

**老九暗池算法（③ 的落地口径）**：

1. 下单瞬间后台按玩家本命生成暗池：**5~10 件高阶底材**，其中**保底 1~2 件高契合**（标签高度重合）。
2. 从暗池里提取全部标签，**亮 4~5 个给玩家选**（如 `饕餮纹` / `器` / `青金石` / `锋锐` / `镇邪`）。
3. 玩家**选定 1 个标签**。
4. 1 游戏月后老九归来，按选定标签在暗池中**加权抽取**（选中标签权重极高），带回 **1~2 件**对应底材。

> **UI（#5）**：秘库页要有「暗池标签展示」区（4~5 个标签、选中态、锁定后显示倒计时）；
> **老九倒计时常驻**在封地 / 内政界面的挂件上（游戏内 1 个月，不随离线停）。

#### 13.3.2 与筑基突破的关系（**双轨，2026-10-26 A1**）

玩家从练气八层破到筑基，缺两件东西：**高契合度的同参底材** + **筑基功法**（如《万兽御器经》）。

| 轨 | 来源 | 口径 |
|---|---|---|
| **① 看脸** | **秘境 / 宝箱** | **掉落与开箱概率一律不改**。脸好直接开出带 `饕餮纹` 的极品底材或功法残页 |
| **② 兜底** | **秘库三层** | 基础货架 / 手动刷新 / 老九订货；残页 3 张 ×600 = 1,800 点 ≈ **2.6 游戏月**（实际 1.5~1.8 / 名义 2.1 现实小时） |

- **不设定向掉率**：不存在「21~30 层掉准正主 1%」这种表（旧口径 2026-10-26 作废）。
- **“准正主 / 正主”只作为来源品类标签存在**（掉落/秘库文案可以说“高阶底材”），
  **不参与任何计算** —— 计算只看标签契合度（模块一 §4.3）。
- 秘库的高阶底材是**随机供货**，未必刷得到想要的那件；老九订货才是定向。

> **落地登记**：贡献点是新资源、秘库是新产出渠道，落地时按 R 类登记（产出登记表 R22）
> 并重算门槛；但**练气九层 / 筑基的门槛值本身不改**（双轨不改概率，只加兜底时间）。
