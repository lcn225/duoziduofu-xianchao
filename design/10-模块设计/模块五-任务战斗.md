## 一、系统定位

任务战斗系统是**纯挂机**系统，玩家不操作具体战斗，只负责**配置队伍、选择任务、派遣、等待结算**。

**核心循环**：

```
接任务 → 勾选人选 → 填充战阵 → 出发 → 自动战斗 → 结算战报
```

**统一范围**：任务派遣、大型探索/任务、子嗣挂机，全部统一为同一个系统。

- 战斗过程不影响结果（结果是出发时已确定的）

### 4.1 阶段设计

| 阶段  | 内容   | 耗时   | 风险  |

| 1   | 侦察   | 7 天  | 低   |

**每个阶段结束后，进入阶段间界面。**

### 4.2 阶段间功能

**阶段间可以：**

| 功能         | 说明           |
| ---------- | ------------ |
| **查看阶段战报** | 了解本阶段战果      |
| **触发随机事件** | 阶段间概率触发      |
| **调整队伍**   | 更换队员、调整战阵    |

| **补充物资**   | 消耗灵石购买丹药、符箓  |
| **撤退**     | 放弃任务，保留已获得收益 |

| 士气高涨 | 下阶段战力 +10%   |
| 内讧   | 队伍战力 -15%    |

### 4.6 阶段增益（原《大型探索阶段增益系统》）

> ⚠ 本节是**多阶段大型任务**的增益；《三大挂机》里的「探索」是另一套文字挂机系统，
> 两者暂未对齐（见《下一步》P5）。阶段增益与秘境层间增益**互不影响**。

**流程**：阶段结算 → 随机事件触发 → 主动选择增益（3 选 1）→ 据点建设/调整队伍 → 继续推进。

| 品质 | 概率 | 示例 |
|---|---:|---|
| 普通 | 70% | +10% 战力、-10% 受伤概率、+10% 成功率 |
| 稀有 | 25% | +20% 战力、+15% 成功率、+20% 资源产出 |
| 史诗 | 5% | +50% 战力、免疫一次陨落、+30% 全属性 |

**增益池**：

- 普通（70%）：战力提升 +10%、防御强化 -10% 受伤、战术优化 +10% 成功率、资源采集 +15%、
  士气激励 +10% 经验、粮草储备 -20% 消耗、情报收集 -10% 事件概率。
- 稀有（25%）：战力大增 +20%、铜墙铁壁 -20% 受伤、运筹帷幄 +15% 成功率、资源丰收 +30%、
  士气如虹 +25% 经验、灵脉共鸣 +30% 建设速度、丹药储备（一阶 ×10）。
- 史诗（5%）：极限突破 +50% 战力、不朽之躯（免疫一次陨落）、战圣至尊 +30% 全属性、
  大道共鸣 +30% 成功率、天材地宝（二阶 ×5）、灵脉贯通 +50% 建设速度、阵法精通（阵法加成翻倍）。

**叠加规则**：

```
最终战力 = 基础战力 × (1 + 所有战力增益之和)
```

- 不同名增益可叠加；**同名只取最高值**。
- 上限：战力 +200%、受伤减免 -80%、成功率 +50%、资源产出 +100%。
- 增益永久生效到本次任务结束；任务结束即失效。

**与秘境层间增益的区别**：触发时机（阶段结束 vs 每层通关）、生效范围（本次任务 vs 本次爬塔），
其余形式（3 选 1、三档品质）相同；两套系统独立。

## 五、战斗结算

### 5.1 成功率公式

```
成功率 = 基础 50% 
       + (队伍战力 - 推荐战力) / 推荐战力 × 30%
       + 子嗣好感加成
       + 词条加成
       + 阵法加成
       - 风险惩罚
```

**上限 95%，下限 5%。**

### 5.2 失败惩罚

| 失败程度 | 判定          | 后果          |
| ---- | ----------- | ----------- |
| 轻败   | 成功率差 10% 以内 | 队员受伤，奖励减半   |
| 中败   | 成功率差 10-30% | 队员重伤，奖励 30% |
| 重败   | 成功率差 30% 以上 | 队员陨落，无奖励    |

**队员陨落**：有灵根子嗣陨落触发修行返还；无灵根子嗣陨落不返还。

### 5.3 战报类型

| 类型  | 内容              |
| --- | --------------- |
| 大胜  | 全额奖励，队员经验 +100% |
| 小胜  | 全额奖励，队员经验 +50%  |
| 惨胜  | 奖励减半，队员受伤       |
| 失败  | 奖励 30%，队员重伤     |
| 惨败  | 无奖励，队员陨落        |

## 六、事件中的战斗与单挑

### 6.1 处理方式

| 场景              | 处理方式           |
| --------------- | -------------- |
| 简单事件（妖兽袭击、路遇劫匪） | 事件选择（简单判定）     |
| 复杂事件（妖兽入侵、商队遇劫） | 触发任务（进入任务派遣系统） |
| 单挑（老十挑衅等）       | 事件选择（简单判定）     |

### 6.2 事件选择判定

```
成功概率 = 基础 50% + 主角战力加成 + 队伍加成 + 词条加成
```

**示例**：

```
┌─────────────────────────────────────────┐
│  【事件】妖兽袭击                         │
│                                         │
│  长岭关外发现一只变异恐獾，正向村庄逼近。   │
│                                         │
│  [亲自出手] 消耗精力 30，成功率 85%        │
│  [派子嗣处理] 派遣队伍，进入任务系统       │
│  [求援门派] 消耗贡献 100，自动成功         │
│  [放任不管] 民心 -10                      │
└─────────────────────────────────────────┘
```

### 6.3 单挑判定

```
胜率 = 基础 50% + (我方战力 - 对方战力) / 对方战力 × 30%
```

**示例**：

```
┌─────────────────────────────────────────┐
│  【事件】老十挑衅                         │
│                                         │
│  老十当众辱骂你，要和你比试。              │
│                                         │
│  [应战] 消耗精力 20，胜率 70%             │
│         胜：老十好感 -20，威望 +10        │
│         败：老十好感 +10，威望 -10        │
│  [忍让] 老十好感 +5，威望 -5              │
│  [告状] 洪晃好感 +5，老十好感 -30         │
└─────────────────────────────────────────┘
```

## 七、队伍配置

### 7.1 队伍槽位

| 槽位  | 职责      | 推荐          |
| --- | ------- | ----------- |
| 大盾将 | 防御，保护全队 | 桂冈、桂大（盾将词条） |
| 天幡将 | 阵法主攻    | 老三、桂二（剑修词条） |
| 地幡将 | 阵法辅助    | 老四、桂四       |
| 人幡将 | 阵法辅助    | 老八、桂六       |
| 游击将 | 输出/支援   | 老十、桂五       |
| 替补  | 随时递补    | 任意          |

### 7.2 阵法加成

| 配置       | 加成   |
| -------- | ---- |
| 三才幡阵完整   | +30% |
| 大盾将 + 剑修 | +15% |
| 纯输出      | +5%  |
| 无阵型      | +0%  |

### 7.3 子嗣战力计算

```
子嗣战力 = 基础战力 × 境界系数 × 灵根系数 × 本命系数 × 词条系数
```

| 项目   | 系数                                              |
| ---- | ----------------------------------------------- |
| 境界系数 | 练气一层 1.0 → 练气十层 5.0 → 筑基初期 10.0                 |
| 灵根系数 | 五灵根 0.8 / 四灵根 1.0 / 三灵根 1.2 / 双灵根 1.5 / 单灵根 2.0 |
| 本命系数 | 1 阶 1.0 / 2–3 阶 1.2 / 4 阶 1.5 / 5 阶 2.0（按物品池基阶；旧词作废） |
| 词条系数 | 普通 +5% / 稀有 +10% / 传说 +20%                      |

### 13.1 任务刷新与接取

| 项 | 口径 |
|---|---|
| 普通任务 | 每游戏周 3 个，约 30 贡献点/个 |
| 困难任务 | 每游戏月 3 个，约 100 贡献点/个 |
| 同时接取 | 最多 3 个 |
| 放弃 | 随时，无惩罚 |
| 动态难度 | 要求物品、杀怪层数、驻扎境界门槛随主角当前境界提升 |

**贡献点月产（2026-10-26 A1）**：普通 3 个/游戏周 × 30 + 困难 3 个/游戏月 × 100
= 90/周 × 4.286 周 + 300 ≈ **690 点/游戏月**。这个数是秘库定价与升职门槛的唯一锚点，
改刷新或单价必须同步重算（真值表 §6.4c）。

### 13.2 三类任务

| 类型 | 形式 | 执行者 | 时间 |
|---|---|---|---|
| 交物品 | 背包满足条件一次性交齐（如 回气丹·中品以上 ×5） | **玩家** | 即时 |
| 杀怪 | 固定 5 层微型副本，第 5 层 Boss 即完成；复用秘境战斗 | **桂冈 + 子嗣**（可手操） | 扣 **1 游戏天** |
| 驻扎 | 1~3 名满足境界的子嗣进入「驻扎中」，到时 100% 完成 | **子嗣** | 按时长 |

> **与 §12.1 #1「任务由子嗣执行」的差异**：§12 的原意是「任务不占用桂冈」。
> 杀怪任务要验证当前队伍战力，所以允许桂冈出手；交物品本来就是玩家操作。
> **子嗣的「家族工作 / 历练 / 任务 / 驻扎」仍然是四选一**（§12.1 #13 + 本版加驻扎）。

#### 13.3.1 贡献点（2026-11-06 重构）

| 来源 | 数量 |
|---|---|
| 任务 | ≈**690 点/游戏月**（普通 3×30/周 + 困难 3×100/月，不变） |
| **俸禄 90%** | 下柱 **750** / 中柱 **1,350** / 上柱 **2,250 点/游戏月** |
| **合计月入** | 下柱 **≈1,440** / 中柱 **≈2,040** / 上柱 **≈2,940 点/游戏月** |

- **1 贡献点 = 1 二阶灵石**（锚点）—— 因为俸禄的 10% 能提现成灵石，两条轴必须 1:1 挂钩。
- 俸禄的 10% **不再自动结算成现银**，改为**累积到可提现额度**，玩家手动提现（见 13.4.1）。
- **累计贡献 = 终身「获得」的总和**（任务 + 俸禄 90%），**提现与消费都不扣**。
  升职门槛读它，不读当前持有。
- ⚠ **预期行为（不是 bug）**：贡献点按**游戏时间**发、货架按**现实时间**刷，
  金丹段仍约 **37 倍**供大于求（上柱 24,300 点/游戏年 ÷ 3.48 现实分钟 vs 货架 9 位/48 现实分钟）。
  **没有随「挂账删除」自动消失**，见《下一步》新待办。本批只做页面，错配另批处理。

#### 13.3.2 货架结构（两栏 / **9 个库位**）

| 栏 | 库位 | 卖什么 | 怎么出 |
|---|---:|---|---|
| **功法栏** | **3** | **心法整本**（只卖心法，**不卖残页**） | 按境界段全随机、**排除已学**、不保底 |
| **物资栏** | **6** | 法器 / 灵兽 / 灵材 / **同参底材** | 总类不限、按境界段随机；同参底材也在这里随机出现 |

- **残页不上架**：2026-10-30 决议继续有效 —— 残页只从探索「无字石碑」掉，
  ~~600 点/张~~ 不再复活。
- **非心法整本不上架**：只从探索「传承印记」掉（《功法系统》§7.1）。
- **原「同参底材 10~12 件/段、限购 1 件/月/段」作废**（2026-11-06 用户拍板）：
  底材并进物资栏随机，**不再有「当月一件保底」**。定向兜底改由**老九订货**承担
  （2 倍价 + 1 游戏月等待，见 13.3.3）。
- **月刷**：每月 9 个库位**全部重随**；**手动刷新 50 → 100 → 200 → 400**（月内递增，下月重置）。
- **库位制天然限流**：每库位买一次就空，所以哪怕灵器不堆叠（P62），
  一个月最多也只进 **9 件**，不会重演「物品表撑到 12 万条」。

#### 13.3.3 老九订货（定向通道）

| 项 | 口径 |
|---|---|
| 定位 | **定向购买**：货架随机，老九定方向 |
| 价格 | **货架价 × 2**（2026-11-06 改；旧「400 点/次」作废） |
| 交付 | **1 游戏月**（48 现实分钟），不缩短 |
| 机制 | 保留原暗池：5~10 件、亮 4~5 个标签选 1、按选中标签加权带回 **1 件**（2026-11-06 拍板，原「1~2 件」作废） |

**暗池算法（原口径保留）**：

1. 下单瞬间按玩家本命生成暗池：**5~10 件高阶底材**，其中**保底 1~2 件高契合**（标签高度重合）。
2. 从暗池里提取全部标签，**亮 4~5 个给玩家选**（如 `饕餮纹` / `器` / `青金石` / `锋锐` / `镇邪`）。
3. 玩家**选定 1 个标签**。
4. 1 游戏月后老九归来，按选定标签**加权抽取**（选中标签权重极高），带回 **1 件**对应底材。

#### 13.3.6 时间轴（现实秒，2026-10-30 定，继续有效）

> ⚠ **时间轴 = 现实秒，不是游戏秒**。
> 飞鹰门是**玩家操作驱动**的系统（接任务 / 点交付 / 刷货架），而筑基后时钟 24×

> 任务货架标「普通任务 X 后刷新 · 困难任务 Y 后刷新」，飞鹰阁标「每月自动换货（Z 后）」，
> 进行中的任务与老九倒计时也按秒走。倒计时读 `factionLiveRealSeconds`（墙钟零头已补），
> 不能直接读存档里的 `realSeconds`（那个只在日结钩子推进，会一跳一跳）。

> **《万兽御器经》**：在**功法栏**，一次性、**不保底出现**。
> 练气段池 ≈24 本心法、每月抽 3 本（+ 手动刷新）⇒ **约 2 个游戏月期望到手**，
> 不手动刷新则约 7 个月。**手动刷新是关键**，这是设计意图。
