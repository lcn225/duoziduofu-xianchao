> **灵根分布不会因元素占比变化而变**：`rollFateSet` 是**按可用灵气均匀抽**，
> 不按池子条目数加权（见 `items.js` 注释）。7 种灵气都还有一阶底材，
> 所以分布仍是 **5.0 / 18.5 / 32.1 / 35.6 / 8.8**（2026-10-19 实测）。
> 落地后跑 `npm run sim:fates` 只是确认，不需要重新配平。

> ✅ **`fateElement` 已统一为英文**（2026-10-20 拍板）：
> 代码真源 `items.js` 的 `FATE_ELEMENTS = ['metal','wood','water','fire','earth','beast','vessel']`，

## E. 执行顺序

1. 备份当前手工池与 `items.data.js`。
2. 按 A 删除 30 条。
3. 按 B 修改 37 条，`id` 不变；仅指定条目改 `type/series`。
4. 按 C 新增 200 条：以 [`新增灵材200.json`](新增灵材200.json) 为准。
5. 跑 `python scripts/build-items.py` 重新生成 `items.data.js`。
6. 跑 D 的池统计断言，确认总数 **570**；再跑 `npm run sim:fates` 与 `npm run verify`。

> 落地时按《当前实现》的「旧档快照不批量重算」口径处理，别顺手改老档加成。
