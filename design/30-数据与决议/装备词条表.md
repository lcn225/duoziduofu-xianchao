## 0. 列定义

| 列 | 含义 | 谁在读 |
|---|---|---|
| **词条** | 同一行内的词**同层、同属性、同槽、同系数**（等价皮肤） | 两边 |
| **层级** | 课题 B 的三层标签层级：顶层 / 中层 / 底层 | 课题 B 算权重 |
| **权重** | 由层级派生：顶层 **1.0** · 中层 **0.4** · 底层 **0.25** | 课题 B |
| **类别** | A 纯增益 / B 条件克制 / C 复合 / D 无战斗映射 | 两边 |
| **目标属性** | 落到哪个真实 stat key（`stats.js` 的键名） | 课题 A |
| **适配槽** | 这件词条能出现在哪 5 个装备槽里 | 课题 A |
| **进 roll 池** | ✅ 能被装备抽到 / ❌ 只做打标 | 课题 A |
| **品质上限** | 该组最高能出到什么品质（B 类封「稀有」） | 课题 A |
| **数值系数** | 套《合并口径》§6.2 的 tier×品质表之后，再乘的系数 | 课题 A |

**表中没写、但必须记住的一条**：词条数值是**乘区**，乘在这件装备的「白板 + 主属性」上，
不是乘在角色总面板上（《合并口径》§一、§8.1）。

## 1. 层级与权重

| 层级 | 权重 | 装什么 | 来源 |
|---|---:|---|---|
| **顶层**（核心意象） | **1.0** | 功能特效、特殊字眼/系列 | 《标签清单》顶层 + 附件 3 |
| **中层**（形态/材质） | **0.4** | 器型、兽型、植型、材质 | 《标签清单》中层 |
| **底层**（大类归属） | **0.25** | `category`、`fateElement` | 脚本强制 |

### 1.1 跨层词裁定

同一个词同时出现在两张清单里时，按**它在物品名里扮演的角色**定层。当前只有 4 个词有歧义：

| 词 | 出现在 | 定为 | 理由 |
|---|---|---|---|
| **暗金** | 材质 + 特殊字眼 | **顶层 1.0** | 课题 B 例 3.1 已按 1.0 计，且它是修饰工艺而非材料本身 |
| **青金石** | 材质 + 特殊字眼 | **中层 0.4** | 课题 B 例 3.1 已按 0.4 计；它是真实材料。**这是唯一的顶层例外** |
| **厚土** | 材质 + 特殊字眼 | **顶层 1.0** | 作意象用（厚土镜/厚土诀），材质表里另有「灵土」 |
| **离火** | 特殊字眼（材质表里是「离火**晶**」，不是同一个词） | **顶层 1.0** | 词不同即分层不同 |

> ⚠ 这四个词是**手动例外**。以后再加跨层词，先写进这张小表，不要在打标脚本里临时判断。

## 2. 类别与数值

| 类别 | 含义 | 数值系数 | 品质上限 | 备注 |
|---|---|---:|---|---|
| **A 纯增益** | 直接加一条属性 | ×1.0 | 传说 | 套 §6.2 原表 |

## 5. 去重与 roll 算法

《合并口径》§6.5 的「按目标属性去重 + 重抽 10 次」保留，但实现顺序改成**先抽属性、后挑皮肤**，
从结构上消灭碰撞，不需要靠重抽兜底：

```
1. 按槽取 §4 的属性池
2. 按成色取词条数 n（§6.1：0 / 1 / 2 / 3）
3. 逐条：
   a. roll 品质（普通/稀有/传说，按 §6.1 的 80/20、75/20/5 与降级规则）
   b. 从该品质**允许的类别**里抽：
        · 传说位 → 只在 A / C 里抽
        · 稀有、普通 → A / B / C 都行
   c. 从该类别里抽一条**目标属性集合完全未被占用**的词条
   d. 该组的全部属性记为已占用（复合类占 N 个）
4. 属性池耗尽 → 本条作废（这件少一条词条），不降级、不补位
```

- 「锋锐」和「极锋锐」同属第 1 行、同占 `attackPct`，**天然不可能同件**。
- 同 series 同 tier 同成色仍可能词条不同（随机性来自品质 + 抽词）。

## 8. 给课题 B 的五条修正

课题 B 的例 3.1 有两处算错，**本表是唯一口径**：

| # | 问题 | 应改为 |
|---:|---|---|
| 1 | 「牌」记 0.25 | **中层 0.4**（器型属中层） |
| 2 | 「坚固」记 0.4 | **顶层 1.0**（功能特效属顶层）。日报只抓到了「牌」，这一处更影响结果 |
| 3 | 「玉」当成标签 | 词表里没有裸「玉」，只有 **白玉 / 青玉 / 暗玉**。例里的「玉(0.4)」应换成具体材质 |
| 4 | 「暗金 1.0 / 青金石 0.4」 | 保持，已写进 §1.1 的跨层裁定 |
| 5 | 底层 `category` 权重 | **0.25**（例里给对了） |

**按本表重算例 3.1**（去掉裸「玉」，其余照原标签）：

```
本命【饕餮玉牌】= 灵器 0.25 + 牌 0.4 + 青金石 0.4 + 饕餮纹 1.0 + 暗金 1.0 = 3.05
同参【风磨铜盾】= 灵器 0.25 + 盾 0.4 + 风磨铜 0.4 + 坚固 1.0 + 饕餮纹 1.0 + 青金石 0.4 = 3.45
交集 = 灵器 0.25 + 青金石 0.4 + 饕餮纹 1.0 = 1.65
契合度 = 1.65 / 3.05 = 54.1%
```

> 原例算成 50%，是因为「牌 0.25 + 坚固 0.4」两个错误互相抵了一部分。
> 这个 54.1% 才是课题 B 后续门槛重算的输入。

## 11. 子嗣专精词条（2026-10-26 新增；**2026-10-31 P60 已落地代码**）

> 来源：P51 #11「角色词条应该包含对装备的影响」→ P50 #15。用户 2026-10-26 拍板：
> **专精只管装备，不叠修炼**；细类覆盖**全部 43 个器型**。

### 11.1 效果

| 类型 | 系数 | 命中条件 | 作用对象 |
|---|---:|---|---|
| **细类专精**（如「剑专精」） | **+0.20（×1.2）** | 所穿装备的**器型** = 该细类 | 该件装备的「白板 + 主属性 + 词条」汇总 |
| **大类专精**（近战 / 防御 / 远程 / 法宝） | **+0.10（×1.1）** | 所穿装备的器型属于该大类 | 同上 |

- **取最高、不叠乘**：剑专精穿剑 = ×1.2；同时有「近战专精」也不会变成 ×1.32。
- **只作用于子嗣装备**（攻 / 防两槽）；**不影响修炼词条系数**（《模块二》§9.1 的 +0.05/+0.10/+0.20）——
  专精词条不进那套乘区。
- **一键装备评分**乘同一个专精系数：同一件装备，有专精的子嗣评分更高，会优先拿到。
- 与装备上的词条**互不干扰**：装备词条仍乘在这件装备的「白板 + 主属性」上（§0 最后一条）。

### 11.2 细类 = 43 个器型，大类映射

> 归类**可微调**（只影响大类专精命中率，不影响细类数值）。有争议的：伞→防御、索→远程、
> 器/舟/棺→法宝。

| 大类 | 器型（细类） | 数量 |
|---|---|---:|
| **近战** | 剑、刀、刺、匕、锤、鞭、矛、枪、棍、戈 | 10 |
| **防御** | 盾、牌、袍、冠、簪、伞 | 6 |
| **远程** | 弓、弩、镖、梭、索、纸鸢 | 6 |
| **法宝** | 幡、塔、戒、铃、杖、镜、舟、器、袋、盘、印、网、简、砚、丹炉、轮、环、钹、棺、拂尘、钵 | 21 |
| **合计** | | **43** |

### 11.3 抽取与品质

- 子嗣**最多 1 条专精**，**占 1 个词条位**（与现有词条位规则一致：下品 1 / 中品 1 /
  上品 2 / 极品 3 稀有 + 1 传说）。
- 品质对应：**细类专精 = 传说位**、**大类专精 = 稀有位**（与 +0.20 / +0.10 对齐）。
- **「剑心通明」改造为「剑专精」**：`t_sword_heart` id 保留、显示名改、效果换成「剑系装备 ×1.2」。

  - **老档不重掷**：按 id 原地改造，老档子嗣同样失去修炼 +0.10、获得剑系 ×1.2。
