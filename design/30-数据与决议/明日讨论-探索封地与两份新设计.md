## 1. 探索整体重做（P13.5 + P15.1）

### 现状（代码事实）

- 5 个地点：新手村 / 天阙峰 / 凤凰谷 / 龙渊 / 仙界入口。
- 事件只有四种：发现 / 战斗 / 战败 / 一无所获；文案与掉落是通用货。
- 修为奖励已删（P13.1）；删完后每地点奖励概率合计 0.8，**20% 固定空档**。
- **等级不参与胜率**（P15.1）：练气四层打「练气一层」的探索仍会战败。

### 必须先定

1. **事件结构**：保留四种，还是加入奇遇 / 商队 / 遗迹 / 散修等叙事节点？
2. **地点表**：名称、等级门槛、灵气消耗、事件间隔、战败养伤时长。
3. **奖励梯度**：灵石 / 灵草 / 丹方残页 / 功法 / 同参的掉率与数量；
   是否保留「一无所获」的空档（建议 5~10%，不要 20%）。
4. **与秘境分工**：
   - 探索 = 基础资源 + 基础功法（低风险高回报）；
   - 秘境 = 高级材料 + 准正主/正主同参；
   - 镇守 = 修为唯一主源。
5. **等级/胜率**：等级差、队伍战力、撤退阈值怎么算；是否复用秘境的战斗模型。
6. **TUNING**：幸运值、自动撤回、事件上限是否保留。
7. **模块五对齐**：普通任务/派遣与探索共用一套事件与战斗吗？

### 建议默认（可改）

- 事件 70% 基础（发现/战斗/采药/遗迹），20% 叙事（商队/散修/奇遇），10% 空档。
- 胜率按 `等级差 + 队伍战力`，同级基准 70%；跨 3 级以上必败/必胜。
- 探索只掉基础资源与**白板功法**；同参仍留给秘境（避免与宝箱/秘境三重来源）。

### 改前动作

- 先登记《产出登记表》R10；
- 按宪法第二章重算门槛；
- 同步《三大挂机》§三、《数值真值表》§6.3。

## 2. 模块四 · 封地经营

### 现状 / 约束

- **21 种建筑**（15 建筑 + 6 据点，见《数据定案》），但一行代码没写。
- 巡视乡间**真占时间、真扣体力、无产出**（现状是故意的）。
- UI 形态已被 P10 钉死：**「建设乡间」应该是「桂冈的一天」里的一环**，
  不是又一个需要切过去操作的管理页。配置面（建筑列表/升级）可以独立。
- 产出物（金页子/情报/民心/稳定度）目前没有任何消费口，属模块四/六。
- 家族工作 14 岗位、内宅稳定度、月饷都依赖它。

### 必须先定

1. **UI 形态**：哪些进主界面（巡视/建设进度），哪些留独立配置页（建筑树/升级）。
2. **21 种建筑**：每种的角色、解锁条件、造价、升级曲线；与 5 阶灵地怎么挂。
3. **资源产出**：灵谷 / 金页子 / 二阶灵石 / 情报 / 民心 / 稳定度；
   各自每天产多少、上限、消费口在哪（模块六/二/五）。
4. **巡视**：模块四上线后巡视产什么？（民心/情报/发现资源点？）现在是无产出。
5. **徭役/人口**：家族工作 14 岗位怎么挂子嗣属性；管理岗位公式是否沿用
   `10 + 有灵根×2 + 无灵根×0.5 + 门人×0.3`。
6. **分封/岁贡**：支脉领地是否复用模块四的建筑/产出模型；岁贡 30% 是否就定 30%。
7. **产出登记 + 门槛重算**：封地是第一块「资源产出引擎」，会改整条产出曲线。

### 建议默认（可改）

- 主界面只放「巡视 + 今日建设进度 + 资源条」；建筑树/升级放独立页。
- 先做 6~8 个基础建筑（灵田/矿场/药圃/账房/工坊/驿站），其余随灵地品阶解锁。
- 巡视产出民心/情报，不产硬资源 —— 保住「巡视是占时间无产出」的取舍。

## 3. 宝箱系统（`design/NEW/宝箱系统 — 暗黑2式TC掉落方案（最终版）.md`）

### 必须先定（按阻塞顺序）

1. **「无正主/极品」与现有同参六档怎么合并** ← **最阻塞**
   - 现有：正主 1.0 / 准正主 0.8 / 同系列 0.6 / 近类型 0.4 / 同类型 0.25 / 无关 0.1。
   - 新方案：只出底材，能不能当同参看 `series` 与本命匹配度。
   - 需要定：正主/准正主是否还是「名字档位」，还是完全由
     `series 命中 + 品阶封顶` 算出来？这决定物品池、探索、秘境的掉落表。
2. ✅ **7 阶宝匣 vs 物品 20 品阶**：宝匣 7 阶是宝匣阶级；6/7 阶不新增物品基阶，
   只出 5 阶极 + 特殊道具。
3. **获取途径与数量**：突破/子嗣诞生/秘境每 5·10 层/首杀/探索/镇守/坊市；
   每条的宝匣阶级、数量、概率；对 626 人口与经济的影响。
4. **大类权重**：灵石 50% / 空包 10% / 灵植材 20% / 灵器灵兽 15% / 残页道具 5%；
   10% 空包是否可接受。
5. **寻宝值 MF**：来源（子嗣词条 / 丹药 / 英烈祠）、上限、只影响成色还是也影响品阶。
6. **特殊道具**：洗命符（开局 5 张）、破境丹、联姻信物（依赖模块八）。
7. **坊市/合成**：灵石只能买 1~2 阶；5 个同阶合 1 个高阶（最高四阶）——价格与消耗口。
8. **宪法/产出登记**：这套是全局掉落源，必须过第七章登记 + 第二章门槛重算；
   还要和 P13.5 探索、秘境掉落避免三重来源。

### 建议默认（可改）

- 保留六档亲和度作为**计算方式**；正主/准正主改为「series 全匹配 + 品阶达标」，
  不再作为独立物品标签。
- 宝匣阶级 1~7 映射到品阶 1~14（凡品~四阶上品），五阶以上留给秘境。
- 空包降到 5%，把 10% 改成「灵材/丹药」。

## 4. 家族树与分封（`design/NEW/家族树与分封系统 — 完整设计方案书.md`）

### 必须先定（按阻塞顺序）

1. **子嗣修炼形式** ✅ **2026-10-19 已定**：启蒙后后台打坐 + 灵地/同参加成；
   出战门槛 = **练气二层**（见模块二 §15.2）。
   - 仍待细化：子嗣境界表、战力公式。
   - 代码现状仍是「有灵根 + 少年 140 天」，待子嗣修炼落地后替换。
2. **英烈祠**：并入家族树的「已故折叠层」，删掉独立入口（覆盖 P15.3）。
3. **洗命符**：开局 5 张、零产出、极低掉落；代码仍 10 张。
4. **血脉提纯合并**：母亲灵根档概率加权 + 现有「灵根数量提纯」（P15.5）的公式。
5. **家族树 UI**：代数折叠、支脉卡片、搜索/筛选；626 人口下的性能。
   与 9 列子嗣表**并存**（已定）。
6. **分家/支脉**：单/双灵根 + 筑基 + 未分配领地；支脉数据、岁贡 30%。
7. **寿元/死亡**：凡人 80 / 练气 120 / 筑基 200 / 结丹 500；每年判定；
   `passed_away`；对 626 人口与家族加成的影响。
8. **数据字段/老档**：`generation` / `branchId` / `lifespan` /
   `status: passed_away|expedition`；老档补齐方式。

### 建议默认（可改）

- 子嗣修炼先做**「灵地自动升级」**：把子嗣分配到某块灵地，按天涨修为，
  只算境界与战力，不单独做页面。
- 出战门槛用「有灵根 + 练气二层」（2026-10-19 拍板），替换现在的「少年 140 天」。
- 家族树先做「主家谱 + 支脉卡片」两层，折叠只做死代，不做无限树。
