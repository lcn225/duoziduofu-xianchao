3.2 单次 Pick 期望公式

```
期望(tier) = 灵石权重 × 灵石期望(tier)

+ 大类权重 × 大类期望(tier)

+ 残页权重 × 残页期望(tier)

+ 特殊权重 × 特殊期望(tier)

+ NoDrop 权重 × 0

大类期望(tier) = 降阶权重(15%) × 物品折价(tier-1)

+ 越阶权重(5%) × 物品折价(tier+1)

+ 本阶权重(80%) × 物品折价(tier)

物品折价(tier) = 基础价(tier) × 平均成色系数

平均成色系数 = 0.6×1.0 + 0.25×1.2 + 0.12×1.5 + 0.03×2.0 = 1.125
```

成色权重（下 60 / 中 25 / 上 12 / 极 3）已定，平均成色系数 = 1.125。

七、你的推导逻辑怎么接进来

你说的三步：

```
① 玩家每天收益多少

② 还缺多少资源突破瓶颈

③ 剩余多少钱买宝箱
```

接入方式：

步骤 公式 依赖

① 日收益 探索日收益 + 秘境日收益 + 封地税收 + 子嗣工作 探索/秘境数值（真值表 §6.3/§6.4）

② 突破缺口 同参价格 + 功法价格 + 丹药价格 物品价格体系（本文 §二）

③ 买宝箱 ① − ② − 必要支出 ① 和 ②

所以：物品价格体系是 ② 和 ③ 的前提。 你先填 §六 的 7 个输入，就能算出宝匣期望，再反推“玩家每天能买几个箱”。
