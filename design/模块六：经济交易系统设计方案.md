# 模块六：经济交易系统设计方案

## 一、模块定位

经济交易系统是放置游戏的中枢，连接修行、封地、内宅、门派和任务。玩家离线时，商队自动贸易、坊市自动交易、支账自动扣款；上线后，处理拍卖、定价、投资和外交经济。

对应小说中的灵石、金页子、大子、老九支账、郑家宝阁、沙洲坊市、拍卖会、人牙买卖。

**核心循环**：封地产出 → 商队贸易 → 坊市交易 → 获取灵石 → 支账购物/拍卖 → 提升修行和封地 → 产出更多资源。

## 二、货币系统

### 2.1 货币层级

| 货币   | 兑换               | 用途   | 来源     |
| ---- | ---------------- | ---- | ------ |
| 大子   | 100 大子 ≈ 1 金页子   | 凡俗日常 | 税收、商队  |
| 金页子  | 3.5 金页子 ≈ 1 一阶灵石 | 凡俗大额 | 税收、商队  |
| 一阶灵石 | 100 一阶 ≈ 1 二阶    | 低阶交易 | 矿场、任务  |
| 二阶灵石 | 800 二阶 ≈ 1 三阶    | 主流交易 | 俸禄、商队  |
| 三阶灵石 | —                | 高阶交易 | 战利品、拍卖 |

**注**：兑换有波动，受坊市供需影响。

### 2.2 门派贡献

| 来源   | 用途      |
| ---- | ------- |
| 门派任务 | 晋升、兑换   |
| 封地建设 | 兑换稀有资源  |
| 战功   | 兑换功法、法器 |

**贡献不可交易，仅限门派内部使用。**

## 三、商队系统

### 3.1 商队配置

| 商队   | 路线          | 耗时  | 收益      | 风险  |
| ---- | ----------- | --- | ------- | --- |
| 短途商队 | 飞鹰镇 ↔ 沙洲坊市  | 3天  | 100 二阶  | 低   |
| 中途商队 | 飞鹰镇 ↔ 郑家山门  | 7天  | 300 二阶  | 中   |
| 长途商队 | 飞鹰镇 ↔ 明冯沼泽  | 10天 | 500 二阶  | 中   |
| 边境商队 | 飞鹰镇 ↔ 连山派边缘 | 20天 | 1500 二阶 | 高   |
| 远洋商队 | 飞鹰镇 ↔ 七连寨   | 30天 | 3000 二阶 | 极高  |

### 3.2 商队配置

每次派遣商队可配置：

| 配置   | 效果                     |
| ---- | ---------------------- |
| 商队管事 | 无灵根子嗣，经商属性越高收益越高       |
| 护卫   | 有灵根子嗣或无灵根子嗣，武艺属性越高风险越低 |
| 货物   | 封地特产，如灵谷、灵草、炭火、法器      |
| 资金   | 用于采购外埠商品，回程贩卖          |

### 3.3 商队收益公式

```
商队收益 = 基础收益 
         × (1 + 商队管事经商/100) 
         × (1 + 货物品质加成) 
         × (1 + 势力好感加成) 
         - 风险损失
```

**风险损失**：遭遇劫匪、妖兽、关卡抽成。

## 四、坊市系统

### 4.1 沙洲坊市

沙洲坊市是飞鹰门与郑家共建，郑家八、飞鹰门二。

| 功能  | 说明                |
| --- | ----------------- |
| 购买  | 凡女、庶女、嫡女、丹药、符箓、法器 |
| 出售  | 封地特产、战利品、闲置物品     |
| 拍卖  | 稀有功法、本命物、高阶法器     |
| 人牙  | 购买侍妾、仆役           |
| 情报  | 购买势力情报、地图         |

### 4.2 郑家宝阁

| 商品   | 价格          | 说明        |
| ---- | ----------- | --------- |
| 凡女   | 1-15 一阶灵石   | 随机颜值      |
| 庶女   | 1-5 二阶灵石    | 5% 灵根概率   |
| 嫡女   | 10-30 二阶灵石  | 20% 灵根概率  |
| 女修   | 88+ 三阶灵石    | 100% 灵根概率 |
| 一阶丹药 | 80-200 二阶   | 正路子       |
| 一阶法器 | 200-2400 二阶 | 品质决定      |
| 符箓   | 50-800 二阶   | 类型决定      |

### 4.3 拍卖会

- 每月一次，沙洲坊市重建后开放。
- 拍卖品包括：功法残卷、本命物、高阶法器、稀有灵草。
- 玩家可**竞拍**或**寄售**。
- 竞拍消耗灵石，寄售收取 10% 手续费。

## 五、支账系统

### 5.1 老九支账

- 玩家俸禄可**支账购物**，享受内部价（市价 70%-80%）。
- 取现灵石需等腊月初八。
- 支账记录由老九管理，可能有**吃差价**风险。

### 5.2 查账机制

- 玩家可**查账**，消耗精力，有概率发现老九贪墨。
- 发现贪墨后，老九好感 -20，返还部分灵石。
- 老九好感低于 30 时，支账价格上浮 10%。

### 5.3 私藏战利品

- 玩家可私藏战利品，不上缴。
- 被执法阁发现后，扣俸禄 + 派系好感下降。
- 老八系成员更容易被告发。

## 六、投资系统

### 6.1 投资类型

| 投资    | 消耗      | 收益         | 风险  |
| ----- | ------- | ---------- | --- |
| 坊市商铺  | 500 二阶  | 每月 50 二阶   | 低   |
| 商队股份  | 1000 二阶 | 每趟 10% 分红  | 中   |
| 灵田开垦  | 300 二阶  | 灵谷 +10/天   | 低   |
| 矿场开采  | 800 二阶  | 一阶灵石 +20/天 | 中   |
| 人牙商行  | 2000 二阶 | 每月新侍妾      | 中   |
| 拍卖行股份 | 5000 二阶 | 每场 5% 抽成   | 高   |

### 6.2 投资回报

- 投资后，每月/每趟自动结算收益。
- 部分投资有**风险**，可能亏损。
- 投资可**转让**，但需手续费。

## 十、可玩性设计要点

1. **离线自动贸易**：商队自动运行，上线时查看收益。
2. **多货币体系**：大子、金页子、一阶/二阶/三阶灵石，层次分明。
3. **支账有风险**：老九可能吃差价，查账可发现，但得罪人。
4. **投资提供被动收入**：坊市商铺、商队股份、灵田开垦，长期回报。
5. **拍卖会提供稀有物品**：每月一次，竞拍功法、本命物、高阶法器。
6. **商队有风险**：遭遇劫匪、妖兽、关卡抽成，需配置护卫。
7. **人牙系统是侍妾来源**：郑家宝阁提供凡女、庶女、嫡女、女修。
8. **私藏战利品有风险**：可快速积累资源，但被执法阁发现后会扣俸禄。
9. **经济与政治联动**：投资坊市提升郑家好感，联姻获取彩礼。
10. **经济与封地联动**：封地资源用于商队贸易，商队收益反哺封地建设。
