# 《多子多福：开创仙朝》放置游戏 整体方案说明书

## 一、项目概述

### 1.1 项目定位

基于《我的放置仙途》开源项目（Vue 3 + Vite + Pinia + Naive UI）二次开发，以小说《多子多福：开创仙朝》为世界观蓝本，打造一款**放置经营 + 家族繁衍 + 门派政治 + 封地建设 + 事件选择 + 轻 Roguelite 子嗣养成**的浏览器端放置游戏。

### 1.2 核心体验

> 你把一个劫修小团体，慢慢经营成飞鹰门；把一个练气二层猪太保，养成多子多福的仙朝之祖。离线时，封地、内宅、门派、商队、子嗣都在自己跑；上线时，你负责突破、抽奖、联姻、站队、派遣和冒险。

### 1.3 技术基础

| 项目     | 说明             |
| ------ | -------------- |
| 前端框架   | Vue 3 + Vite   |
| 状态管理   | Pinia          |
| UI 组件库 | Naive UI       |
| 后台计算   | Web Workers    |
| 存档     | IndexedDB 增量存档 |
| 开源许可   | MIT            |

## 五、模块一：修行与突破

### 5.1 核心机制

- **速度线**：四维契合度决定修炼速度。
- **门槛线**：只有五个节点有契合度硬性要求，其余小境界挂机即可。

### 5.2 四维契合度

```
综合契合度 = (功法契合 + 同参契合 + 灵地契合 + 本命契合) / 4
```

| 维度   | 影响因素               |
| ---- | ------------------ |
| 功法契合 | 功法五行、等级、熟练度        |
| 同参契合 | 同参五行、等级、祭炼程度       |
| 灵地契合 | 灵地等级、五行匹配          |
| 本命契合 | 境界系数、本命技解锁数、本命物收集数 |

### 5.3 门槛节点

| 节点           | 契合度要求 |
| ------------ | ----- |
| 练气二层→三层（第一槛） | 20%   |
| 练气五层→六层（第二槛） | 50%   |
| 练气八层→九层（第三槛） | 75%   |
| 练气十层→筑基      | 80%+  |
| 筑基→结丹        | 100%  |

### 5.4 修炼速度公式

```
修炼速度 = 基础速率 × (0.5 + 综合契合度 × 1.5) × 子嗣加成 × 其他加成
```

## 六、模块二：多子多福

### 6.1 核心机制

- **仅有灵根子嗣提供修行加成和契合度加成。**
- **无灵根子嗣是人口基数和家族劳力**，用于扩大人口池、提升灵根概率、从事家族工作。
- **人口基数加成灵根概率**，形成“多子多福”的长期正循环。

### 6.2 灵根概率

```
灵根概率 = 基础概率 10% + 人口基数加成
```

| 子孙总数      | 人口基数加成 | 灵根概率 |
| --------- | ------ | ---- |
| 0-50      | +0%    | 10%  |
| 51-100    | +1%    | 11%  |
| 101-200   | +2%    | 12%  |
| 201-500   | +3%    | 13%  |
| 501-1000  | +5%    | 15%  |
| 1001-5000 | +8%    | 18%  |
| 5001+     | +10%   | 20%  |

### 6.3 子嗣抽卡

| 品质  | 综合概率 | 灵根      | 本命    | 词条          |
| --- | ---- | ------- | ----- | ----------- |
| 无灵根 | 90%  | 无       | 无     | 无           |
| 下品  | 6%   | 五灵根     | 凡兽    | 1个普通词条      |
| 中品  | 2.5% | 四灵根/三灵根 | 灵兽    | 1个稀有词条      |
| 上品  | 1.2% | 双灵根     | 王级变异兽 | 2个稀有词条      |
| 极品  | 0.3% | 单灵根     | 神兽/仙器 | 3个词条+1个传说词条 |

### 6.4 保底机制

- 每 20 次抽卡必出有灵根子嗣。
- 每 100 次抽卡必出上品及以上。
- 每 500 次抽卡必出极品。
- 首充礼包：第一个子嗣必定拥有灵根。

### 6.5 家族工作

无灵根子嗣可分配到 14 种岗位，产出资源、维护家族运转：

| 岗位   | 产出     |
| ---- | ------ |
| 庄头   | 粮草、金页子 |
| 账房   | 灵石     |
| 商队管事 | 灵石     |
| 亭卫亭卒 | 边境安全   |
| 灵田佃农 | 灵谷     |
| 工坊匠人 | 法器/符箓  |
| 家族护卫 | 家族安全   |
| 情报暗探 | 情报     |
| 教书先生 | 子孙成长   |

## 七、模块三：内宅姻缘

### 7.1 位阶系统

| 位阶  | 名称    | 月例       | 丫鬟  | 子嗣灵根加成 | 解锁条件          |
| --- | ----- | -------- | --- | ------ | ------------- |
| P1  | 通房丫鬟  | 50 大子    | 0   | +0%    | 初始            |
| P2  | 一等丫鬟  | 100 大子   | 1   | +0%    | 互动 10 次       |
| P3  | 三等侍妾  | 50 大子+衣物 | 2   | +0%    | 入房            |
| P4  | 四等如夫人 | 1 二阶灵石   | 4   | +1%    | 有喜            |
| P5  | 五等夫人  | 3 二阶灵石   | 6   | +2%    | 诞下有灵根子嗣       |
| P6  | 六等正妻  | 10 二阶灵石  | 8   | +3%    | 诞下极品子嗣 或 联姻嫡女 |

**关键**：位阶不影响怀孕率，只影响子嗣灵根加成和资源待遇。

### 7.2 侍妾状态机

| 状态   | 可互动 | 可怀孕 | 持续时间 |
| ---- | --- | --- | ---- |
| 待孕   | ✅   | ✅   | 默认   |
| 已孕   | ❌   | ❌   | 270天 |
| 例假   | ❌   | ❌   | 5天   |
| 产后恢复 | ❌   | ❌   | 30天  |
| 生病   | ❌   | ❌   | 3-7天 |
| 生气   | ❌   | ❌   | 1-3天 |
| 回娘家  | ❌   | ❌   | 7天   |

### 7.3 怀孕概率

```
怀孕概率 = 基础概率 10%
         + 好感度加成（好感/10，上限 +10%）
         + 子嗣加成（已有子嗣数 × 0.5%，上限 +10%）
         + 丹药加成（助孕丹 +20%，一次性）
         + 人口基数加成
         - 疲劳惩罚（精力低于 30 时 -10%）
```

### 7.4 精力系统

```
精力值上限 = 基础值 100 + 炼体等级 × 5 + 子嗣加成 + 侍妾加成
```

- 每次互动消耗 15 精力。
- 自然睡眠回满，丹药/灵茶/侍妾照料可额外恢复。
- 彩蛋：50 子嗣或 20 P4 侍妾后解锁精力无限。

### 7.5 母子关系

```
母子关系 = 基础值 50 + 生母好感/2 + 共同生活时间/10 - 分离时间/5
```

| 母子关系 | 效果                    |
| ---- | --------------------- |
| 亲密   | 子嗣对玩家好感 +10，派遣成功率 +5% |
| 和睦   | 子嗣对玩家好感 +5，派遣成功率 +2%  |
| 疏远   | 子嗣对玩家好感 -5，叛逆概率 +5%   |
| 冷漠   | 子嗣对玩家好感 -10，叛逆概率 +10% |

**同母子女**：好感度更高，可组队派遣，效率 +10%。

```
成功率 = 基础 50% 
       + (队伍战力 - 推荐战力) / 推荐战力 × 30%
       + 子嗣好感加成
       + 词条加成
       - 风险惩罚
```

| 子嗣事件 | 诞生、成长、派遣、陨落触发     |
| 内宅事件 | 争宠、告状、下毒触发        |
| 封地事件 | 秋收、妖兽入侵触发         |
| 门派事件 | 合议、职位晋升触发         |
| 随机奇遇 | 低概率触发，提供额外奖励      |

### 11.2 事件优先级

| 优先级 | 类型             | 处理时限 |
| --- | -------------- | ---- |
| 紧急  | 子嗣陨落、侍妾下毒、妖兽入侵 | 立即   |
| 高   | 合议、职位晋升、子嗣诞生   | 当日   |
| 中   | 争宠、告状、商队遇劫     | 3 日内 |
| 低   | 怀孕喜讯、侍妾生病、流民来投 | 7 日内 |
| 背景  | 秋收、登仙大典、幡阵操演   | 自动结算 |

### 11.3 事件分支与连锁

每个事件的选择会影响多个模块的数值和后续剧情。例如：

**子嗣陨落**：

- 复仇 → 对相关势力发起攻击 → 触发征战任务
- 抚恤 → 安抚生母 → 生母好感 +10
- 遗忘 → 无变化 → 生母好感 -20
